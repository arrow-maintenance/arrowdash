* **Apache Arrow 26.0.0 release:** The community released version 26.0.0, which resolves 337 issues across the project's various language implementations and libraries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Apache Arrow ADBC 25 release:** Release 25 of the ADBC subproject is now available, featuring updates to independent components across C/C++, Go, Java, Python, and Rust. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed Sovereign Tech Agency has contracted several maintainers to focus on PyArrow type annotations, documentation improvements, and extension type support through 2027. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI workflow optimization proposal:** A detailed analysis suggests that Arrow can reduce its GitHub Actions runner usage by up to 40% by refining path filters and reducing the frequency of heavy Linux package builds on merges to main. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%7E30-40%25%20fewer%20runner%20minutes)

* **Managing AI-generated contributions:** Maintainers are discussing new policies to handle the high volume of AI-generated pull requests, including mandatory disclosure and automated draft conversion for low-engagement PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Arrow Rust 60.0.0 release:** The Rust community announced version 60, which includes new Parquet encoding support and significant kernel performance improvements across decimal and filter operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical range extension types:** A vote is underway to add fixed and variable closedness range types to the Arrow canonical extension types to support mathematical intervals and PostgreSQL-style ranges. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary-encoded extension types:** This proposal introduces optional `custom_metadata` to `DictionaryEncoding` to ensure extension type metadata is preserved during IPC and C Data Interface transfers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **PyArrow modularity improvements:** Developers are exploring ways to split PyArrow into smaller, modular components to reduce binary wheel sizes and lower the maintenance burden for downstream projects. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Substrait dialect advertising in Flight SQL:** A proposal to add new `SqlInfo` codes would allow Flight SQL servers to communicate which specific Substrait types, relations, and expressions they support to clients. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)
