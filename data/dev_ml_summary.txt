* **BigDecimal extension proposal pause:** The proposal for a canonical `BigDecimal` extension type was paused to re-evaluate requirements, focusing on layout performance and alignment with existing database numeric types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate `Tensor` and `SparseTensor` messages in the IPC protocol, as these features currently lack the multi-implementation support required for official format standards. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal, a new project providing Arrow compute kernels that run on Apple silicon GPUs via Metal and use the C Device Data Interface for zero-copy interop. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Aligning Variant and Parquet specs:** Discussions focused on reconciling the Arrow Variant extension with Parquet shredding specifications, specifically regarding the handling of types like unsigned integers and nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Apache Arrow Go 18.8.0 release:** The Go implementation released version 18.8.0 after resolving build tag issues related to newer Go toolchains and the standard library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20Go%20v18.8.0%20Released)

* **New File extension type proposal:** A proposal was introduced for a canonical `arrow.parquet.file` extension type to store file-level references (URI, offset, size) in-memory, matching the Parquet FILE LogicalType. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Limits on concurrent PRs:** Consensus was reached to limit non-committers to three concurrent open pull requests to help manage the maintenance and review burden across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **New Committer appointments:** Zehua Zou and Kosta Tarasov have been invited and accepted roles as new committers for the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Kosta%20Tarasov)
