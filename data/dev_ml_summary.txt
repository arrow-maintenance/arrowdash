* **BigDecimal extension status:** Discussion on the `arrow.big_decimal` proposal has been paused to better evaluate compute kernel support and alignment with existing ecosystem practices for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Hackathon at Community Over Code:** An in-person hackathon is scheduled for October 13 in Glasgow, featuring curated issues and on-site committers to help new contributors get started with the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Variant and Parquet shredding consistency:** Discussion on updating the Variant extension spec to explicitly disallow certain types in the Arrow representation that have no equivalent in the Parquet shredding specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data-oriented runtimes and data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **IPC Tensor deprecation:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to simplify the format and reflect low implementation across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Go 18.8.0 release:** Apache Arrow Go v18.8.0 has been released, including 283 commits and fixes for compatibility with the Go 1.27 toolchain. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **Canonical extension for FILE type:** Proposal to define an `arrow.parquet.file` extension type to match the new FILE LogicalType in Parquet, allowing file-level references to be preserved in Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArrowMetal compute for Apple GPUs:** Announcement of ArrowMetal, a project providing Arrow compute kernels for Apple Silicon GPUs via Metal with zero-copy memory sharing and support for multiple language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **New committers:** The project welcomed Zehua Zou and Kosta Tarasov as new committers in recognition of their significant contributions to the Arrow and Parquet implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou)
