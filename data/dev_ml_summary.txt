* **Arrow Rust 60.0.0 Release:** Major release featuring the first Parquet implementation of ALP encoding, new PageIndex structures, and significant kernel performance optimizations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **PyArrow Modularity Proposal:** Discussion on splitting PyArrow into multiple optional wheels (e.g., pyarrow-s3) to significantly reduce the package size on PyPI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel Support:** Proposal to end official support for macOS Intel targets due to the inability to maintain testing CI as platforms like Homebrew phase out support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **AI-Generated Contribution Guidelines:** Proposal to establish reviewer protocols and a "needs-author-engagement" label to handle low-quality, AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Apache Arrow 26.0.0 Release:** Voting is concluding for the version 26.0.0 release candidate, which includes over 300 resolved issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **IBM Db2 ADBC Driver:** IBM engineers have proposed contributing a new native C++ ADBC driver for IBM Db2 to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON Representation of Schemas:** Ongoing technical discussion regarding the standardization of a JSON format for Arrow schemas to support complex nested types and unions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Canonical Range Extensions:** A vote is in progress to add new canonical extension types for representing bounded intervals with fixed or variable closedness. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)
