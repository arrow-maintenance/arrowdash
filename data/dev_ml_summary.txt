* **Concurrent PR limits:** Discussion on limiting non-committers to three concurrent open pull requests to ensure manageable review cycles and mitigate potential AI-generated spam. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **IPC Tensor deprecation:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to a lack of cross-language implementation support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal extension proposal:** A proposal for a canonical BigDecimal extension type was paused to allow for deeper investigation into compute kernel requirements and existing ecosystem practices. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArrowMetal announcement:** Introduction of ArrowMetal, a project providing Arrow compute kernels that run on Apple silicon GPUs through Metal using the C Device Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **FILE Extension Type:** Discussion on defining a canonical extension type (`arrow.parquet.file`) to align with the new Parquet FILE LogicalType for file-level references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang integration:** Introduction of Arx, an experimental programming language built with Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Conbench infrastructure:** Discussion on evolving the project's benchmarking infrastructure, including moving toward a storage model based on Parquet files and DuckDB queries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **Go and Rust releases:** The community finalized releases for Arrow Go v18.8.0 and Arrow Rust v60.0.0, featuring numerous improvements to Parquet support and Flight SQL. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)
