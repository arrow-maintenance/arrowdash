* **PyArrow modularity and wheel splitting:** Proposal to split PyArrow into multiple wheels (e.g., `pyarrow-s3`, `pyarrow-gcs`) to reduce the installation size on PyPI, which currently totals over 2GB per release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 release:** The community is voting on the 26.0.0 release candidate, which includes over 330 resolved issues across the project's various implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Apache Arrow Rust 60.0.0 release:** A major update for the Rust implementation is now available, featuring support for the new ALP encoding in Parquet and significant performance improvements in kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Deprecation of macOS Intel support:** Discussion on dropping support for macOS x86_64 due to Homebrew ending support for Intel bottles and very low usage statistics compared to ARM64. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** A formal vote is underway to add `fixed_closedness_range` and `variable_closedness_range` to the official Arrow specification for representing bounded sets. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Reviewer guidelines for AI-generated code:** Proposal to update reviewer documentation with clear steps for handling low-quality AI contributions, including a new "needs-author-engagement" GitHub label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Standardizing JSON representation of Arrow schemas:** Ongoing discussion to formalize a JSON format for schemas to improve data contract definitions and interoperability between different processes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **CSV date and time parsing improvements:** Efforts to merge a long-standing PR that allows the CSV reader to use custom timestamp parsers as a fallback for specific date and time types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2B%20Python%20Getting%20PR%20%2350146%20CSV%20date%2Ftime%20parsing%2C%20GH-41488%20reviewed)

* **ADBC visual identity and logo:** The Arrow Database Connectivity (ADBC) subproject is finalizing its new logo and visual identity to be incorporated into its documentation and site. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)
