* **Arrow 26.0.0 and 26.0.1 releases:** Arrow 26.0.0 was released with over 300 resolved issues, followed quickly by a 26.0.1 patch to address a Brotli security vulnerability (CVE-2026-111497) and CI failures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.1%20-%20RC1)

* **ADBC 25 release:** The ADBC subproject released version 25, featuring 57 improvements and bug fixes across the C/C++, C#, Go, Java, Python, R, Ruby, and Rust implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **Sovereign Tech Fund investment:** The German Sovereign Tech Agency announced funding for PyArrow development, focusing on type annotations, documentation improvements, and tools to help maintainers manage high volumes of contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI optimization and policy changes:** Maintainers discussed strategies to reduce GitHub Actions usage by 40% and prepared for the upcoming restriction of the `pull_request_target` trigger in ASF repositories. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **AI-generated contribution policy:** The community is formalizing a policy for AI-generated PRs, including proposed mandatory disclosure and a neutral "needs-author-engagement" label for low-quality agentic submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Rust patch release cycle:** Significant effort went into coordinating patch releases for the arrow-rs 57, 58, 59, and 60 branches to backport bug fixes and maintain stability across versions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Rust%20patch%20releases%20for%2057%2C%2058%2C%2059%20and%2060%20branches)

* **Dictionary-encoded extension types:** Proposal to update the IPC format to allow metadata on dictionary values, enabling the correct representation of extension types (like UUIDs) when they are dictionary-encoded. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait dialect advertising:** Discussion on adding new `SqlInfo` codes to Flight SQL so that servers can advertise exactly which Substrait dialects and features they support to clients. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC driver:** IBM developers proposed contributing a new native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **New committer announcement:** Richard Baah has been invited to become a committer on the project in recognition of his significant contributions to the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Richard%20Baah)
