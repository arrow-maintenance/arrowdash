* **Arrow 26.0.1 patch release:** The RC1 vote passed with seven binding approvals, and the release was announced on Nov 4. It includes the Brotli fix for CVE-2026-111497. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.1%20released)

* **PyArrow 27 timing:** Users asked when PyArrow 27 would ship after a scanner flagged a vulnerability in 26.0.1. The reply says it is planned for January 2027. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Version%2027)

* **FILE canonical extension type:** A vote is open on adding the arrow.parquet.file extension type (GH-51143). Reviewers disagree on whether Parquet-specific types should be canonical in Arrow or specified by the Parquet project itself. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow Java 20.0.0 release:** The vote passed with seven binding approvals, and the release went out on Nov 21. It requires Java 17 as the minimum version. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Java%2020.0.0%20Released)

* **Arrow Java release cadence:** A proposal to release Arrow Java at least quarterly, or on demand, received broad support. A volunteer will manage the releases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **Arrow-rs patch releases:** Versions 60.2.0, 59.3.3, 58.4.2 and 57.3.3 were all approved and published in mid-November. Each vote had at least four binding approvals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1)

* **Flight SQL Substrait dialect codes:** A vote proposes two new SqlInfo codes so clients can discover and cache the Substrait dialect a server accepts. The change is backward-compatible. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **ADBC 1.2 planning:** The planning session cleaned up the milestone and agreed on the approach for metadata, credential callbacks, error details and vendor actions. Partitioned bulk ingest still lacks consensus, async is out of scope, and no target date is set. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **Merge button and CI migration:** Committers can now squash-and-merge PRs in apache/arrow instead of using the merge script. Workflows are also being moved off pull_request_target before GitHub restricts it on December 2. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20PRs%20in%20apache/arrow%20can%20now%20be%20merged%20with%20merge%20button) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)
