* **Semantics of non-nullable fields:** Discussion on the technical definition of the `nullable` flag in the IPC format for complex types, specifically how to handle non-nullable child fields within null parent structs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Windows Arm64 support for PyArrow:** Microsoft engineers proposed a formal support plan for adding `win_arm64` wheels, including dedicated maintenance resources and a commitment to unify Windows build paths. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **PR limits for non-committers:** Proposal to limit contributors without write access to 3 concurrent open pull requests to help manage a recent uptick in stale or low-value AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal extension type:** Formal vote opened for adopting a new `arrow.big_decimal` extension type to provide high-fidelity representation for variable-scale numeric data from databases like PostgreSQL and Oracle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Apache Arrow 25.0.0 and 25.0.1 releases:** Major release 25.0.0 and follow-up patch release 25.0.1 were published, resolving over 200 issues including performance improvements for Python nested type conversions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Swift 6.0 minimum version bump:** Proposal to raise the minimum Swift requirement to 6.0 to unlock native `Int128` support, which is a prerequisite for implementing Decimal types in the Swift binding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension spec inconsistency:** Review of the Arrow Variant spec revealed discrepancies with the Parquet shredding spec regarding supported unsigned integer mappings, leading to a proposal for alignment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC 24 release:** The ADBC subproject released version 24, featuring a major overhaul of the documentation to better explain driver sources and independent component versioning. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)
