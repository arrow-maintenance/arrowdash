* **Windows Arm64 support for PyArrow:** Microsoft proposed a formal support plan for win_arm64, including dedicated engineering from Linaro and a transition to `abi3` wheels to manage PyPI package size constraints. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-language implementation and a shift in project focus. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal Canonical Extension Type:** A proposal for a variable-scale `arrow.big_decimal` type was discussed to improve RDBMS interoperability, though active work is currently paused to better align on compute kernel requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limiting concurrent Pull Requests for non-committers:** To manage an influx of low-quality and AI-generated contributions, the project is moving toward a policy that limits non-committers to three concurrent open pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **New Canonical Extension Type for FILE:** A new proposal was introduced for `arrow.parquet.file` to provide a standardized in-memory representation for file-level references, aligning with recent changes to the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Apache Arrow 25.0.1 Release:** This patch release addressed 9 issues, including significant performance improvements for converting nested types to Python lists and fixes for timezone handling in Gandiva. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **ArxLang announcement:** Introduction of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data-oriented runtimes, arrays, and tensors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** Discussion on using custom fault handling to lazily map Parquet columns to memory, enabling vectorized operations over entire columns while hiding row-group boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **Conbench benchmarking infrastructure updates:** Proposals were made to evolve the Conbench benchmarking tool, including a transition toward storing performance data in Parquet files queried via DuckDB. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)
