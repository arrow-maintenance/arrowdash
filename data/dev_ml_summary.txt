* **Windows ARM64 support for PyArrow:** Microsoft proposed a plan to support Windows on ARM64, offering dedicated engineering resources and hardware to manage CI maintenance and ensure stable releases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limiting concurrent PRs for non-committers:** Discussion on implementing a limit of 3 concurrent open pull requests for contributors without write access to manage the influx of stale or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal extension type:** A proposal to add a variable-scale decimal extension type for better RDBMS interoperability remains under debate regarding its memory layout and performance characteristics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang - An Arrow-native programming language:** Introduction of Arx, an experimental language built with Apache Arrow as its native foundation for arrays, tensors, and dataframes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** Proposal for a technique to map Parquet columns to virtual memory lazily, allowing large datasets to be treated as zero-copy NumPy arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Apache Arrow 25.0.1 maintenance release:** The community released version 25.0.1, featuring several bug fixes and significant performance improvements for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **ADBC 24 and nanoarrow 0.9.0 releases:** Updates to the Arrow Database Connectivity (ADBC) libraries and the lightweight nanoarrow implementation were finalized this month. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Community growth and upcoming hackathon:** The project welcomed new PMC member Jeffrey Vo and committers Tadeja Kadunc and Zehua Zou, and announced an in-person hackathon in Glasgow this October. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
