* **Limit on concurrent open PRs:** Proposal to limit non-committers to three concurrent open pull requests to manage an uptick in stale or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to lack of cross-implementation support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal extension proposal paused:** Design work on a canonical BigDecimal extension type has been paused to better evaluate ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArrowMetal GPU compute kernels:** Announcement of ArrowMetal 0.1.0, which provides Arrow compute kernels for Apple Silicon GPUs using Metal with zero-copy data sharing between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Variant and Parquet shredding alignment:** Discussion on updating the Variant extension specification to explicitly disallow types like unsigned integers that have no equivalent in the Parquet shredding spec. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Canonical FILE extension type:** Proposal to introduce an `arrow.parquet.file` extension type to provide a standardized in-memory representation for file-level references found in Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Arrow Hackathon at Community Over Code:** Announcement of an in-person hackathon in Glasgow on October 13, 2026, targeting both new and experienced contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
