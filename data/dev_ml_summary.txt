* **Arrow 26.0.1 patch release:** The RC1 vote passed with seven binding approvals, and the release shipped on Nov 4 with the bundled Brotli CVE fix. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.1%20released)

* **Arrow Java 20.0.0 and release cadence:** The 20.0.0 vote passed and the release went out on Nov 21, with Java 17 now the minimum. A proposal to release Arrow Java at least quarterly drew broad support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **Arrow Rust patch releases:** Rust 57.3.3, 58.4.2, 59.3.3 and 60.2.0 were all approved and published to crates.io. Each vote drew several approvals, and one test-portability issue on Rust 1.99 was judged non-blocking. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1)

* **Parquet FILE canonical extension type:** A vote on adding arrow.parquet.file (GH-51143) is underway. Contributors debated whether Parquet-specific types belong among Arrow canonical extension types or should be defined by the Parquet project, and the vote may be put on hold. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ADBC 1.2 planning:** A planning session agreed that the credential callback will call SetOption, that structured error details will use JSON, and that vendor actions will follow the draft escape-hatch design. Partitioned bulk ingest still lacks consensus, and no target date is set. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **Flight SQL Substrait dialect codes:** A proposal to add SQL_SUBSTRAIT_DIALECT and a dialect hash to SqlInfo received approvals from several committers. The change is backward compatible. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **pull_request_target migration:** GitHub will restrict this workflow trigger from Dec 2, so Arrow workflows need migrating. The Boring Cyborg labeling bot has been enabled across Arrow repositories. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)

* **Merge button for PRs:** Committers can now use "Squash and merge" in apache/arrow instead of the dev/merge_arrow.sh script. The script still works for now. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20PRs%20in%20apache%2Farrow%20can%20now%20be%20merged%20with%20merge%20button)

* **Copilot auto-review costs:** Automatic Copilot reviews on apache/arrow were being billed to contributors' personal accounts. A change to stop auto-review on every push was proposed. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Auto%20GitHub%20Copilot%20review)

* **Compute! Paris gathering:** An Arrow and Parquet joint Birds of a Feather session is scheduled for Nov 26 during Compute! Paris, with no fixed agenda. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Nov%2026%20Arrow%20%2F%20Parquet%20Birds%20of%20a%20Feather%20at%20Compute%21%20Paris)
