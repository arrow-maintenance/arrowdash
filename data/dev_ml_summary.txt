* **Arrow 25.0.0 Release:** Major release featuring over 220 resolved issues and performance improvements across multiple implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **Deprecating Tensor IPC messages:** Proposal to deprecate dedicated Tensor and SparseTensor IPC messages in favor of canonical extension types for better security and maintainability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Deprecate%20Tensor%20and%20SparseTensor%20messages?)

* **JSON Schema Representation:** Discussion on establishing a canonical human-readable JSON representation of Arrow schemas for use in REST APIs and ADBC metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Conbench v2 Migration:** Progress on migrating the project's benchmarking infrastructure to a new Go backend and Svelte/Vite frontend to address performance bottlenecks. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)

* **Nullability semantics in complex types:** Debate regarding how the `nullable` flag should be interpreted for non-trivial types, such as non-nullable child fields within nullable parent structs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant spec alignment:** Efforts to align the Arrow Variant extension specification with the Parquet shredding spec, specifically regarding the inclusion of unsigned integer types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **C Data Interface field name constraints:** Clarification on how the C Data Interface should handle field names containing embedded null bytes, which are valid in Arrow but problematic for C strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **ADBC 24 Release and Documentation:** Release candidate for the latest ADBC libraries alongside a significant overhaul of the documentation to better describe driver sources. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)
