* **Apache Arrow 26.0.0 Release:** The community announced the release of version 26.0.0, which resolves 337 issues and includes significant updates across various language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed Sovereign Tech Agency is funding 1.9 FTEs through 2027 to work on PyArrow annotations, documentation, and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **New range canonical extension types:** A vote was held to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` to the official canonical extension types to better support mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **AI-generated contribution policy:** Maintainers discussed strategies to handle the high volume of AI-generated PRs, including mandatory disclosure and automated "author engagement" labels for suspicious contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Improving PyArrow modularity:** Discussion on splitting PyArrow into smaller modules to reduce the size of the wheel, addressing concerns from downstream libraries that find the current package too large. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **IPC representation of dictionary-encoded extension types:** A proposal to add `custom_metadata` to `DictionaryEncoding` to allow IPC and the C Data Interface to correctly represent extension types within dictionary-encoded data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait dialect advertising:** Proposal to add new `SqlInfo` codes allowing Flight SQL servers to describe exactly which parts of the Substrait specification they support using dialect files. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **GitHub Actions CI optimization:** Analysis of Arrow's CI usage suggests that removing redundant "Extra" workflows and moving to smaller runners could save 30-40% of total runner minutes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20~30-40%25%20fewer%20runner%20minutes)

* **Security patch for Brotli CVE:** The community fast-tracked a fix for CVE-2026-111497 in the Brotli library, ensuring it is included in the upcoming 26.0.1 patch release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20GH-55165%20in%2026.0.1)

* **IBM Db2 driver for ADBC:** IBM contributors have implementation-ready native C++ ADBC drivers for IBM Db2 (LUW) and are seeking to integrate them into the official ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
