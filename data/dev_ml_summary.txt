* **Windows Arm64 support for PyArrow:** Microsoft proposed a plan to support `win_arm64` builds, offering to fund engineering work for `abi3` wheels and unified Windows build paths. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limits on concurrent open PRs:** Community members discussed limiting non-committers to three concurrent open pull requests to mitigate an increase in stale or low-value AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Deprecation of Tensor and SparseTensor in IPC:** A formal vote passed to informally deprecate `Tensor` and `SparseTensor` messages in the IPC protocol, encouraging implementations to move away from these metadata formats. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal canonical extension type:** A proposal for a `BigDecimal` extension type to handle variable-scale decimals was paused after feedback suggested the need for a broader design regarding compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Apache Arrow 25.0.1 release:** Version 25.0.1 was released, including 9 resolved issues and significant performance improvements for Python conversions of nested types like structs and maps. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.1%20released)

* **Canonical Extension Type for FILE:** Developers are discussing a new `arrow.parquet.file` extension type to maintain semantic parity with the new Parquet FILE logical type across IPC and Flight streams. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** An introduction to Arx, an experimental programming language that utilizes Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant and Parquet spec consistency:** Discussion on updating the Variant extension specification to explicitly disallow certain types like unsigned integers to maintain consistency with Parquet shredding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Lazy memory mapping for Parquet:** A proposal to use custom fault handling to lazily map Parquet columns to memory, enabling vectorized operations over entire columns without explicit row-group handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)
