* **Arrow 25.0.0 release:** Official release of version 25.0.0, covering over 220 resolved issues across the core implementations and including performance improvements for PyArrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on a new canonical JSON format for schemas to improve human readability and interoperability in REST APIs and ADBC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable fields in nested types:** Technical debate regarding how the `nullable` flag should be interpreted for child fields in structs and unions when the parent element is null. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Swift 6.0 minimum version proposal:** Proposal to raise the minimum Swift version requirement to 6.0 to leverage native Int128 support for implementing Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension and Parquet spec alignment:** Identification and discussion of inconsistencies between the Arrow Variant extension and the Parquet Variant shredding specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **C Data Interface field name clarification:** Investigation into how the C FFI should handle field names containing embedded null bytes, which are valid in Arrow but incompatible with standard C-strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **nanoarrow 0.9.0 release:** The lightweight implementation for C and C++ reached version 0.9.0, including significant updates to the R and Python bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC Member:** Jeffrey Vo has been invited to and joined the Apache Arrow Project Management Committee (PMC). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
