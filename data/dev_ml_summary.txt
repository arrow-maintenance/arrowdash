* **Apache Arrow 26.0.0 release:** The community announced the major release of version 26.0.0, which resolves 337 issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **PyArrow modularity proposal:** Discussion on breaking down the monolithic PyArrow installation into smaller, optional wheels (e.g., `pyarrow-s3`) to reduce package size on PyPI and decrease the burden on users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **AI-generated contributions policy:** Proposal to introduce a "needs-author-engagement" GitHub label to flag PRs that appear AI-generated and require more direct input from authors to ensure they understand the proposed changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Dropping macOS Intel support:** Discussion on phasing out support for macOS Intel hardware due to Homebrew dropping support and the increasing difficulty of maintaining these environments in CI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** Formal vote on adding `fixed_closedness_range` and `variable_closedness_range` extension types to the Arrow specification to standardize bounded set representations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC dictionary-encoded extension metadata:** Proposal to add an optional `custom_metadata` field to `DictionaryEncoding` in the IPC format, allowing dictionary value types to properly carry extension type information. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Arrow Rust 60.0.0 release:** Announcement of the latest major Rust release, including significant Parquet encoding updates, kernel performance optimizations, and a sustained effort to reduce panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Flight SQL Substrait dialect advertisement:** Proposal to allow Flight SQL servers to advertise supported Substrait dialects via `SqlInfo`, helping producers avoid sending unsupported plans. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC driver contribution:** IBM researchers proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
