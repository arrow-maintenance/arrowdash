* **Apache Arrow 26.0.0 Release:** Major release featuring over 300 resolved issues across all implementations, followed immediately by a 26.0.1 patch to address a Brotli security vulnerability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Sovereign Tech Fund Investment:** The German government-backed fund is financing approximately 1.9 full-time equivalents through 2027 to improve PyArrow annotations, documentation, and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **GitHub Actions CI Optimization:** Discussion on reducing Arrow's CI footprint by up to 40% through better job filtering, moving to "ubuntu-slim" runners, and optimizing nightly vs. per-commit triggers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **Handling AI-Generated Contributions:** Proposal to implement stricter rules for AI-written PRs, including mandatory disclosure and automated draft status for PRs that lack human engagement. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **PyArrow Modularity Improvements:** Discussion on reducing the PyArrow package size by splitting it into smaller, modular components to help users avoid heavy dependencies they don't need. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **ADBC 25.0.0 Release:** A new release of the Arrow Database Connectivity subproject includes updates for C, C++, Go, Java, and Python, alongside news of a native Db2 driver contribution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **Range Canonical Extension Types:** Formal vote to add `fixed_closedness_range` and `variable_closedness_range` to the Arrow format to support mathematical intervals (e.g., PostgreSQL's numrange). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Dictionary-Encoded Extension Types in IPC:** Proposal to allow `custom_metadata` on dictionary values within the IPC format to enable proper representation of extension types that are dictionary-encoded. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Substrait Dialect Support in Flight SQL:** Proposal to add new SqlInfo codes allowing servers to advertise which specific Substrait dialects and features they support for plan execution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)
