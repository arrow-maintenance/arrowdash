* **Arrow 26.0.0 release:** A vote is underway for the major version 26.0.0 release, which includes over 330 resolved issues across the project's components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and split wheels:** Proposal to split PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to significantly reduce the main package size and maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **AI-generated contribution guidelines:** Reviewers are discussing new policies for handling low-quality AI-generated pull requests, including a "needs-author-engagement" label to manage low-effort submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Range canonical extension types:** The community voted to add new "fixed_closedness_range" and "variable_closedness_range" extension types to represent mathematical intervals within Arrow arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Rust 60.0.0 release:** The Rust implementation reached version 60.0.0, featuring support for the new ALP encoding in Parquet and significant performance gains for kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Dropping macOS Intel support:** Developers are considering sunsetting official CI support for x86_64 macOS as Homebrew and GitHub Actions move toward prioritizing ARM-based runners. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **JSON representation of Arrow schemas:** Discussion continues on formalizing a JSON-based schema format to help define data contracts for cross-process communication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Tensor deprecation in IPC:** A formal PR has been submitted to deprecate Tensor and SparseTensor types in the IPC format to focus on more widely used core components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)
