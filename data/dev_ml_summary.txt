* **Arrow 25.0.1 release:** The community released version 25.0.1, a maintenance update resolving 9 issues including timezone-related test failures in the C++ implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.1%20released)

* **Limits on concurrent PRs:** Discussion on implementing a limit of 3 concurrent open pull requests for non-committers to mitigate the influx of low-value or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Deprecation of Tensors in IPC:** A vote passed to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-implementation support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal extension type:** A proposal for a canonical `arrow.big_decimal` extension type was discussed but ultimately paused to better evaluate performance requirements and compute kernel needs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **New Canonical FILE extension:** Proposal to add `arrow.parquet.file` as a canonical extension type to provide an in-memory representation for the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Community milestones and Hackathon:** The project welcomed three new committers—Tadeja Kadunc, Zehua Zou, and Kosta Tarasov—and announced a contributor hackathon at the Community Over Code Glasgow conference in October. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Go and Rust implementation updates:** Version 59.3.0 of the Rust implementation was released, while the Go 18.8.0 release process addressed build compatibility issues for the Go 1.27 toolchain. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
