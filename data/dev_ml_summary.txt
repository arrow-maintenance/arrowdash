* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-implementation support and maintenance overhead. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal 0.1.0, a project providing Arrow compute kernels that run natively on Apple GPUs via Metal, utilizing shared memory for zero-copy transfers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension type pause:** Discussion on the `arrow.big_decimal` canonical extension type has been paused to gather more information on ecosystem practices and compute requirements before standardizing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Canonical Extension Type for FILE:** A proposal was introduced for an `arrow.parquet.file` extension type to align with Parquet’s new FILE logical type, preserving file-level reference semantics in Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang experimental language:** Introduction of Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data types and its runtime environment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Arrow Go 18.8.0 release:** The Go implementation release was finalized with 283 commits, following troubleshooting regarding build tags and compatibility with newer Go toolchains. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **Variant and Parquet shredding consistency:** Developers are discussing modifications to the Variant extension spec to explicitly disallow certain types that lack equivalents in the Parquet shredding specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Rust 60.0.0 and Object Store releases:** The Rust implementation is moving through major version release candidates, while the Object Store library addressed licensing header issues discovered during its release cycle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Arrow Hackathon at Community Over Code:** Planning is underway for an in-person hackathon in Glasgow this October, intended to help new contributors get started with curated "good first issues." [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
