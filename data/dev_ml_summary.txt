* **Deprecation of Tensor and SparseTensor:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol, as they are under-implemented across language bindings and better handled by external libraries like NumPy. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal proposal pause:** Active work on the `arrow.big_decimal` canonical extension type is being paused to re-evaluate ecosystem requirements and performance considerations for arbitrary-precision compute. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArrowMetal announcement:** A new project called ArrowMetal was introduced, providing Arrow-native compute kernels for Apple Silicon GPUs through Metal with zero-copy data sharing between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **PR limits for non-committers:** Discussion reached a consensus to limit non-committer contributors to three concurrent open PRs to reduce CI load and help maintainers focus on high-quality submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **File extension type:** A proposal was made for a canonical `arrow.parquet.file` extension type to allow Arrow to represent the new Parquet FILE logical type consistently across IPC streams and language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Variant spec alignment:** Developers are addressing inconsistencies between the Arrow Variant extension and the Parquet shredding spec, specifically regarding the handling of types like unsigned integers and nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Go 18.8.0 Release:** The Go implementation was updated with 283 commits, including improvements to Flight, FlightSQL, and Parquet support, along with fixes for Go 1.27 compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Arrow Glasgow Hackathon:** An Apache Arrow hackathon has been announced for October 13, 2026, during the Community Over Code conference in Glasgow for contributors of all experience levels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20hackathon%20at%20Community%20Over%20Code%20Conference%202026)
