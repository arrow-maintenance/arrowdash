* **IPC Tensor deprecation:** The community has voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to streamline the specification and focus on core columnar formats. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **PR limits for non-committers:** Discussion on implementing a limit of 3 concurrent open pull requests for non-committers to manage review bandwidth and mitigate the influx of AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension proposal:** A proposal for a canonical `arrow.big_decimal` type to improve RDBMS interoperability was discussed and eventually paused to allow for a broader evaluation of compute kernel requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArrowMetal GPU compute:** Announcement of ArrowMetal, a new project providing GPU-accelerated compute kernels for Apple Silicon that uses shared-storage memory for zero-copy interoperability between CPUs and GPUs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **FILE extension type:** Developers are discussing the addition of `arrow.parquet.file` as a canonical extension type to maintain semantic parity with the new FILE logical type in the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Lazy Parquet memory mapping:** A proposal to use custom fault handling for lazy memory mapping of Parquet columns, allowing vectorized operations to run over entire columns without manual row-group management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **ArxLang introduction:** Introduction of Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Major releases for Go and Rust:** Apache Arrow Go 18.8.0 has been released, while the Rust implementation has moved to a release candidate for version 60.0.0. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Community over Code hackathon:** Plans were finalized for an in-person Arrow hackathon in Glasgow this October, focusing on "good first issues" and community collaboration. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
