* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to simplify the format and encourage the use of specialized storage or extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal project announcement:** A new library, ArrowMetal 0.1.0, was introduced to provide Arrow compute kernels for Apple Silicon GPUs via Metal, utilizing shared memory to avoid upload/download overhead. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **PyArrow modularity and wheel splitting:** Developers are discussing a plan to split PyArrow into smaller, modular wheels (e.g., optional `pyarrow[s3]`) to reduce the monolithic package size on PyPI and ease maintenance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** A proposal was made to sunset formal support and CI coverage for macOS Intel (x86_64) due to declining usage and the discontinuation of support from upstream tools like Homebrew. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Apache Arrow Rust 60.0.0 release:** This major release includes initial support for the Adaptive Lossless Floating-Point (ALP) encoding in Parquet, new PageIndex structures, and significant performance enhancements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **AI-generated contribution guidelines:** Discussion is ongoing regarding establishing specific reviewer standards and a "needs-author-engagement" label to handle low-quality AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Canonical Extension Type for FILE type:** A proposal was introduced to define `arrow.parquet.file` as a canonical extension type to represent file references, aligning with the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **BigDecimal extension proposal pause:** Active work on the `arrow.big_decimal` extension has been paused to gather more information and align the proposal with broader ecosystem practices for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)
