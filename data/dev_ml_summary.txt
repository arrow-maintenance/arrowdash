* **Arrow 26.0.0 Release:** The community approved the release of Apache Arrow 26.0.0, resolving over 300 issues across the project's various implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Rust 60.0.0 Release:** Version 60.0.0 of the Rust implementation was released, notably becoming the first Parquet implementation to support the new Adaptive Lossless Floating-Point (ALP) encoding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Dropping macOS Intel support:** A proposal was discussed to drop CI support and binary distribution for Intel-based Macs due to Homebrew deprecating support and declining user statistics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Improving PyArrow modularity:** Developers are working on a proof-of-concept to split PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce package size and manage optional dependencies more effectively. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Canonical Range extension types:** A formal vote is underway to add fixed and variable "closedness" range types to the Arrow canonical extension specifications for better interval handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Handling AI-generated contributions:** The community is establishing new reviewer guidelines and GitHub labels, such as `needs-author-engagement`, to manage low-quality AI-generated PRs and ensure contributors understand their changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **JSON representation of Arrow schemas:** Discussions continued regarding a standardized JSON format for Arrow schemas, including refinements for handling Sparse/Dense Union types and nested structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **ADBC Logo and Identity:** A new logo for the Arrow Database Connectivity (ADBC) subproject was proposed and reached lazy consensus to improve the project's visual identity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)

* **CSV date/time parsing improvements:** A long-standing proposal to allow the CSV reader to use `timestamp_parsers` for explicit date and time columns is moving forward to improve parsing flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2B%20Python%20Getting%20PR%20#50146%20CSV%20date/time%20parsing,%20GH-41488%20reviewed)
