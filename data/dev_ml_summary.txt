* **Deprecating Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to reduce implementation complexity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPU compute:** Announcement of ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple silicon GPUs via Metal with zero-copy memory sharing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Limit on concurrent open PRs for non-committers:** Discussion on implementing a limit of three concurrent open pull requests for contributors without write access to manage an uptick in stale or low-quality AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal paused:** Active work on the `arrow.big_decimal` canonical extension type has been paused to better evaluate ecosystem requirements and the necessity of compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Canonical extension type for FILE type:** Proposal to introduce `arrow.parquet.file`, a canonical extension type designed to align with the recently finalized Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow 25.0.1 and implementation releases:** The community announced the release of Apache Arrow 25.0.1, alongside new versions for the Rust (59.3.0) and Go (18.8.0) implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.1%20released) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **Community growth and new committers:** Tadeja Kadunc, Zehua Zou, and Kosta Tarasov have been invited and accepted roles as new committers for the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Kosta%20Tarasov)

* **Arrow Hackathon at Community Over Code:** Announcement of an Arrow-focused hackathon taking place in Glasgow on October 13, 2026, aimed at both new and experienced contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **ArxLang - Arrow-native programming language:** Introduction of Arx, an experimental language built with Apache Arrow as the native foundation for its runtime data types and data-oriented design. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
