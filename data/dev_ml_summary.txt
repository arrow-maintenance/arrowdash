* **Arrow Rust 60.0.0 release:** Major release of the Rust implementation featuring support for the new ALP encoding and significant performance improvements for Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **ArrowMetal GPU compute:** Introduction of ArrowMetal, a new library enabling Arrow compute kernels to run natively on Apple silicon GPUs using shared-storage Metal memory for zero-copy transfers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation and usage across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArxLang introduction:** Discussion on Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **FILE canonical extension type:** Proposal to introduce `arrow.parquet.file` as a canonical extension type to provide an in-memory Arrow representation that aligns with Parquet's new FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Proposal to establish clear reviewer instructions for handling low-quality or low-engagement PRs that violate the project's AI-generated code policy. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **BigDecimal extension status:** Active work on the `arrow.big_decimal` canonical extension type was paused to allow for a broader re-evaluation of ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Go 18.8.0 release:** The Go implementation version 18.8.0 was released, incorporating nearly 300 commits including updates to the compute registry and improved toolchain compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Lazy memory mapping for Parquet:** Proposal to implement an mmap-like interface that loads Parquet row groups lazily when accessed, hiding row-group boundaries from application code. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Conbench architecture shift:** Discussion on moving the Conbench benchmarking tool toward a storage model based on Parquet files and DuckDB instead of relying solely on Postgres. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)
