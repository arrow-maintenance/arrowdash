* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to streamline the specification and focus on core columnar formats. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **PR limits for non-committers:** Discussion on limiting non-committers to three concurrent open pull requests to manage maintainer workload and mitigate the influx of low-quality or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **ArrowMetal GPU compute:** Announcement of ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple Silicon GPUs through the Metal API using shared-storage memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension type paused:** A proposal to standardize a canonical BigDecimal extension type was paused to re-evaluate requirements for arbitrary-precision compute kernels and ecosystem alignment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Canonical FILE extension type:** Proposal to introduce an `arrow.parquet.file` extension type to provide a standardized in-memory representation for file-level references, matching recent updates to the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Community Over Code hackathon:** Plans were finalized for an Arrow hackathon in Glasgow this October, focusing on onboarding new contributors and addressing a curated list of issues across different language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Variant and Parquet spec alignment:** Developers are discussing inconsistencies between the Arrow Variant extension and the Parquet shredding specification, particularly concerning the handling of unsigned integers and null types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Go and Rust releases:** The project released Apache Arrow Go v18.8.0 and progressed through several release candidates for Arrow Rust v60.0.0 and the Rust Object Store v0.14.2. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **New project committers:** The Arrow PMC announced the addition of three new committers: Tadeja Kadunc, Zehua Zou, and Kosta Tarasov. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
