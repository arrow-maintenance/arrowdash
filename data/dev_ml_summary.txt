* **Apache Arrow 26.0.0 Release:** The community announced the release of version 26.0.0, which includes 337 resolved issues across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Sovereign Tech Fund Investment:** Germany's Sovereign Tech Fund is contracting 1.9 FTEs through 2027 to work on PyArrow type annotations, documentation improvements, and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **AI-Generated Contributions Policy:** Maintainers are discussing new guidelines to handle the surge of AI-generated PRs, including mandatory disclosure and automated drafting of inactive or problematic contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **PyArrow Modularity Improvements:** Discussion on reducing the PyArrow package size by splitting it into smaller, modular sub-packages to make it more lightweight for downstream users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **GitHub Actions CI Optimization:** A proposal to reduce Arrow's GitHub Actions usage by 30-40% through better path filtering, scheduled "canary" runs, and optimizing nightly failure reports. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **Apache Arrow ADBC 25 Release:** The ADBC subproject released version 25, featuring significant updates for the C++, C#, Java, R, and Rust implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **IBM Db2 ADBC Driver:** IBM engineers proposed contributing a native C++ ADBC driver for IBM Db2 (LUW) to the Apache Arrow ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Canonical Extension Range Types:** A proposal to add fixed and variable closedness range types as canonical extension types, allowing standardized representation of mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC Representation for Dictionary-Encoded Extensions:** Discussion and draft PRs aimed at allowing IPC to represent extension type metadata on dictionary-encoded values, matching the capabilities of the C Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait Dialects:** Proposal to allow Flight SQL servers to advertise their supported Substrait dialects via SqlInfo, enabling clients to verify compatibility before plan execution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)
