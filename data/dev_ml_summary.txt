* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol because they are largely unused outside of the C++ implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal 0.1.0 announcement:** Introduction of a new project providing Arrow compute kernels for Apple silicon GPUs through Metal, allowing arrays to exist simultaneously as valid CPU and GPU buffers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Dropping macOS Intel support:** Discussion on sunsetting CI support for Intel-based Macs as Homebrew and Apple move toward ARM-only support, making maintenance of x86_64 macOS environments difficult. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel splitting:** Proposal to break down PyArrow into multiple wheels (e.g., `pyarrow` and `pyarrow-s3`) to reduce the monolithic package size, which currently totals over 2GB for a full release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **New Canonical Extension Types:** Developers proposed `arrow.parquet.file` to align with Parquet’s new FILE logical type and reached a consensus on the design for an `arrow.range` type for bounded ranges. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer protocols for low-quality AI PRs, including a proposed "needs-author-engagement" label to flag contributors who do not meaningfully interact with feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Arrow Rust 60.0.0 release:** A major release featuring support for the new Adaptive Lossless Floating-Point (ALP) encoding in Parquet and significant performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Arrow Go 18.8.0 release:** The latest Go library release includes 283 commits across Arrow, Flight, and Parquet, following several RC iterations to fix Go 1.27 compatibility issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Go%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)
