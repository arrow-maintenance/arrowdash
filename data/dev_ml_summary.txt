* **ArrowMetal announcement:** Introduction of ArrowMetal, a new project providing Arrow compute kernels for Apple silicon GPUs via Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Arrow Rust 60.0.0 release:** Major release of the Rust implementation featuring Parquet ALP encoding support and widespread kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Apache Arrow 26.0.0 RC0:** Release candidate voting opened for version 26.0.0, covering over 330 resolved issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity improvements:** Proposal to split the monolithic PyArrow package into multiple smaller wheels (e.g., pyarrow-s3) to reduce download sizes and installation burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official support and CI testing for macOS Intel (x86_64) due to low usage and Homebrew's deprecation of the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** Vote on adding two new canonical extension types, arrow.fixed_closedness_range and arrow.variable_closedness_range, to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Tensor deprecation in IPC:** The community voted to informally deprecate Tensor and SparseTensor types within the IPC format and C++ API. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer protocols for AI-generated code, including the introduction of a "needs-author-engagement" label to flag low-effort PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **JSON schema representation:** Continued effort to standardize a JSON representation for Arrow schemas to facilitate sharing data definitions across different ecosystems. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Go 18.8.0 release:** Release of Apache Arrow Go v18.8.0, including 283 commits across Arrow, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Go%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)
