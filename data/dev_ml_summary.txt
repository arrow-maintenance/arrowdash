* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, which resolves over 300 issues and includes various improvements across C++, Python, and other language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **PyArrow modularity improvements:** Developers are discussing ways to split PyArrow into smaller, more modular packages to reduce the library's disk footprint and make it a more viable dependency for downstream projects. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Sovereign Tech Fund investment:** The German government-backed Sovereign Tech Fund is financing a major development effort for PyArrow through 2027, focusing on type annotations, documentation, and improved extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI infrastructure optimization:** A proposal aims to reduce GitHub Actions runner usage by up to 40% through workflow optimizations, including better path filtering and the migration of certain tasks to self-hosted runners. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20~30-40%25%20fewer%20runner%20minutes)

* **Range canonical extension types:** The community is voting on adding two new canonical extension types to represent mathematical intervals (fixed and variable closedness ranges). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **AI-generated contribution policy:** Discussion continues regarding the influx of AI-generated PRs, with new recommendations to mandate AI disclosure and implement automated triage for low-engagement contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **IPC for dictionary-encoded extension types:** A proposal suggests adding custom metadata to the DictionaryEncoding message to allow Arrow's IPC format to fully represent dictionary-encoded extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Apache Arrow ADBC 25 release:** The ADBC subproject released version 25, which includes various driver updates and a new native C++ driver for IBM Db2. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2025%20Released)

* **Flight SQL Substrait dialect advertising:** A new proposal would allow Flight SQL servers to advertise specifically which Substrait types and relations they support using dialect files and SqlInfo codes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Brotli security patch (26.0.1):** Work is underway for a 26.0.1 patch release to address a security vulnerability (CVE-2026-111497) by updating the statically linked Brotli library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20GH-55165%20in%2026.0.1)
