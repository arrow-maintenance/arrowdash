* **Arrow 26.0.0 release:** The community approved the release of version 26.0.0, which resolves over 300 issues across the C++, Python, and core implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and wheel splitting:** Proposal to split PyArrow into several optional packages (e.g., pyarrow-s3) to reduce the binary size on PyPI and alleviate installation friction for users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official support and CI coverage for x86_64 macOS as platform providers and package managers like Homebrew shift focus to Apple Silicon. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contributions policy:** Proposal to introduce a "needs-author-engagement" label to manage PR quality and ensure that contributors using generative AI tools fully understand and can maintain their submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Canonical Range extension types:** A vote on adding new "fixed-closedness" and "variable-closedness" range types to the Arrow canonical extension specification for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary extension types:** Technical discussion and draft implementation for allowing the Arrow IPC format to support custom metadata on dictionary value types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM announced the completion of a native C++ ADBC driver for Db2 (LUW) and requested to contribute it to the official Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertising:** Proposal to allow Flight SQL servers to advertise supported Substrait dialects via SqlInfo, helping clients determine plan compatibility before execution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)
