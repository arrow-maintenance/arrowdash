* **AI-generated contributions:** Discussion on establishing reviewer guidelines for handling low-quality PRs and introducing a "needs-author-engagement" label for contributors who fail to respond to technical feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **macOS Intel support:** Proposal to drop official CI support for macOS on Intel (x86_64) due to increasing maintenance challenges and Homebrew's transition away from Intel bottles. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity:** Exploration of a multi-wheel installation strategy to reduce the size of PyArrow by making heavy components like S3, GCS, and Azure optional side-packages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Range extension types:** Discussion and voting on new canonical extension types (`arrow.fixed_closedness_range` and `arrow.variable_closedness_range`) to represent bounded intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)

* **JSON representation of Arrow schemas:** Discussion on standardizing a JSON format for schemas to facilitate data contracts in configuration files and cross-process data interchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Arrow 26.0.0 release:** The community passed the vote for version 26.0.0, which includes over 300 resolved issues across the C++, Python, and documentation components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0:** Major release of the Rust implementation featuring new Parquet encoding support, kernel performance improvements, and an effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Dictionary-encoded extension types:** Draft PRs have been submitted to allow IPC to represent dictionary-encoded extension types by adding metadata support to the DictionaryEncoding format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 ADBC driver:** IBM proposed the contribution of a native C++ ADBC driver for Db2 (LUW) to expand the current ADBC driver ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
