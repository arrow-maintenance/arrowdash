* **Apache Arrow 26.0.0 Release:** The community has released version 26.0.0, which resolves over 300 issues including verification fixes for Python 3.15 and Windows builds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **PyArrow Modularity and Multi-wheel Support:** A proposal and proof-of-concept are under discussion to split PyArrow into multiple wheels, allowing optional components like S3 and GCS to be installed separately to reduce the core package size. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Deprecation of macOS Intel Support:** Developers are moving to drop official support for macOS on Intel hardware due to CI maintenance challenges and the cessation of support for Intel bottles by Homebrew. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Dictionary-Encoded Extension Types in IPC:** A format change has been proposed to allow the Arrow IPC format to represent extension types when they are dictionary-encoded by adding custom metadata to the DictionaryEncoding message. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Arrow Rust 60.0.0 Release:** The Rust implementation reached version 60.0.0, featuring new Parquet encoding support, kernel performance optimizations, and a major effort to eliminate panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical Range Extension Types:** A vote is active to introduce fixed-closedness and variable-closedness range types as new canonical extension types in the Arrow format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Substrait Dialect Advertising in Flight SQL:** This proposal suggests adding new SqlInfo codes to Flight SQL to allow servers to advertise their specific supported Substrait dialect using standard YAML documents. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSqlInfo%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC Driver Contribution:** IBM developers have proposed contributing a native C++ ADBC driver for IBM Db2 (LUW) to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON Representation of Arrow Schemas:** Discussion is ongoing regarding a standardized JSON format for Arrow schemas to facilitate data contracts in configuration files, including support for Union and nested types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)
