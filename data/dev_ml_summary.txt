* **JSON representation of Arrow schemas:** Discussion on a draft specification for a standardized JSON representation of schemas, including proposals for supporting complex types like unions and nested structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **AI-generated contribution guidelines:** Proposal to add reviewer-specific guidelines for handling low-quality AI PRs, including a potential "needs-author-engagement" GitHub label to flag insufficient developer interaction. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Dropping macOS Intel support:** The community is moving to drop official CI support for macOS Intel due to Homebrew deprecations and maintenance burdens, transitioning Intel support to a best-effort source-build basis. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Improving modularity of PyArrow:** A proof-of-concept is underway to split PyArrow into multiple wheels (e.g., a core package and optional side-wheels for S3 or GCS) to significantly reduce the installation footprint. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 release:** The project successfully released version 26.0.0, resolving over 300 issues across various components including C++, Python, and documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Canonical extension types for ranges:** A formal vote is open for adding fixed and variable closedness range types to the canonical extension specifications to better support interval data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM has proposed contributing a native C++ ADBC driver for Db2 (specifically for Linux, UNIX, and Windows) to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **ADBC subproject visual identity:** The community has reached lazy consensus on a new logo and visual identity for the ADBC (Arrow Database Connectivity) subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)

* **CSV date and time parsing improvements:** Discussion on merging long-standing PRs to improve CSV reader flexibility, allowing the use of custom timestamp parsers as fallbacks for date types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Getting%20PR%20%2350146%20CSV%20date/time%20parsing%2C%20GH-41488%20reviewed)
