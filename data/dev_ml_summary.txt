* **Apache Arrow 26.0.0 release:** The community announced the major release of version 26.0.0, which includes 337 resolved GitHub issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed Sovereign Tech Agency has contracted work for PyArrow to fund maintenance, type annotations, and improved documentation through 2027. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI optimization for GitHub Actions:** Developers discussed strategies to reduce GitHub Actions runner usage by 30-40%, including disabling certain workflows on every merge and moving bot jobs to smaller runners. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%28~30-40%25%20fewer%20runner%20minutes%29)

* **Handling AI-generated contributions:** The community is refining policies for AI-generated PRs, including mandatory disclosure, rules against AI-written review replies, and automatic drafting of idle PRs to reduce maintainer burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Canonical Range extension types:** A vote was held on adding fixed and variable closedness range types to the Arrow canonical extension types to better support mathematical intervals and PostgreSQL-style ranges. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Dictionary-encoded extension types in IPC:** A proposal and implementation are underway to allow the IPC format to represent dictionary-encoded extension types by adding custom metadata to the DictionaryEncoding field. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **ADBC 25 release and IBM Db2 contribution:** The ADBC subproject released version 25 and received a proposal from IBM to contribute a new native C++ driver for IBM Db2 (LUW). [Thread 1](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2) [Thread 2](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertisement:** Discussion on adding new SqlInfo codes to Flight SQL to allow servers to advertise exactly which Substrait dialects and relations they support for query plans. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Security patch for Brotli CVE:** The community is preparing a 26.0.1 patch release to address a vulnerability (CVE-2026-111497) in the statically linked Brotli library used by PyArrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20%28GH-55165%29%20in%2026.0.1)

* **BenchDB and Conbench status:** Discussion regarding the future of the Conbench benchmarking project and a proposal to migrate to BenchDB, a Go-based port for tracking performance results. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)
