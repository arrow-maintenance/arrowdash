* **Apache Arrow 25.0.0 and 25.0.1 releases:** Major release 25.0.0 was announced with over 200 issues resolved, followed shortly by patch release 25.0.1 to address critical regressions in nested type conversions and Gandiva time zone handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Windows Arm64 support for PyArrow:** Microsoft and Linaro proposed a plan to add and maintain official win_arm64 support, offering dedicated engineering resources and CI hardware to resolve build consolidation and wheel size concerns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSPythonCI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Semantics of non-nullable fields:** A technical discussion was opened regarding the interpretation of the "nullable" flag in IPC format when dealing with non-trivial structures, such as non-nullable child fields within a null parent struct. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Apache Arrow ADBC 24 release:** Version 24 of the Arrow Database Connectivity (ADBC) libraries was released, featuring a documentation overhaul to better explain the distinction between ASF-maintained and vendor-provided drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Swift 6.0 requirement proposal:** Maintainers discussed raising the minimum Swift version to 6.0 for the Swift implementation to leverage native Int128 support for high-precision decimal arithmetic. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension and Parquet shredding alignment:** Developers identified inconsistencies between the Arrow Variant extension specification and the Parquet shredding spec, proposing updates to ensure unsigned integers and nulls round-trip correctly. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **nanoarrow 0.9.0 release:** The lightweight C-language implementation of Arrow, nanoarrow, reached version 0.9.0, including significant updates to its Python and R bindings and improved integration with CMake. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC member appointment:** Jeffrey Vo (Jefffrey) has been appointed as a new member of the Apache Arrow Project Management Committee (PMC) for his contributions across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
