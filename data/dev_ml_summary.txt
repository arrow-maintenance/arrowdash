* **PyArrow modularity split:** Proposal to split PyArrow into multiple wheels (e.g., `pyarrow[s3]`) to reduce the monolithic package size and allow optional dependencies for specific cloud providers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **ArrowMetal 0.1.0 announcement:** Introduction of a new project providing Arrow compute kernels for Apple silicon GPUs through Metal, featuring zero-copy shared memory and support for over 300 compute functions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Dropping macOS Intel support:** Discussion on ending support for macOS x86_64 due to Homebrew's deprecation and low usage metrics, which currently account for roughly 0.1% of PyArrow downloads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** Formal vote to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` types to the Arrow specification to standardize bounded interval data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Tensor IPC deprecation:** The community voted to informally deprecate Tensor and SparseTensor within the IPC format and Flatbuffers definitions in favor of better-maintained alternatives. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Reviewer guidelines for AI contributions:** Discussion on establishing procedures for reviewers to handle low-quality AI-generated PRs, including a "needs-author-engagement" label and escalation paths for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Arrow 26.0.0 release candidate:** Voting has commenced for the 26.0.0 release candidate, covering over 300 resolved issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 release:** A major update for the Rust implementation was released, introducing support for the new Parquet Adaptive Lossless Floating-Point (ALP) encoding and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **JSON schema representation:** Continued refinement of a standardized JSON representation for Arrow schemas to simplify cross-platform data contracts and configuration management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)
