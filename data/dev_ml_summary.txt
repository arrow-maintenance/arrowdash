* **Windows Arm64 support for PyArrow:** Microsoft proposed a funded plan to add Windows Arm64 support, which includes engineering resources to implement abi3 wheels and consolidate the Windows build path. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limits on concurrent open PRs:** Proposal to limit non-committers to a small number of concurrent pull requests (e.g., three) to mitigate the impact of stale, AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Swift 6.0 minimum version:** Discussion on raising the minimum Swift requirement to 6.0 to leverage native Int128 support, which is essential for high-precision Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant and Parquet shredding inconsistency:** Proposal to align the Arrow Parquet Variant extension with the Parquet shredding spec by disallowing types, like unsigned integers, that lack a valid Parquet representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **BigDecimal canonical extension type:** A vote was initiated for a new `arrow.big_decimal` extension to handle variable-scale numeric data, though some maintainers expressed concerns regarding the current representation's consensus. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Arrow 25.0.1 maintenance release:** This patch release includes fixes for nested type performance in Python and resolves timezone-related test failures in the Gandiva engine. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **ADBC 24 release:** The Arrow Database Connectivity (ADBC) subproject released version 24, resolving 55 issues including critical fixes for Windows JNI artifact linking. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC1)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language that uses Apache Arrow as its native data foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
