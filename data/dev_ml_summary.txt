* **BigDecimal extension pause:** The proposal for a canonical `arrow.big_decimal` extension was paused to better evaluate compute kernel requirements and align with existing ecosystem practices for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Ivan Ogasawara introduced Arx, an experimental programming language designed with Apache Arrow as its native foundation for data-oriented runtime and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **IPC Tensor deprecation:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation support and to focus on more widely used features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Parquet lazy memory mapping:** Discussion on a proposal to load Parquet row groups lazily using custom fault handling, which could allow exposing columns as zero-copy NumPy arrays for vectorized operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ParquetCPython%20Lazy%20memory%20mapping)

* **New File extension type:** A proposal was made to add `arrow.parquet.file` as a canonical extension type to provide an in-memory representation matching the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArrowMetal announcement:** Developers introduced ArrowMetal 0.1.0, a new project providing Arrow compute kernels that run on Apple silicon GPUs through Metal with zero-copy memory shared with the CPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **AI-generated contribution guidelines:** Discussion is underway to establish reviewer guidelines for identifying and escalating low-effort or AI-generated pull requests that fail to meet community engagement standards. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Rust and Go releases:** Major releases were finalized this month, including Arrow Go 18.8.0 and Arrow Rust 60.0.0, the latter featuring support for the new ALP encoding and Parquet PageIndex improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)
