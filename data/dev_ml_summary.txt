* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol and will encourage implementations to remove associated APIs to simplify the format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation was approved, featuring support for the new Adaptive Lossless Floating-Point (ALP) encoding in Parquet and new Parquet PageIndex structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **ArrowMetal announcement:** Introduction of a new project that provides Arrow compute kernels for Apple Silicon GPUs through Metal, utilizing shared-storage memory for zero-copy interchange across multiple languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **FILE Canonical Extension Type:** Proposal to add an `arrow.parquet.file` extension type to the Arrow specification to maintain parity with Parquet’s FILE logical type for representing file-level references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Discussion on establishing formal reviewer guidelines for handling low-quality or non-compliant AI-generated pull requests, including escalation paths for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **BigDecimal extension status:** Work on the `arrow.big_decimal` extension proposal has been paused to re-evaluate ecosystem requirements and compute kernel support for arbitrary-precision types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Go 18.8.0 release:** The community released version 18.8.0 of the Go libraries, which includes 283 commits covering updates to Arrow, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Conbench benchmarking infrastructure:** Proposal to overhaul the project's benchmarking data storage to use Parquet and DuckDB while streamlining the UI to better serve different sub-projects. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)
