* **Apache Arrow 26.0.0 release:** The community approved the release of version 26.0.0, which includes 337 resolved GitHub issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 release:** This major release features support for the new Parquet ALP encoding, PageIndex structures, and significant performance improvements for compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%2060.0.0%20RC1)

* **PyArrow modularity and multi-wheel support:** Discussion on splitting PyArrow into smaller, optional wheels (e.g., `pyarrow-s3`) to reduce the package size on PyPI and simplify installation for users with specific needs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Reviewer guidelines for AI-generated code:** Proposal to establish formal handling for low-quality AI contributions, including a new "needs-author-engagement" GitHub label for PRs where the author shows limited understanding or engagement. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Deprecating macOS Intel support:** The community is moving toward dropping support for macOS Intel (x86_64) due to Homebrew deprecations and the increasing difficulty of maintaining CI for older Apple hardware. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** A vote is underway to introduce `fixed_closedness_range` and `variable_closedness_range` extension types to provide standardized representation for mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Continued refinement of a standardized JSON format for Arrow schemas to support cross-process data contracts and interoperability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **ADBC logo and visual identity:** The ADBC subproject is finalizing its branding and visual identity, with a new logo proposal nearing adoption via lazy consensus. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)
