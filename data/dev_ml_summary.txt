* **Windows ARM64 support for PyArrow:** A proposal was submitted to add official `win_arm64` wheel support, including engineering commitments from Microsoft and Linaro to maintain CI and provide hardware for debugging. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol, encouraging implementations to move away from these types due to limited cross-language support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Limits on concurrent PRs for non-committers:** Discussion on limiting non-committers to three concurrent open pull requests to address an uptick in stale, low-value, or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal paused:** Active work on the `arrow.big_decimal` canonical extension type has been paused to better evaluate ecosystem requirements for arbitrary-precision numerics and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language that uses Apache Arrow as its native foundation for data runtimes, arrays, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Canonical Extension Type for FILE:** A new proposal aims to standardize an `arrow.parquet.file` extension type to represent file-level references, matching recent additions to the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow 25.0.1 release:** The project successfully released version 25.0.1, a patch release addressing nine issues including performance improvements for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **New Project Committers:** The Apache Arrow PMC announced three new committers this month: Tadeja Kadunc, Zehua Zou, and Kosta Tarasov. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)

* **Conbench benchmarking evolution:** Discussion on refactoring the Conbench benchmarking platform, including moving toward a Parquet-based storage layer and improving the UI for better human-in-the-loop performance analysis. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **Lazy memory mapping for Parquet:** Proposal to use custom fault handling to lazily map Parquet columns to NumPy-like interfaces, allowing vectorized operations over entire columns without manual row-group handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)
