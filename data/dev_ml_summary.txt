* **Windows on Arm support for PyArrow:** Engineers from Microsoft and Linaro proposed a plan to support the `win_arm64` platform, offering dedicated maintenance, hardware for maintainers, and assistance with consolidating Windows build paths. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Proposed limit on concurrent PRs:** Discussion on limiting non-committers to three open pull requests to manage an influx of stale or AI-generated contributions and ensure timely feedback cycles. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Apache Arrow 25.0.1 release:** The community approved and released version 25.0.1, a patch release addressing nine issues including significant performance optimizations for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **BigDecimal extension type proposal:** A vote for a canonical `BigDecimal` extension type was paused to allow for broader discussion on memory layout performance and compute kernel requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language built with Apache Arrow as its native foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** Proposal to use custom page fault handling to map Parquet columns lazily, enabling vectorized operations over entire columns while loading row groups only when accessed. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Rust implementation releases:** The Rust implementation saw two releases (59.2.0 and 59.3.0) to address various bugs and improve consistency across the crate ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)

* **Nanoarrow 0.9.0 release:** Version 0.9.0 of the nanoarrow implementation was released, including 38 resolved issues and a new draft blog post highlighting its features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Community governance updates:** The project welcomed Jeffrey Vo as a new PMC member, while Tadeja Kadunc and Zehua Zou were invited to join as new committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
