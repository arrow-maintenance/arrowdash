* **ArrowMetal 0.1.0 announcement:** Introduction of ArrowMetal, which provides compute kernels for Apple silicon GPUs via Metal, utilizing the C Device Data Interface for zero-copy sharing across multiple languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Deprecation of Tensor types in IPC:** The community voted to informally deprecate Tensor and SparseTensor in the IPC format to focus maintenance efforts on more widely used components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULTVOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Improved PyArrow modularity:** Proposal for a multi-wheel installation approach for PyArrow to reduce package size on PyPI by making large components like S3 support optional side-wheels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending support for Intel-based macOS as the ecosystem and CI providers shift focus toward ARM-based runners, making maintenance of x86_64 binaries difficult. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Reviewer guidelines for AI contributions:** Efforts to establish clear protocols for reviewers to handle low-quality AI-generated contributions, including the use of a "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Canonical range extension types:** Formal vote to standardize `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` extension types for representing bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Continued design discussion on a standardized JSON format for Arrow schemas to facilitate data contract definitions and interoperability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20JSON%20representation%20of%20Arrow%20schemas)

* **Apache Arrow Rust 60.0.0 release:** Major release of the Rust implementation featuring new support for ALP encoding in Parquet and significant performance improvements for compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Apache Arrow 26.0.0 release cycle:** Voting has commenced for the first release candidate of Arrow 26.0.0, which addresses over 300 resolved issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)
