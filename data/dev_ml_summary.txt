* **Deprecating Tensor and SparseTensor IPC messages:** Proposal to deprecate the experimental Tensor and SparseTensor IPC messages in favor of using the newer FixedShapeTensor and VariableShapeTensor canonical extension types within RecordBatches. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DiscussIPC%20Deprecate%20Tensor%20and%20SparseTensor%20messages%3F)

* **JSON representation for Arrow schemas:** Discussion on establishing a canonical human-readable JSON format for Arrow schemas to simplify authoring and use in REST API contracts and ADBC metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Apache Arrow 25.0.0 Release:** The community completed the release of version 25.0.0, resolving over 220 issues across the project; a patch release 25.0.1 is being considered to address performance regressions in Spark UDF serialization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **Field name nul-byte handling in C FFI:** Investigation into how the C Data Interface handles nul bytes in field names, with a consensus that producers should error out to avoid round-trip failures or crashes in consumers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **ADBC 24 Release and Documentation:** Release 24 of the ADBC libraries is now available, featuring an overhauled documentation site and improved clarity regarding vendor-developed drivers versus ASF-maintained ones. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Swift 6.0 Upgrade Proposal:** Proposal to increase the minimum Swift version to 6.0 for the Swift implementation to leverage native `Int128` support, which is a required building block for Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Nullability semantics for non-trivial types:** Technical debate on the meaning of the `nullable` flag for nested structures, such as how to interpret a non-nullable child field when the parent struct contains nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant extension spec alignment:** Identification of inconsistencies between Arrow's Variant extension and the Parquet Variant shredding spec, specifically regarding the support for unsigned integer types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)
