* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor-related messages in the IPC protocol to simplify the specification and focus on core columnar data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Canonical Extension Type for FILE type:** Proposal to define `arrow.parquet.file` as a canonical extension type to match the Parquet FILE LogicalType, facilitating standardized file-level references across language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArrowMetal 0.1.0 release:** Announcement of a new project that provides Arrow compute kernels for Apple Silicon GPUs via Metal, enabling shared-memory data processing without CPU-to-GPU uploads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Apache Arrow Go 18.8.0 release:** This release includes 283 commits from 16 contributors, covering updates to the core library, Flight, FlightSQL, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation featuring new Parquet ALP encoding support, PageIndex structures, and significant performance improvements in kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Dropping macOS Intel support:** Discussion on deprecating support for macOS on x86_64 hardware following Homebrew's decision to stop providing bottles for Intel-based Macs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel sizes:** Proposal to split PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the 2.1 GB monolithic installation size on PyPI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **AI-generated contribution guidelines:** Discussion on improving reviewer workflows for handling low-quality AI-generated PRs, including a proposed "needs-author-engagement" label for flagging weak engagement. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **JSON representation of Arrow schemas:** Ongoing discussion regarding the standardization of a JSON format for schemas to improve data contract definitions and inter-process metadata exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)
