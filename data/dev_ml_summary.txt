* **Arrow 25.0.1 release:** A patch release resolving nine issues, including significant performance improvements for Python's `to_pylist()` on nested types and fixes for timezone handling in Gandiva. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Windows Arm64 support for PyArrow:** Microsoft engineers proposed a plan to provide official Windows on Arm64 wheels, offering engineering time for build consolidation and ABI3 work as prerequisites. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limiting concurrent PRs:** To address an increase in stale and AI-generated contributions, the community is discussing a policy to limit non-committers to three concurrent open pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal extension type:** Discussion on a new extension type to represent variable-scale decimal data from RDBMS sources like PostgreSQL and Oracle without losing precision. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Presentation of an experimental programming language built with Arrow as its native foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Apache Arrow ADBC 24 release:** Announcement of the latest ADBC release, featuring 57 bug fixes and improvements across database access abstractions for analytical applications. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Variant extension spec alignment:** Proposed changes to the Arrow documentation to ensure consistency with the Parquet shredding specification, specifically regarding the handling of unsupported types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Lazy memory mapping for Parquet:** Proposal for a custom fault-handling library that allows Parquet columns to be mapped as lazy, zero-copy NumPy arrays, hiding row-group boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **New community members:** The project announced the addition of Jeffrey Vo to the PMC and welcomed Tadeja Kadunc and Zehua Zou as new committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)

* **Arrow Hackathon at Community Over Code:** Plans were finalized for an in-person hackathon in Glasgow on October 13, focusing on documentation and code tasks for new contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
