* **Deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol and will begin encouraging implementations to remove related APIs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal project announcement:** Introduction of ArrowMetal, a new library providing Arrow compute kernels for Apple silicon GPUs that enables zero-copy data sharing between CPU and GPU via the C Device Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension proposal paused:** Work on standardizing a canonical BigDecimal extension type has been paused to better evaluate compute kernel requirements and existing ecosystem practices for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Go 18.8.0 release:** The Go implementation reached version 18.8.0, resolving build issues with Go 1.27 and updating internal dependencies for better compatibility with newer toolchains. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **FILE canonical extension type:** A new proposal suggests a `arrow.parquet.file` extension type to provide a standardized in-memory representation for file-level references that aligns with the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers introduced Arx, an experimental data-oriented programming language designed to use Apache Arrow as its native foundation for types and runtime execution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **PR limits for non-committers:** Discussion concluded with a decision to implement a limit of three concurrent open pull requests for non-committer contributors to help manage maintainer review capacity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Arrow Rust 60.0.0 release candidate:** The Rust implementation is currently voting on version 60.0.0, representing the latest major milestone for the standalone Rust crates. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Lazy memory mapping for Parquet:** A proposal explores using a "faultcache" approach to map Parquet columns to memory lazily, allowing for vectorized operations over entire columns without explicit row-group handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **New Project Committers:** The PMC announced the addition of Zehua Zou and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou)
