* **Informal deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation across languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal GPU compute kernels:** Announcement of ArrowMetal 0.1.0, providing Arrow compute kernels that run directly on Apple silicon GPUs via Metal with no data upload/download required. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer guidelines for handling low-quality AI PRs, including a proposed "needs-author-engagement" label for flagging weak understanding of code changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **PyArrow modularity and wheel splitting:** Proposal to split PyArrow into multiple optional wheels (e.g., `pyarrow[s3]`) to reduce the monolithic 2.1GB total release size and simplify installations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official support for macOS Intel (x86_64) due to Homebrew deprecations and the increasing difficulty of maintaining CI coverage for older hardware. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation featuring the first Parquet implementation of ALP encoding and new Parquet PageIndex structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Canonical Extension Type for FILE type:** Proposal for an `arrow.parquet.file` extension type to allow Arrow to preserve the semantic metadata of Parquet's FILE logical type during IPC and serialization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Big_decimal extension status:** Active work on the `arrow.big_decimal` proposal has been paused to re-evaluate ecosystem practices and requirements for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **New Committer announcement:** Kosta Tarasov has been invited and accepted to become a committer on the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
