* **Limit on concurrent open PRs for non-committers:** The community is discussing a policy to limit contributors without write access to three concurrent open pull requests to manage an influx of AI-generated and stale contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal:** A proposal for a canonical `arrow.big_decimal` extension type was paused to further evaluate physical representation trade-offs and compute kernel requirements across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor and SparseTensor in IPC:** A formal vote passed to informally deprecate Tensor and SparseTensor messages within the IPC protocol, encouraging implementations to move toward extension types for these structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Developers introduced ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple Silicon GPUs via Metal with zero-copy data sharing between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical Extension Type for FILE type:** There is a new proposal to define `arrow.parquet.file` as a canonical extension type to represent file-level references, maintaining alignment with the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers presented Arx, an experimental programming language that uses Apache Arrow as its native foundation for data-oriented runtimes and data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** A proposal was made to use custom fault handling to map Parquet column address ranges lazily, enabling large datasets to be treated as zero-copy NumPy arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **New Committers:** The Project Management Committee announced the addition of Tadeja Kadunc, Zehua Zou, and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Arrow 25.0.1 and Go 18.8.0 Releases:** The community announced the release of Apache Arrow 25.0.1 and Apache Arrow Go v18.8.0, addressing several bugs and improving stability across the libraries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.1%20released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20Go%20v18.8.0%20Released)
