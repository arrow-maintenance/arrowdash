* **Arrow 25.0.0 release:** The community announced the release of version 25.0.0, which resolves over 200 issues across the ecosystem since the last major release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Semantics of non-nullable fields:** Discussion regarding how the IPC format's `nullable` flag should be interpreted for complex types like nested structs and dictionaries, particularly when parent nulls logically imply child nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Windows Arm64 support for PyArrow:** Microsoft engineers proposed a plan to enable Windows on Arm builds, offering dedicated engineering time and hardware to the PMC to help maintain the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **ADBC 24 release and documentation:** The Arrow Database Connectivity (ADBC) subproject released version 24 and implemented a major documentation overhaul to clarify the distinction between ASF and vendor-developed drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Documentation%20overhauled%20for%20ADBC)

* **Variant extension spec inconsistency:** Contributors identified a discrepancy between the Arrow Variant extension and the Parquet Variant shredding spec regarding support for unsigned integer types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift 6.0 minimum version proposal:** Proposal to move the Swift implementation's minimum version to 6.0 to utilize native `Int128` support for decimal types and improved concurrency safety. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **JSON representation of Arrow schemas:** Discussion on how to practically implement inline JSON for extension types (like GeoArrow) in the schema representation without creating "escaped-JSON-in-JSON" issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Nanoarrow 0.9.0 release:** Approval of version 0.9.0 for the nanoarrow subproject, including various fixes and feature improvements for C, Python, and R bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC member:** Jeffrey Vo (Jefffrey) was invited to and accepted a position on the Apache Arrow Project Management Committee. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
