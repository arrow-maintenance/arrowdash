* **Arrow 25.0.1 patch release:** The community released version 25.0.1, resolving nine issues including improvements to nested type conversions and fixes for timezone-sensitive tests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **Windows Arm64 support for PyArrow:** Microsoft proposed a plan to provide `win_arm64` wheels, involving the use of `abi3` to manage package size and a commitment to maintain the necessary CI infrastructure. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Proposed limit on concurrent PRs:** To manage an increase in stale or AI-generated contributions, developers discussed limiting non-committers to three concurrent open pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal canonical extension type:** A proposal for an `arrow.big_decimal` type to represent variable-scale numeric data (like PostgreSQL NUMERIC) is being debated, focusing on memory layout and compute performance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed with Arrow as its native foundation for data-oriented runtimes and memory management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant and Parquet spec alignment:** Discussion continues on resolving inconsistencies between the Arrow Variant extension and the Parquet shredding specification, particularly regarding unsupported types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Major subproject releases:** Several subprojects reached new versions, including ADBC 24 (containing 57 bug fixes), nanoarrow 0.9.0, and Arrow Rust 59.2.0. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Community growth:** The project announced Jeffrey Vo as a new PMC member, while Tadeja Kadunc and Zehua Zou were invited to become committers following their significant contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
