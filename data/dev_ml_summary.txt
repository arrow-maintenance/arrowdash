* **Arrow 26.0.0 release:** Voting is underway for the latest major release, which includes over 300 resolved issues and improved verification scripts for Python 3.15. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity proposal:** Developers are discussing splitting PyArrow into multiple wheels to reduce the monolithic ~2GB package size and allow optional installation of components like S3 and GCS support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** A proposal was made to deprecate x86_64 macOS support due to CI maintenance difficulties and Homebrew's decision to stop providing bottles for Intel-based Macs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** The community is refining policies for reviewers to handle low-quality AI-generated PRs, including a proposed "needs-author-engagement" label to flag lack of meaningful contributor interaction. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **New range canonical extension types:** A vote is open to add `fixed_closedness_range` and `variable_closedness_range` extension types to the official format for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Arrow Rust 60.0.0 release:** The Rust implementation has reached version 60.0.0, featuring new Parquet encoding support and significant performance optimizations for kernels and FFI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Native IBM Db2 driver for ADBC:** IBM contributors have proposed a new native C++ ADBC driver for Db2 LUW to be integrated into the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Dictionary-encoded extension types in IPC:** A proposal to allow extension type metadata on dictionary values within the IPC format to better support complex types like UUIDs and spatial geometries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)
