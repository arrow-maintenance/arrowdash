* **Tensor and SparseTensor deprecation:** The community voted to informally deprecate Tensor and SparseTensor-related IPC messages to focus on core columnar data and reduce maintenance for unused features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal announcement:** Introduction of ArrowMetal 0.1.0, which enables Arrow compute kernels to run natively on Apple silicon GPUs via Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **FILE canonical extension type:** Proposal to add a matching extension type for the new Parquet `FILE` LogicalType, allowing Arrow to natively represent file-level references including URIs, offsets, and checksums. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **BigDecimal extension proposal paused:** Active work on standardizing the `arrow.big_decimal` extension was paused to re-evaluate how various tools in the ecosystem handle arbitrary-precision numerics and compute requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Concurrent PR limits for non-committers:** Discussion on implementing a limit (likely three) on concurrent open pull requests for non-committers to manage reviewer workload and mitigate low-quality or AI-generated submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Refactoring Conbench and benchmarking infrastructure:** Proposal to modernize the Conbench project by moving toward a Parquet-based storage model and DuckDB-driven queries for better performance and flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language built with Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** Technical discussion on using custom fault handling to map address ranges lazily to Parquet content, allowing entire columns to be treated as NumPy-like arrays without explicit row-group management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Community over Code 2026 Hackathon:** Planning for an Arrow hackathon in Glasgow (October 13), where contributors can collaborate on "good first issues" and documentation in person. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
