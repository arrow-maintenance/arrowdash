[Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

[Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200%2E1%2E0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension paused:** Standardization of the `arrow.big_decimal` extension type has been paused to re-evaluate requirements for arbitrary-precision numeric types across the broader ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow%2Ebig%5Fdecimal%20extension%20proposal)

* **Parquet FILE extension:** Proposal to introduce an `arrow.parquet.file` canonical extension type to align with the new FILE logical type recently added to the Parquet specification.
