* **Arrow 25.0.0 release:** The community released version 25.0.0, resolving over 220 issues and introducing significant performance optimizations for PyArrow list conversions used by Spark. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on establishing a canonical, human-readable JSON format for schemas to simplify tasks like JSON API contracts and ADBC metadata exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Deprecating Tensor IPC messages:** Proposal to deprecate dedicated Tensor and SparseTensor IPC messages in favor of using canonical extension types, which offer better integration with existing high-level APIs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Deprecate%20Tensor%20and%20SparseTensor%20messages)

* **Semantics of non-nullable nested fields:** Technical debate regarding how the `nullable` flag should be interpreted in complex types, such as child fields within structs that have null parents. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant and Parquet spec alignment:** Efforts to resolve inconsistencies between the Arrow Variant extension and the Parquet shredding specification to ensure reliable data round-tripping. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC 24 release and documentation overhaul:** The ADBC libraries reached version 24 alongside a major documentation refresh to better distinguish between ASF-hosted and vendor-provided drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Conbench v2 migration:** Updates on the transition to Conbench v2 for project benchmarking, including a new Go-based backend and UI improvements for regression detection. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)

* **C Data Interface field name clarification:** Discussion on how the C FFI should handle edge cases like embedded null bytes in UTF-8 field names to prevent crashes in producers and consumers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **Bug squashing initiative:** A call for volunteers to help triage and reproduce older bug reports as automation begins flagging stale issues for closure. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Closing%20out%20old%20issues%20-%20extra%20help%20wanted)
