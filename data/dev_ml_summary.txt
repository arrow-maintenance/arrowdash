* **Windows Arm64 support for PyArrow:** Microsoft and Linaro proposed a plan to support `win_arm64`, offering dedicated engineering for CI maintenance and hardware for maintainers to debug platform-specific issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSPythonCI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Arrow 25.0.1 release:** The community released version 25.0.1, a patch release resolving nine issues including significant performance improvements for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limits on concurrent PRs:** To manage a surge in AI-generated and stale contributions, developers discussed limiting non-committers to three concurrent open pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal canonical extension type:** A proposal for an `arrow.big_decimal` type was paused to better align with ecosystem requirements and evaluate the need for dedicated compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Deprecation of IPC Tensor messages:** A vote is underway to informally deprecate Tensor and SparseTensor messages within the IPC protocol due to limited implementation support across different languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Parquet File extension type:** Discussion has started on defining an `arrow.parquet.file` extension type to provide a standardized in-memory representation for the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Variant extension and Parquet shredding alignment:** Developers are updating the Arrow Variant extension specification to ensure consistency with Parquet shredding by explicitly disallowing certain types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang introduction:** Arx is an experimental programming language that uses Apache Arrow as its native foundation for data-oriented runtimes, arrays, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** A proposal was introduced to use custom fault handling to lazily map Parquet columns into memory, enabling vectorized operations without manual row-group management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSParquetCPython%20Lazy%20memory%20mapping)

* **New project committers:** The project welcomed Tadeja Kadunc, Zehua Zou, and Kosta Tarasov as new committers following their continued contributions to the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
