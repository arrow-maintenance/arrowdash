* **Apache Arrow 25.0.1 release:** The community released version 25.0.1, a patch release addressing 9 issues discovered since the previous major version. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limit on concurrent open PRs:** Proposal to limit non-committers to three open PRs to mitigate a recent surge in low-quality or stale AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal canonical extension type:** A proposal to standardize `arrow.big_decimal` for arbitrary-precision numeric data was paused to further evaluate ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of IPC Tensor messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation across languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Variant extension spec alignment:** Discussion on refining the Arrow Variant extension specification to ensure it remains consistent with the Parquet shredding specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArrowMetal project announcement:** Introduction of a new project that implements Arrow compute kernels for Apple Silicon GPUs using Metal, featuring zero-copy shared memory between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical extension type for FILE:** Proposal for a new `arrow.parquet.file` extension type to provide a native Arrow representation for file-level references defined in the Parquet format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language that uses Apache Arrow as the primary foundation for its data-oriented runtime and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Release of Arrow Rust and Go:** The Rust implementation released version 59.3.0, and the Go implementation released version 18.8.0, both addressing stability and build compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)
