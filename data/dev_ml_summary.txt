* **Limits on concurrent open PRs:** Proposal to limit non-committers to three concurrent open pull requests to manage a surge in AI-generated contributions and reduce the burden of stale PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to a lack of multi-language implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal, a project providing Arrow compute kernels that run natively on Apple silicon GPUs via the Metal API and the C Device Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension proposal paused:** Active work on the `arrow.big_decimal` canonical extension type is on hold to gather more feedback on compute kernel support and existing ecosystem practices. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **New Canonical Extension Type for FILE:** Discussion on adding `arrow.parquet.file` as a canonical extension type to align with the new FILE logical type in the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Introduction of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Apache Arrow 25.0.1 Release:** The community announced the release of version 25.0.1, a maintenance release resolving nine issues from the previous version. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.1%20released)

* **Variant and Parquet shredding alignment:** Discussion on updating the Arrow Variant extension specification to ensure it is consistent with the Parquet shredding specification, specifically regarding disallowed types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Go 18.8.0 Release:** Version 18.8.0 of the Go implementation has been released, including 283 commits covering Arrow, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Lazy memory mapping for Parquet:** Proposal for a library that uses custom fault handling to map Parquet column ranges lazily, allowing for vectorized operations without explicit row-group handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)
