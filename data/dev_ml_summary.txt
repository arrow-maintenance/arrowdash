* **PyArrow modularity:** Proposal to split PyArrow into smaller, optional wheels (e.g., `pyarrow-s3`) to reduce package size for users and the maintenance burden for releases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Arrow 26.0.0 release:** The project successfully released version 26.0.0, which includes over 330 resolved issues across multiple language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust releases:** A major release (60.0.0) was announced for the Rust implementation, alongside a coordinated set of patch releases across the 57, 58, and 59 branches to address backported fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Range extension types:** A vote is underway to add two new canonical extension types—`arrow.fixed_closedness_range` and `arrow.variable_closedness_range`—to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **CI optimization proposal:** Discussion on reducing GitHub Actions runner usage by up to 40% through better labeling, optimizing merge-to-main triggers, and refactoring the Package Linux matrix. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%28~30-40%25%20fewer%20runner%20minutes%29)

* **IBM Db2 ADBC driver:** IBM contributors have proposed adding a native C++ ADBC driver for Db2 (LUW) to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Dictionary-encoded extension types:** Technical discussion on updating the IPC format to support custom metadata (extension types) within `DictionaryEncoding` to align with the C Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait support:** Proposal to add new `SqlInfo` codes allowing Flight SQL servers to advertise supported Substrait dialects for improved query interoperability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **New committer:** Richard Baah has been invited and accepted the role of a new committer on the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Richard%20Baah)

* **CSV timestamp parsing improvements:** Review is progressing on a long-standing request to allow the CSV reader to use fallback timestamp parsers for explicitly typed date and time columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2BPython%20Getting%20PR%20%2350146%20%28CSV%20date/time%20parsing%2C%20GH-41488%29%20reviewed)
