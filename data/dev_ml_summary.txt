* **Informal deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol, encouraging implementations to move away from these seldom-used formats. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Canonical Extension Type for FILE type:** Proposal to introduce `arrow.parquet.file` to provide a standardized in-memory representation for the Parquet FILE LogicalType across different language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArrowMetal release for Apple silicon GPUs:** Announcement of ArrowMetal, a project providing Arrow compute kernels that run on Apple silicon GPUs via Metal with zero-copy shared memory between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Dropping macOS Intel support:** Discussion on deprecating macOS Intel support for CI and official binaries as Homebrew and GitHub Actions move toward prioritizing Apple silicon. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Improving PyArrow modularity via wheel splitting:** Proposal and proof-of-concept for splitting PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce the monolithic package size and simplify dependency management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Guidelines for AI-generated contributions:** Developers are discussing new reviewer guidelines to handle low-quality AI-generated pull requests and the introduction of a "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Apache Arrow Rust 60.0.0 release:** This major release includes the first Parquet implementation of Adaptive Lossless Floating-Point (ALP) encoding and new Parquet PageIndex structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Status update on Big Decimal extension:** Work on the `arrow.big_decimal` extension proposal is being paused to gather more information on how the broader ecosystem handles arbitrary-precision decimals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)
