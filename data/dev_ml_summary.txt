* **Apache Arrow 26.0.0 release:** The community passed the vote for version 26.0.0, which includes 337 resolved issues across the project's various language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed Sovereign Tech Agency is funding development for PyArrow through 2027, focusing on type annotations, documentation, and managing the high volume of automated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **AI-generated contribution policies:** Maintainers are discussing new workflows to handle the influx of AI PRs, including mandatory disclosure, automated drafting for idle PRs, and potential neutral labels for requested author engagement. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **PyArrow modularity and package size:** Proposal to split PyArrow into multiple wheels to reduce its dependency footprint, addressing concerns from users who currently reject the package due to its large installation size. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Arrow Rust 60.0.0 major release:** The Rust implementation reached version 60, introducing new Parquet encoding support, kernel performance optimizations, and a concerted effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **IPC support for dictionary-encoded extension types:** A set of draft PRs across C++, Go, Rust, and nanoarrow aim to allow the IPC format to represent metadata for dictionary values, filling a previous gap in the Arrow type model. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Substrait dialect advertisement in Flight SQL:** Discussion on adding new SqlInfo codes to Flight SQL to allow servers to advertise which specific Substrait types, relations, and functions they support using standard dialect files. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **New canonical extension types for ranges:** A proposal and vote are underway to add "fixed_closedness_range" and "variable_closedness_range" to the standard extension types for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Apache Arrow ADBC 25 release:** The ADBC subproject released version 25, providing updated database access abstractions and drivers for C, C#, Go, Java, Python, R, and Rust. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **CI resource optimization:** Developers are implementing strategies to reduce GitHub Actions runner usage by 30-40%, including reducing redundant "Extra" workflow runs on merges and moving bot tasks to lighter runners. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20~30-40%25%20fewer%20runner%20minutes)
