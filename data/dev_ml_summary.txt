* **Windows on Arm support:** Microsoft and Linaro proposed adding `win_arm64` support for PyArrow, offering dedicated engineering time for `abi3` wheel consolidation and hardware for maintainers to debug issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **BigDecimal Extension Type:** A proposal for a canonical `arrow.big_decimal` extension type to support variable-scale decimals is under review, though maintainers have requested further discussion on the underlying representation before finalizing the vote. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limiting concurrent PRs:** Developers are discussing a policy to limit non-committers to a small number of concurrent open pull requests to mitigate the impact of stale, low-quality, or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Arrow 25.0.1 and ADBC 24 Releases:** Multiple releases were finalized, including Arrow 25.0.1 to address performance regressions and ADBC 24 which resolved 55 issues across C++, Go, Python, and Java drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Variant spec alignment:** A proposal aims to update the Arrow Variant extension spec to be consistent with the Parquet shredding spec, specifically regarding the handling of unsigned integers and null values in `typed_value` columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift 6.0 migration:** Discussion on raising the minimum Swift version to 6.0 for the `arrow-swift` implementation to leverage native `Int128` support, which is a key building block for Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Struct nullability semantics:** Discussion regarding how Arrow handles nullability in nested types, including a proposal to support positional indices for nested structs to avoid "polluting" child arrays with dummy values in nullable slots. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Community Growth:** The project welcomed Jeffrey Vo to the Project Management Committee (PMC) and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
