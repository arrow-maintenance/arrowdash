* **Arrow 25.0.1 release:** The community released version 25.0.1, resolving nine issues including fixes for Gandiva timezone handling and improvements to the source verification process. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limits on concurrent PRs:** Discussion on implementing a limit of three concurrent open pull requests for non-committers to help manage the influx of stale or low-value AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension status:** The proposal for a canonical BigDecimal extension type has been paused to re-evaluate ecosystem-wide requirements, compute kernel support, and memory layout performance considerations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Tensor IPC deprecation:** A formal vote passed to informally deprecate Tensor and SparseTensor messages in the IPC protocol, acknowledging that these features lack cross-language implementation parity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **FILE extension type proposal:** Developers are proposing a new `arrow.parquet.file` canonical extension type to provide a standardized in-memory representation for file-level references, including URIs, offsets, and checksums. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow Rust 59.3.0 release:** The Rust implementation version 59.3.0 was approved and released, following verification across multiple architectures including Apple Silicon and Fedora. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)

* **New committer announcements:** The project welcomed three new committers—Tadeja Kadunc, Zehua Zou, and Kosta Tarasov—in recognition of their contributions to CI maintenance, format specifications, and core implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Variant extension consistency:** Discussion on aligning the Arrow Variant extension documentation with the Parquet shredding specification to ensure consistent handling of types like unsigned integers and Nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Lazy memory mapping for Parquet:** A proposal and experimental library were shared exploring the use of custom fault handling to map Parquet column address ranges lazily, hiding row-group boundaries from the caller. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSParquetCPython%20Lazy%20memory%20mapping)
