* **Apache Arrow 25.0.0 and 25.0.1 releases:** The community announced a major release featuring over 200 resolved issues, quickly followed by a patch release to address critical bugs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **ADBC 24 release and documentation overhaul:** A new version of the Arrow Database Connectivity (ADBC) libraries was released alongside a significant rewrite of the documentation to better clarify driver sources and vendor support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Documentation%20overhauled%20for%20ADBC)

* **Windows Arm64 support for PyArrow:** Microsoft proposed a comprehensive plan to enable win_arm64 builds, including resource commitments for CI maintenance and a move toward unified build paths and abi3 wheels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Semantics of nullability in complex types:** Discussion regarding how the IPC `nullable` flag should be interpreted for non-trivial types like nested structs with null parents or dictionary arrays with nulls in the dictionary. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **BigDecimal canonical extension type:** A formal vote was opened to adopt a new extension type for variable-scale decimal data, enabling better support for database types like PostgreSQL NUMERIC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limiting concurrent PRs for non-committers:** To manage an increase in stale or AI-generated contributions, the community is discussing a policy to limit the number of open pull requests allowed for contributors without write access. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Swift minimum version increase:** Proposal to raise the minimum required Swift version to 6.0 to leverage native Int128 support, which is essential for implementing high-precision Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Nanoarrow 0.9.0 release:** The lightweight C/C++ implementation was updated with several improvements across Python and R bindings and a new draft blog post highlighting key features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Variant extension and Parquet shredding inconsistency:** Developers identified discrepancies between the Arrow Parquet Variant spec and the Parquet Shredding spec regarding unsigned integer support in shredded columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)
