* **Apache Arrow 25.0.0 and 25.0.1 releases:** The community released version 25.0.0, featuring over 200 resolved issues, followed quickly by a 25.0.1 patch release to address critical bugs in Python and Gandiva. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Windows ARM64 support for PyArrow:** Microsoft and Linaro proposed a commitment to support Windows on Arm64, offering dedicated engineering resources for build consolidation and hardware for maintainers to use in debugging. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Canonical BigDecimal extension type:** A formal vote is underway to adopt `arrow.big_decimal` as a canonical extension type, enabling high-fidelity transport of variable-scale numeric data from databases like PostgreSQL and Oracle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Semantics of non-nullable fields:** Discussion regarding the IPC format's `nullable` flag and how implementations should handle non-nullable child fields when their parent structs contain null values. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Limit on concurrent pull requests:** Proposal to restrict the number of concurrent open PRs for non-committers to manage the project's maintenance burden and address an uptick in stale, low-quality, or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Raising Swift minimum to 6.0:** Proposal to move the Swift implementation to a minimum of version 6.0 to leverage native Int128 support, which is necessary for robust Decimal type implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant and Parquet spec inconsistency:** Discovery of discrepancies between the Arrow Variant extension and the Parquet Shredding specification regarding unsigned integer support and representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC 24 and nanoarrow 0.9.0 releases:** Significant updates were released for the Arrow Database Connectivity (ADBC) libraries and the nanoarrow C library, including improved documentation and expanded driver support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Community updates:** Jeffrey Vo was appointed as a new PMC member, and Tadeja Kadunc was welcomed as a new project committer for her ongoing work on CI and infrastructure. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)
