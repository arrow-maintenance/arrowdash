* **Deprecation of Tensor/SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to streamline the format and reduce maintenance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal 0.1.0 announcement:** A new project called ArrowMetal was introduced, providing compute kernels for Apple silicon GPUs through Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Dropping macOS Intel support:** Discussion on dropping CI support for macOS on Intel hardware due to Homebrew stopping builds and increasing maintenance overhead. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel splitting:** Proposal to split PyArrow into multiple wheels (e.g., core and S3) to reduce monolithic installation sizes and manage dependencies more effectively. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Canonical FILE extension type:** Discussion on adding `arrow.parquet.file` as a canonical extension type to provide an in-memory representation matching the Parquet FILE LogicalType. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Developers are establishing reviewer guidelines for handling low-quality AI-generated pull requests and ensuring authors demonstrate an understanding of their contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Arrow Rust 60.0.0 release:** The major 60.0.0 release of the Rust implementation includes new support for ALP encoding in Parquet and significant performance optimizations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Standardizing arrow.range extension:** Renewed interest in standardizing a canonical extension type for bounded ranges, focusing on a single type with configurable closedness. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)

* **Big Decimal proposal status:** Work on the `arrow.big_decimal` extension proposal has been paused to gather further information on existing ecosystem practices for arbitrary-precision decimals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)
