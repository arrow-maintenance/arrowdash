* **ArrowMetal 0.1.0 release:** Introduction of a new project providing Arrow compute kernels for Apple silicon GPUs via Metal, featuring shared-storage memory for zero-copy CPU/GPU interop. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor-related messages in the IPC protocol to focus on more widely used format features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal extension proposal status:** Active work on the `arrow.big_decimal` canonical extension type is being paused to better evaluate ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Go 18.8.0 release:** The Go implementation release is finalized, including nearly 300 commits and updates across the core library, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Canonical Extension Type for FILE type:** Proposal to add `arrow.parquet.file` as a canonical extension type to provide an in-memory representation matching the Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Lazy memory mapping for Parquet:** Discussion on using custom fault handling to lazily map Parquet row groups to memory, allowing for vectorized operations over large columns without manual row-group management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Limit on concurrent open PRs:** Agreement to implement a limit of three concurrent open pull requests for non-committers to improve review quality and maintainer bandwidth. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Variant extension specification refinement:** Discussion on adjusting the Variant spec to explicitly disallow Arrow types that cannot be represented in the underlying Variant format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Hackathon at Community Over Code:** Planning for an in-person Arrow hackathon in Glasgow this October, focusing on curating "good first issues" and community mentorship. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
