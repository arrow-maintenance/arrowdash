* **PyArrow modularity and multi-wheel split:** Proposal to split PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce the monolithic package size on PyPI and simplify installations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on sunsetting official support and CI testing for Intel-based macOS following similar moves by Homebrew and Apple. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Handling AI-generated contributions:** Proposal to update reviewer guidelines and introduce a "needs-author-engagement" label to manage low-quality or low-effort AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Arrow Rust 60.0.0 release:** Major release of the Rust implementation featuring new Parquet ALP encoding support, improved kernel performance, and a focus on removing panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **ArrowMetal project announcement:** Introduction of a new compute library providing Arrow kernels optimized for Apple Silicon GPUs via the Metal API and C Device Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical Extension Type for FILE:** Proposal to standardize an `arrow.parquet.file` extension type to maintain parity with the Parquet format's FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Deprecation of Tensor types in IPC:** Successful vote to informally deprecate Tensor and SparseTensor in the IPC format and C++ API in favor of simpler conventions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **JSON representation of Arrow schemas:** Iteration on a standardized JSON format for Arrow schemas to facilitate data contracts and configuration-based data exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Go 18.8.0 release:** New release of the Go implementation including 283 commits and updates across Arrow, Flight, and Parquet modules. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC0)
