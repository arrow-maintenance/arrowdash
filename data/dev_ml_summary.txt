* **Arrow 25.0.0 Release:** The community released version 25.0.0 with 222 resolved issues, following a discussion on performance improvements for `to_pylist` conversions commonly used in Spark. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on a proposed JSON format for Arrow schemas to simplify integration with REST APIs and ADBC, debating the balance between human readability and machine-friendly precision. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable fields in nested types:** A technical deep dive into what the `nullable` flag should mean for child fields in complex types, such as when a parent struct is null but the child field is marked non-nullable. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **ADBC 24 Release and Documentation:** The ADBC subproject released version 24 alongside a major documentation overhaul designed to clarify the distinction between ASF-maintained and vendor-specific database drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Parquet Variant spec inconsistency:** Developers identified a discrepancy between the Arrow Variant extension and the Parquet shredding spec regarding unsigned integer support, leading to a proposal to align the Arrow spec for better round-tripping. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift 6.0 Migration Proposal:** Proposal to increase the minimum Swift version to 6.0 to leverage native `Int128` support, which is a prerequisite for implementing robust Decimal types in the Swift implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **C Data Interface field name safety:** Clarification regarding field names in the C FFI, concluding that producers must error when names contain nul bytes because they are valid in Arrow's UTF-8 strings but incompatible with C-style strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **nanoarrow 0.9.0 Release:** The lightweight nanoarrow library reached version 0.9.0, including significant updates to the C library core as well as the R and Python bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20nanoarrow%200.9.0)

* **Rust implementation updates:** Release of version 59.2.0 of the Arrow Rust implementation and version 0.14.1 of the Object Store crate, maintaining the project's rapid release cadence. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.2.0%20RC1)
