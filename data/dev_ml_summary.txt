* **Arrow 25.0.0 release:** Version 25.0.0 was released with 222 resolved issues; the community opted to proceed with the release candidate while planning a 25.0.1 patch to address PyArrow performance for Spark users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on creating a canonical, human-readable JSON format for schemas to simplify application-level tasks like REST API contracts and ADBC metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Deprecation of Tensor and SparseTensor IPC messages:** Proposal to deprecate experimental tensor-related IPC messages in favor of modern canonical extension types which offer better integration with existing Arrow implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Discuss%20IPC%20Deprecate%20Tensor%20and%20SparseTensor%20messages%3F)

* **Semantics of non-nullable fields with non-trivial types:** Technical debate regarding how the `nullable` flag should be interpreted for complex types, such as child fields in a struct where the parent is null. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant extension spec inconsistency:** Developers identified discrepancies between the Arrow Variant extension and the Parquet shredding spec, specifically regarding support for unsigned integers and null columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift version 6.0 upgrade proposal:** Proposal to raise the minimum Swift requirement to 6.0 to leverage native Int128 support, which would enable robust implementation of Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **ADBC 24 release and documentation overhaul:** Major release of ADBC libraries alongside a site overhaul designed to better distinguish between official ASF drivers and those maintained by external vendors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC1)

* **Status of Conbench benchmarking:** Discussion on improving regression detection and resolving performance timeouts in the Conbench infrastructure used for tracking Arrow's performance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)
