* **AI-generated contributions:** Proposal to establish reviewer guidelines for handling low-quality AI-generated pull requests, including the introduction of a "needs-author-engagement" label to flag PRs where the contributor is not meaningfully interacting with feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Dropping macOS Intel support:** Discussion on ending official CI support and binary wheel distribution for Intel-based Macs, driven by Homebrew’s deprecation of the platform and usage data showing Intel Macs account for a small fraction of downloads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and multi-wheel installation:** Effort to split the monolithic PyArrow package into smaller, modular wheels (e.g., `pyarrow-s3`) to significantly reduce the installation size for users who do not require all C++ dependencies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Arrow 26.0.0 release:** The community successfully voted on and released version 26.0.0, which includes 337 resolved GitHub issues across all implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **JSON representation of Arrow schemas:** Ongoing discussion to define a standard JSON format for Arrow schemas to improve cross-language data contracts, with recent updates focusing on support for Union and nested types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Canonical extension types for ranges:** A vote to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` as canonical extension types to support bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 ADBC driver:** IBM proposed contributing a native C++ driver for Db2 (LUW) to the ADBC ecosystem, expanding the reach of Arrow-native database connectivity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Arrow Rust 60.0.0 release:** The Rust community announced version 60.0.0, featuring new Parquet encoding support, major kernel performance improvements, and a significant effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **ADBC logo and visual identity:** Discussion on finalizing a new logo and visual branding for the Arrow Database Connectivity (ADBC) subproject to clarify its identity within the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)

* **New committer Richard Baah:** The project welcomed Richard Baah as a new committer in recognition of his contributions to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Richard%20Baah)
