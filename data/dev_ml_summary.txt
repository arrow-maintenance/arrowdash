* **Apache Arrow 25.0.0 release:** The community approved the release of version 25.0.0, which resolves over 220 issues across the project's various language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on a proposal to define an unambiguous, human-friendly JSON format for Arrow schemas to simplify integration with REST APIs and ADBC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable fields:** A deep technical discussion regarding how the `nullable` flag should be interpreted for complex types, such as child fields in null struct parents or dictionaries with null values. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Apache Arrow ADBC 24 release:** The ADBC subproject released version 24, featuring significant documentation improvements and updates to the Python, Go, and C++ drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Swift 6.0 upgrade proposal:** Developers discussed raising the minimum Swift version to 6.0 to leverage native Int128 support, which is a prerequisite for implementing Decimal types in the Swift library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Parquet Variant spec inconsistencies:** Identification of divergences between the Arrow and Parquet specifications for shredded variants, specifically regarding the mapping of unsigned integer types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **C Data Interface field names:** Clarification on how to handle field names containing embedded NUL bytes in the C FFI, which are valid in Arrow's Flatbuffer definition but problematic for standard C-string consumers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **nanoarrow 0.9.0 release:** The lightweight nanoarrow library released version 0.9.0, including 38 resolved issues and improved support for R and Python bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC Member appointment:** Jeffrey Vo (Jefffrey) has been invited and appointed to the Apache Arrow Project Management Committee in recognition of their contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)
