* **BigDecimal Extension Type:** Discussion on a canonical type for arbitrary-precision decimals reached a pause as the community decided to re-evaluate compute support and alignment with RDBMS patterns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor IPC messages:** A formal vote passed to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation and usage across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal project announcement:** Introduction of a new project providing Arrow compute kernels for Apple silicon GPUs through Metal, featuring shared-memory interop with several language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Variant and Parquet spec alignment:** Developers are refining the Variant extension specification to ensure consistency with Parquet shredding, specifically regarding the exclusion of unsigned integers and null types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Rust 60.0.0 release:** This major release includes the first Parquet implementation of the Adaptive Lossless Floating-Point (ALP) encoding alongside new PageIndex structures and performance enhancements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **ArxLang introduction:** A new experimental programming language, Arx, was introduced to the community, featuring Apache Arrow as its native foundation for data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **FILE Extension Type proposal:** A proposal was made to create a canonical `arrow.parquet.file` extension type to align with the recently added FILE LogicalType in the Parquet format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Conbench infrastructure redesign:** Discussion on the future of Arrow's benchmarking data, with a proposal to move toward a storage model using Parquet files and DuckDB instead of a traditional Postgres backend. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **Pull request limits for non-committers:** The community agreed to a general guideline limiting non-committers to three concurrent open pull requests to help manage the project's review bandwidth. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Arrow Hackathon at Community Over Code:** Announcements and task list preparations are underway for the upcoming Arrow hackathon in Glasgow, scheduled for October 13, 2026. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
