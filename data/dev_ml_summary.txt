* **Dropping macOS Intel support:** Discussion on deprecating macOS Intel builds and CI testing due to Homebrew's lack of support for newer versions and limited hardware availability for testing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **PyArrow modularity and multi-wheel installation:** Proposal to split PyArrow into smaller, optional wheels (e.g., core and s3) to reduce the monolithic package size on PyPI and manage specific dependencies more effectively. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 release:** The project announced the official release of version 26.0.0, which includes 337 resolved issues across the C++, Python, and core implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **IBM Db2 driver for ADBC:** IBM contributors have proposed the donation of a native C++ ADBC driver for IBM Db2 (LUW) to the Apache Arrow ADBC subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Canonical range extension types:** A formal vote is in progress to add `fixed_closedness_range` and `variable_closedness_range` to the Arrow specification to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Dictionary-encoded extension types in IPC:** Proposal to update the IPC format to include optional metadata on dictionary encodings, allowing extension type information to be preserved for dictionary-encoded fields. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Substrait dialect advertising via Flight SQL:** Proposal to add new `SqlInfo` codes to the Flight SQL protocol so servers can describe exactly which Substrait features and dialects they support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Arrow Rust 60.0.0 release:** The Rust community released version 60.0.0, featuring significant kernel performance improvements, new Parquet encoding support, and a continued effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **ADBC project visual identity:** Discussion and lazy consensus on adopting a new logo and visual identity for the ADBC (Arrow Database Connectivity) subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)

* **CSV date/time parsing improvements:** Contributors are pushing for reviews on long-standing issues to allow the CSV reader to use `timestamp_parsers` as a fallback for explicitly typed date and time columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2B%20Python%20Getting%20PR%20%2350146%20CSV%20date/time%20parsing%2C%20GH-41488%20reviewed)
