* **Apache Arrow ADBC 24 Release:** The ADBC subproject released version 24, including 57 bug fixes and improvements such as critical JNI build fixes for Windows. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Swift version bump to 6.0:** Proposal to raise the minimum Swift version to 6.0 to leverage native Int128 support, which is a prerequisite for robustly implementing Decimal32/64/128/256 types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **nanoarrow 0.9.0 release:** The lightweight nanoarrow implementation released version 0.9.0, resolving 38 issues across its C, Python, and R components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Windows on Arm support for PyArrow:** Microsoft and Linaro engineers proposed a plan to support win_arm64, including a commitment to move toward abi3 wheels and a unified Windows build path. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Apache Arrow 25.0.1 patch release:** A maintenance release was shipped to resolve 9 issues, notably improving `to_pylist()` performance for nested types like Maps and Structs in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limiting concurrent PRs for non-committers:** Discussion on implementing a limit of three concurrent open pull requests for non-committers to mitigate the influx of stale or low-value AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal Canonical Extension Type:** A formal vote was opened to adopt a `arrow.big_decimal` extension type for variable-scale numeric data, though some maintainers expressed concerns regarding specification consensus. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed with Arrow as its native foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **New project leadership:** The community welcomed Jeffrey Vo to the PMC, while Tadeja Kadunc and Zehua Zou were invited and accepted roles as new project committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)
