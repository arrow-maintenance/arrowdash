* **Modularity of PyArrow:** Proposal to split PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the 2GB monolithic package size and allow users to install only required components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer protocols for handling low-quality AI PRs, including a proposed "needs-author-engagement" label to flag lack of understanding from contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Dropping macOS Intel support:** Proposal to drop CI support for Intel-based Macs due to maintenance difficulties as Homebrew and other upstream tools shift focus to ARM-based Apple Silicon. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **ArrowMetal announcement:** Introduction of ArrowMetal 0.1.0, a new project providing Arrow compute kernels that run natively on Apple Silicon GPUs using the Metal API with zero-copy data transfer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Range canonical extension types:** A formal vote is underway to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` as standard extension types for representing bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Ongoing discussion to define a standardized JSON format for Arrow schemas to facilitate data contracts and cross-process schema exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Arrow 26.0.0 and Rust 60.0.0 releases:** The community is testing the 26.0.0 RC0 release candidate while announcing the major release of Arrow Rust 60.0.0, which introduces support for the new Parquet ALP encoding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Tensor deprecation in IPC:** The vote passed to formally deprecate the Tensor and SparseTensor types within the Arrow IPC format and Flatbuffers definitions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Go v18.8.0 release:** The Apache Arrow Go libraries have been updated to version 18.8.0, including 283 commits across Arrow, Flight, and Parquet modules. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **CSV date/time parsing improvements:** Discussion on a long-standing PR to allow the CSV reader to use custom timestamp parsers as fallbacks for date and time types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C++%20Python%20Getting%20PR%20#50146%20CSV%20date/time%20parsing%20GH-41488%20reviewed)
