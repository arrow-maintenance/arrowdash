* **Informal deprecation of Tensor and SparseTensor:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to a lack of multi-language implementation support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal announcement:** Introduction of a new project providing Arrow compute kernels for Apple Silicon GPUs via Metal, featuring zero-copy shared memory and broad language support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **PyArrow modularity and wheel splitting:** Proposal to decompose PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce monolithic binary sizes and improve installation flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official support for macOS Intel (x86_64) as CI providers and tools like Homebrew discontinue support for older hardware. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Canonical extension type for FILE:** Proposal to add `arrow.parquet.file` as a canonical extension type to preserve Parquet FILE LogicalType semantics across Arrow interfaces. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer protocols for low-quality AI-generated PRs and introducing a "needs-author-engagement" label to manage low-effort submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Standardizing arrow.range extension type:** Continued effort to standardize a canonical extension for bounded ranges, focusing on how to represent interval closedness efficiently. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation featuring initial support for Adaptive Lossless Floating-Point (ALP) encoding in Parquet and significant performance optimizations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **JSON representation of Arrow schemas:** Ongoing discussion regarding the formalization of the JSON representation for Arrow schemas to improve interoperability across different implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Go 18.8.0 release:** The Go implementation release includes 283 commits from 16 contributors covering core libraries, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Go%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)
