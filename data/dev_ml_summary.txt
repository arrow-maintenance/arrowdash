* **Apache Arrow 25.0.0 and 25.0.1 releases:** The community released version 25.0.0 followed by a 25.0.1 patch to address regressions, including performance improvements for `to_pylist()` on nested types and Gandiva timezone fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.0%20released)

* **Semantics of nullability in nested types:** Deep technical discussion regarding how the IPC format's `nullable` flag should be interpreted for complex types like structs with null parents or dictionary arrays with null values. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Windows ARM64 support plan for PyArrow:** Microsoft and Linaro proposed a commitment to provide engineering resources and hardware to establish Windows on Arm as a first-class supported platform for PyArrow builds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limiting concurrent PRs for non-committers:** Discussion on implementing a policy to limit the number of open pull requests from contributors without write access to manage stale or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Swift version bump to 6.0:** Proposal to raise the minimum Swift version requirement to 6.0 to unlock native `Int128` support for high-precision decimal arithmetic. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Canonical BigDecimal Extension Type:** A proposal to adopt a variable-scale decimal extension type to better represent numeric data from systems like PostgreSQL and Trino. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Variant spec alignment with Parquet:** Identification of inconsistencies between the Arrow Variant extension and the Parquet shredding specification, particularly regarding unsigned integer support and null mappings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC 24 Release:** The ADBC subproject announced a major release featuring over 50 bug fixes and improvements across C, C++, Go, Java, Python, and Rust drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20ADBC%2024%20Released)

* **New Project Management Committee (PMC) and Committer:** The community welcomed Jeffrey Vo as a new PMC member and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
