* **AI-generated contributions:** Discussion on managing the quality of contributions created with AI and a proposal to introduce a "needs-author-engagement" label for PRs where authors do not sufficiently respond to feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Drop macOS Intel support:** Proposal to drop support for macOS on Intel CPUs following Homebrew's deprecation of Intel bottles and increasing difficulty in maintaining CI for the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel size:** Discussion on breaking down the monolithic PyArrow installation into multiple wheels (e.g., core, S3, GCS) to reduce package size and improve flexibility for downstream users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Arrow 26.0.0 and Rust 60.0.0 releases:** Major releases were finalized, with Arrow 26.0.0 resolving over 300 issues and Rust 60.0.0 introducing significant Parquet encoding improvements and kernel performance optimizations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Range canonical extension types:** A vote is underway to formalize `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` as canonical extension types for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary-encoded extension types:** Proposal to add metadata support to dictionary encoding in the IPC format, filling a gap in the current type model that affects DuckDB and spatial data exports. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM contributors have proposed contributing a native C++ ADBC driver for Db2 LUW to the official Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertising:** Proposal to add new SqlInfo codes allowing Flight SQL servers to advertise specifically which Substrait dialects and functions they support to improve plan compatibility checks. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **JSON representation of Arrow schemas:** Continued refinement of a standardized JSON format for Arrow schemas to facilitate data contract definitions and cross-process communication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20JSON%20representation%20of%20Arrow%20schemas)
