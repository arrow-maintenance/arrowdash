* **Windows on Arm support for PyArrow:** Microsoft and Linaro proposed a plan to support Windows on Arm, including commitments for CI maintenance and engineering time to consolidate Windows builds and move toward abi3 wheels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limit on concurrent PRs for non-committers:** Discussion on limiting the number of open pull requests (potentially to 3) for contributors without write access to mitigate a surge in stale and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal Extension Type:** A proposal and vote for a new `arrow.big_decimal` extension type to represent variable-scale numeric data, though some maintainers expressed concerns regarding the maturity of the specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Raising minimum Swift version to 6.0:** Proposal to update the Swift implementation's requirements to version 6.0 to leverage native Int128 support, which is essential for implementing Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Apache Arrow 25.0.1 release:** The community approved and released version 25.0.1, a patch release addressing 9 issues including critical fixes for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Subproject releases for nanoarrow, Rust, and ADBC:** Several subprojects successfully passed release votes this month, including nanoarrow 0.9.0, Arrow Rust 59.2.0, and ADBC 24. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20Rust%2059.2.0%20RC1)

* **Variant and Parquet shredding spec alignment:** Technical discussion regarding potential inconsistencies between the Arrow Variant extension and Parquet shredding specifications, specifically around handling types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
