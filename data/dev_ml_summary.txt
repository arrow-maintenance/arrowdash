* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol because they are not widely implemented across language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal project announcement:** Introduction of ArrowMetal, a new project providing Arrow compute kernels for Apple silicon GPUs via Metal, enabling zero-copy data sharing between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Dropping macOS Intel support:** Discussion on ending official support and CI testing for macOS Intel hardware due to maintenance difficulties and Homebrew's shift toward Apple silicon. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Arrow Rust 60.0.0 release:** This milestone release includes the first Parquet implementation of the new Adaptive Lossless Floating-Point (ALP) encoding and significant performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Reviewer guidelines for AI contributions:** Proposal to establish clear reviewer procedures for handling low-quality AI-generated PRs, including a new "needs-author-engagement" GitHub label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **FILE canonical extension type:** Proposal to define `arrow.parquet.file` as a canonical extension type to represent file-level references, aligning the Arrow format with recent Parquet specification updates. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Pause on Big Decimal proposal:** Work on the `arrow.big_decimal` extension has been paused to allow for further research into how the broader ecosystem handles arbitrary-precision decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Range extension type standardization:** Renewed discussion on standardizing `arrow.range` for bounded ranges, with a focus on using a single type that includes a parameter for closedness. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)

* **Conbench project evolution:** Wes McKinney proposed shifting Conbench's storage model toward Parquet files queried via DuckDB to improve performance and developer engagement. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)
