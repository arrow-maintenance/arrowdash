* **Improving PyArrow Modularity:** Discussion on splitting PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce the monolithic package size and allow users to install only the components they need. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 Release:** The community released version 26.0.0, which resolves over 300 issues including improvements to C++ SIMD support and Python binary verification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **JSON Representation of Arrow Schemas:** Ongoing discussion regarding a standardized JSON format for Arrow schemas to facilitate data contract definitions in configuration files and across different processes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Canonical Range Extension Types:** A vote is underway to add `fixed_closedness_range` and `variable_closedness_range` as canonical extension types to better represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Arrow Rust 60.0.0 Release:** The Rust implementation reached a major milestone with version 60.0.0, introducing new Parquet encoding support and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **IBM Db2 Driver for ADBC:** IBM has proposed contributing a native C++ ADBC driver for Db2 (LUW) to the ADBC ecosystem to improve database-agnostic connectivity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **GitHub Actions CI Optimization:** Proposal to reduce CI runner minutes by ~30-40% through more efficient scheduling, avoiding redundant runs on the main branch, and utilizing smaller runner types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **ADBC Release 25:** Voting is open for version 25 of the ADBC libraries, which includes updates for Go, Java, Python, Rust, C#, and R components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **Substrait Dialect via Flight SQL:** Proposal to allow Flight SQL servers to advertise supported Substrait dialects via `SqlInfo`, enabling clients to verify compatibility before sending execution plans. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IPC Representation of Dictionary Extensions:** Discussion on adding `custom_metadata` to the `DictionaryEncoding` IPC field to correctly represent extension types that use dictionary encoding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)
