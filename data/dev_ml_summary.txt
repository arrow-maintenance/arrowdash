* **Arrow 26.0.0 release:** The community approved the release of Apache Arrow 26.0.0, resolving over 300 issues across the project including significant C++ and Python enhancements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and split wheels:** Proposal to break PyArrow into smaller, modular wheels (e.g., moving S3 and specific filesystem support to optional packages) to reduce core installation size and maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Arrow Rust 60.0.0 release:** The Rust implementation reached version 60.0.0, introducing support for the new ALP encoding in Parquet and a large number of kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Dropping macOS Intel support:** Discussion on removing official CI support for macOS Intel (x86_64) due to Homebrew's deprecation of the platform and the increasing difficulty of maintaining testing infrastructure. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** Reviewers are establishing new protocols for handling low-quality AI-generated pull requests, including a proposed "needs-author-engagement" label to manage PRs with weak contributor interaction. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Canonical range extension types:** A vote is underway to standardize `fixed_closedness_range` and `variable_closedness_range` as canonical extension types to represent bounded intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Discussion continues on a standardized JSON format for Arrow schemas to facilitate data contracts and cross-process schema exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Tensor and SparseTensor deprecation:** Antoine Pitrou has submitted a PR for the informal deprecation of Tensor and SparseTensor types within the IPC format and C++ API to focus on more widely used components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULTVOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)
