* **Improving PyArrow modularity:** Proposal to split PyArrow into multiple wheels (e.g., core, S3, Parquet) to reduce the 2.1GB total wheel size and ease the maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official support for x86_64 macOS due to Homebrew deprecation and lack of CI availability, noting that Intel users now account for a very small fraction of downloads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Release of Apache Arrow 26.0.0:** The community successfully voted and released version 26.0.0, resolving over 330 GitHub issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Range canonical extension types:** Formal vote for adding `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` extension types to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **AI-generated contribution guidelines:** Discussion on updated reviewer guidelines to handle low-quality AI PRs, including a proposal for a "needs-author-engagement" label to flag lack of participation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **IPC representation of dictionary-encoded extension types:** Proposal to add an optional metadata field to `DictionaryEncoding` in the IPC format to better support extension types like UUIDs and spatial data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 ADBC driver contribution:** IBM developers proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON representation of Arrow schemas:** Ongoing discussion regarding "draft-02" of the JSON schema format, specifically focusing on how to represent Arrow Union types and nested structures efficiently. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)
