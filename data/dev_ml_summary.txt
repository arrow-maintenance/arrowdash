* **BigDecimal extension type proposal:** Discussion on a canonical extension for arbitrary-precision decimals to improve RDBMS interoperability, currently paused to address concerns regarding internal representation and compute kernel requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor and SparseTensor:** The community voted to informally deprecate Tensor and SparseTensor messages within the IPC protocol due to limited cross-language implementation and usage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal announcement:** Introduction of ArrowMetal 0.1.0, providing Arrow compute kernels for Apple Silicon GPUs using Metal and zero-copy shared memory to eliminate data transfer overhead. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **FILE canonical extension type:** Proposal to add an `arrow.parquet.file` extension type to represent file-level metadata like URIs and offsets, ensuring semantic consistency when reading the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language designed with Apache Arrow as its native foundation for all data structures and runtimes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Arrow hackathon at Community Over Code:** Announcement of an in-person hackathon in Glasgow this October, intended to help new contributors get started with curated tasks and documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Variant and Parquet spec consistency:** Discussion on aligning the Arrow Variant extension with Parquet shredding by explicitly disallowing types like unsigned integers that lack a direct equivalent in the Variant specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Go 18.8.0 release:** The Go implementation reached version 18.8.0, incorporating 283 commits that improve the core Arrow, Flight, and Parquet libraries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Lazy memory mapping for Parquet:** Exploration of using custom fault handling to lazily map Parquet columns to memory, allowing developers to perform vectorized operations on entire columns without managing row groups. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)
