* **Swift 6.0 migration:** Proposal to bump the minimum Swift version to 6.0 to enable native support for `Int128`, which is a critical building block for implementing Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Windows Arm64 support:** Proposal from Microsoft and Linaro to provide official `win_arm64` wheels for PyArrow, including a commitment for dedicated engineering support and CI hardware. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **BigDecimal Extension Type:** Formal vote to adopt a canonical `BigDecimal` extension type for variable-scale numeric data, intended to improve interoperability with databases like PostgreSQL and Trino. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **PR limits for contributors:** Discussion on implementing a limit of three concurrent open pull requests for contributors without write access to manage reviewer bandwidth and reduce stale AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Variant and Parquet alignment:** Technical discussion regarding inconsistencies between the Arrow Variant extension specification and the Parquet shredding specification, specifically concerning unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Multiple subproject releases:** Successful completion of releases for Arrow 25.0.1 (patch), nanoarrow 0.9.0, ADBC 24, and Arrow Rust 59.2.0. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Arx programming language:** Introduction of Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data types, arrays, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **New maintainers:** The community welcomed several new maintainers, including Jeffrey Vo to the PMC and Tadeja Kadunc and Zehua Zou as committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
