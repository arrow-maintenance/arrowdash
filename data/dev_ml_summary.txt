* **Release activity for Arrow 25.0.1, Rust, and nanoarrow:** Multiple releases were finalized this month, including Apache Arrow 25.0.1 (a patch release with 9 bug fixes), Arrow Rust versions 59.2.0 and 59.3.0, and nanoarrow 0.9.0. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2059.2.0%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20nanoarrow%200.9.0)

* **Windows on Arm (win_arm64) support for PyArrow:** Microsoft proposed a plan to support PyArrow wheels for Windows on Arm, committing dedicated engineering resources and hardware to help maintainers with build consolidation and CI stability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limiting concurrent open PRs for non-committers:** To manage an influx of stale or low-quality AI-generated contributions, the community is discussing a policy to limit contributors without write access to 3 concurrent open pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal extension type proposal:** A proposal for a high-fidelity variable-scale numeric type was discussed and subsequently paused to allow for further evaluation of storage layouts and compute kernel requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Variant extension and Parquet shredding spec alignment:** Discussion continues regarding inconsistencies between the Arrow Variant extension and Parquet shredding, specifically around disallowing types in shredded columns that lack a direct Variant equivalent. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang - an Arrow-native programming language:** Introduction of Arx, an experimental language built on an Arrow C++ runtime that treats Arrow arrays, tensors, and RecordBatches as native first-class data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet reading:** Proposal to use custom fault handling to lazily map Parquet columns into memory, allowing developers to perform vectorized NumPy operations over entire columns without manually handling row group boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **Community leadership updates:** The project announced Jeffrey Vo as a new PMC member and welcomed Tadeja Kadunc and Zehua Zou as new committers to the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou)
