* **Apache Arrow 26.0.0 release:** The community passed the vote for version 26.0.0, resolving over 330 issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and wheel size reduction:** A proposal is under discussion to split PyArrow into smaller, optional modules (like `pyarrow[s3]`) to reduce the monolithic 2.1GB total wheel size. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Due to Homebrew's deprecation and low usage statistics, the project is moving to drop CI support for macOS on Intel, maintaining it only on a best-effort basis for source builds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Canonical Extension Types for ranges:** Discussion and voting are underway for new extension types representing fixed and variable closedness ranges (intervals), aimed at better compatibility with systems like PostgreSQL and pandas. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Guidelines for AI-generated contributions:** Reviewers are establishing formal processes and GitHub labels (like "needs-author-engagement") to handle low-quality AI-generated PRs that lack sufficient human oversight. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Native IBM Db2 ADBC driver:** IBM developers have proposed contributing a new native C++ ADBC driver for Db2 (LUW) to the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Arrow Rust 60.0.0 release:** The Rust implementation reached version 60.0.0, featuring new Parquet encodings, significant kernel performance improvements, and a sustained effort to eliminate panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **Standardized JSON representation of Arrow schemas:** Developers are refining a specification for representing schemas in JSON, including support for complex types like unions and nested structures for cross-process configuration. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **IPC representation of dictionary-encoded extension types:** A proposal reached consensus to allow custom metadata on dictionary value types in the IPC format, with implementation drafts across C++, Go, and Rust. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **ADBC logo and visual identity:** The community adopted a new logo for the ADBC subproject by lazy consensus, including a new visual identity page and trademarks notice. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)
