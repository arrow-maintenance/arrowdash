* **BigDecimal extension type proposal:** Discussion and a subsequent vote on a canonical `arrow.big_decimal` type were paused to re-evaluate compute kernel requirements and better align with existing arbitrary-precision patterns in the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of IPC Tensor messages:** A formal vote passed to informally deprecate `Tensor` and `SparseTensor` messages in the IPC protocol to simplify the specification and encourage more standard implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Go v18.8.0 release:** The Go implementation was updated with 283 commits, featuring fixes for Go 1.27 toolchain compatibility and improvements to the compute registry and Parquet headers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **ArrowMetal GPU compute:** Announcement of ArrowMetal, a new project providing Arrow compute kernels for Apple Silicon GPUs via the Metal API, achieving significant speedups for memory-bound operations like group-by and sort. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Limits on concurrent PRs:** Developers discussed limiting non-committers to three concurrent open pull requests to manage reviewer bandwidth and mitigate the influx of low-quality or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical FILE extension type:** A proposal was introduced to define an `arrow.parquet.file` extension type to provide a standardized in-memory representation for file-level references, mirroring recent changes in the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Apache Arrow Rust 60.0.0:** Voting is currently underway for the major version 60.0.0 release of the Rust implementation, following the recent 59.3.0 maintenance release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **New project committers:** The community welcomed three new committers this month: Tadeja Kadunc, Zehua Zou, and Kosta Tarasov. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
