* **Informal deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to low adoption and maintenance overhead. Developers are encouraged to transition to other representation methods as these messages may be removed from future API implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal 0.1.0 announcement:** A new project called ArrowMetal was introduced, providing compute kernels for Apple Silicon GPUs via the Metal API. It utilizes shared-storage memory for zero-copy data transfer between CPU and GPU, supporting multiple language bindings including Python, Rust, and Go. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Release of Apache Arrow Rust 60.0.0:** This major release includes the first known implementation of the Adaptive Lossless Floating-Point (ALP) encoding for Parquet. It also introduces new Parquet PageIndex structures and significant performance improvements across the crate. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **AI-generated contribution guidelines:** Discussions are underway to establish clearer reviewer guidelines for handling low-quality or AI-generated pull requests. Proposed measures include a "needs-author-engagement" label to flag PRs where the author is not adequately responding to technical feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Proposal to drop macOS Intel support:** Developers are discussing dropping CI and official support for macOS Intel (x86_64) platforms following Homebrew's deprecation of the architecture. Data shows that Intel-based macOS downloads now account for only ~0.1% of PyArrow's total volume. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Improving PyArrow modularity via multi-wheel packaging:** A proposal and proof-of-concept were shared to split PyArrow into several smaller, optional wheels (e.g., `pyarrow-s3`). This change aims to reduce the monolithic wheel size and allow users to install only the specific storage drivers they require. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Canonical Extension Type for FILE references:** The community is standardizing a new extension type, `arrow.parquet.file`, to represent file-level references in-memory. This aligns Arrow with the finalized Parquet FILE logical type, preserving metadata like URI, offset, and checksum across serialization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Pause on Big Decimal extension proposal:** Active work on the `arrow.big_decimal` canonical extension has been paused to gather more feedback on ecosystem practices. The team intends to evaluate how various tools handle arbitrary-precision numerics before proceeding with a standardized implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)
