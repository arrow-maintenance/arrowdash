* **Arrow Rust 60.0.0 release:** The community announced the major release of Arrow Rust 60.0.0, which features new support for ALP encoding in Parquet and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Proposed PyArrow modularity improvements:** Discussion on a Proof of Concept to split PyArrow into multiple wheels (e.g., pyarrow-s3) to reduce the 2.1 GB installation footprint and manage optional dependencies better. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Deprecating macOS Intel support:** Developers proposed dropping support for macOS Intel due to Homebrew ending its support and the increasing difficulty of maintaining hardware-specific CI environments. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Apache Arrow 26.0.0 release:** The vote passed for the release of version 26.0.0, which includes over 300 resolved issues across the C++, Python, and core implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Guidelines for AI-generated contributions:** Proposal to update reviewer guidelines with protocols for handling low-quality AI PRs, including a new "needs-author-engagement" label to ensure contributors understand their submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **New Range canonical extension types:** A vote was initiated to add two new extension types—fixed and variable closedness ranges—to formalize the representation of mathematical intervals in Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM proposed contributing a native C++ ADBC driver for Db2 (LUW) to the ecosystem, sparking discussion on repository access and the contribution process. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Standardizing JSON representation of schemas:** Ongoing efforts to finalize a standardized JSON format for Arrow schemas, with recent updates focusing on better support for nested types and unions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **ADBC project logo:** The community reached lazy consensus on a new visual identity and logo for the ADBC subproject following several rounds of design feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)

* **CSV date and time parsing improvements:** Discussion on a long-standing PR to allow the CSV reader to use fallback timestamp parsers for explicitly typed date and time columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C++%20Python%20Getting%20PR%20%2350146%20CSV%20date%20time%20parsing%2C%20GH-41488%20reviewed)
