* **Limit on concurrent open PRs:** Proposal to limit non-committers to 3 concurrent open pull requests to manage an uptick in stale and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal Extension Type:** A vote was held for a new `arrow.big_decimal` canonical extension type, but the effort has been paused to better evaluate ecosystem requirements for arbitrary-precision compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-language support and low usage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal GPU compute:** Announcement of ArrowMetal 0.1.0, which provides Arrow compute kernels for Apple Silicon GPUs using zero-copy memory sharing via the C Device Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **ArxLang introduction:** Discussion on Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Canonical FILE extension type:** Proposal to add `arrow.parquet.file` as a canonical extension type to align with the recently finalized Parquet FILE logical type for storage references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Conbench evolution:** Discussions regarding the future of the Conbench benchmarking project, including a potential move toward a storage layer based on Parquet and DuckDB. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **New committers:** The project welcomed three new committers this month: Tadeja Kadunc, Zehua Zou, and Kosta Tarasov. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Kosta%20Tarasov)
