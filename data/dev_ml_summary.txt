* **BigDecimal Extension Type proposal:** Discussion on a canonical extension type for arbitrary precision decimals to improve RDBMS interoperability, though active work is currently paused to better align with existing ecosystem requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Arx is a new experimental programming language designed with Apache Arrow as its native foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to a lack of multi-language implementation and usage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal release:** Announcement of ArrowMetal 0.1.0, which provides Arrow compute kernels for Apple silicon GPUs using the Metal API and zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical Extension for FILE type:** Proposal to define `arrow.parquet.file` to provide a matching Arrow in-memory representation for the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contribution guidelines:** Discussion on establishing formal procedures for reviewers to handle low-quality AI-generated pull requests and escalation paths for closing non-compliant contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Apache Arrow Rust 60.0.0 release:** Version 60.0.0 has been released, featuring new support for ALP encoding in Parquet, updated PageIndex structures, and significant performance optimizations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Conbench modernization:** Developers are discussing evolving the Conbench benchmarking tool toward a storage model based on Parquet and DuckDB for improved flexibility and performance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)

* **Lazy memory mapping for Parquet:** Proposal for a technique using custom fault handling to map Parquet column address ranges lazily, hiding row-group boundaries from vectorized operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)
