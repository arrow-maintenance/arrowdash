* **Arrow 26.0.0 release:** The community approved the release of Apache Arrow 26.0.0, which includes 337 resolved GitHub issues and specific fixes for Python 3.15 wheel verification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and wheel splitting:** Proposal to break PyArrow into smaller, optional wheels (e.g., `pyarrow-s3`) to reduce the installation size, which has grown to over 2GB for a full release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending official CI support for x86_64 macOS due to Homebrew deprecations and low usage statistics, while still allowing best-effort source builds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** Reviewers are establishing new protocols for handling low-quality AI-generated PRs, including a proposed "needs-author-engagement" GitHub label to flag PRs lacking sufficient human oversight. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Dictionary-encoded extension types in IPC:** A proposal to add `custom_metadata` to the `DictionaryEncoding` IPC format to allow proper representation of extension types (like UUIDs) within dictionary-encoded columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **New canonical extension types for ranges:** A vote is underway to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` to the official specification for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM contributors have proposed a native C++ ADBC driver for Db2 (LUW), expanding the connectivity options for the Arrow Database Connectivity ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON representation of Arrow schemas:** Discussion continues on a standard JSON format for defining Arrow data contracts, including support for union types and cross-process schema exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Rust 60.0.0 release:** The Rust implementation reached version 60.0.0, featuring new Parquet encoding support, kernel performance optimizations, and a concerted effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **ADBC visual identity and logo:** The community has finalized a new logo for the ADBC subproject through a lazy consensus process to improve the project's branding and documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)
