* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor-related messages in the IPC protocol to simplify the specification and encourage implementations to remove these legacy APIs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal, a new project providing compute kernels that run directly on Apple silicon GPUs via Metal with zero-copy data transfer between CPU and GPU buffers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Apache Arrow Rust 60.0.0 release:** This major release introduces support for the new Parquet ALP encoding, includes Parquet PageIndex structures, and delivers significant performance improvements to kernels and FFI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Dropping macOS Intel support:** A proposal was made to drop CI support for macOS Intel (x86_64) due to Homebrew ending its support for Intel bottles and extremely low download statistics for Intel-based binaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel splitting:** Developers are discussing a plan to split PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the monolithic binary size and simplify the maintenance of various filesystem drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Canonical Extension Type for FILE type:** Discussion on adding a canonical extension type named `arrow.parquet.file` to provide an in-memory Arrow representation for Parquet's new file-level reference logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Reviewer guidelines for AI-generated code:** Proposal to update reviewer documentation with specific procedures for handling low-quality AI-generated contributions, including a new "needs-author-engagement" label to flag PRs with weak author interaction. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **JSON representation of Arrow schemas:** Ongoing efforts to finalize a standardized JSON format for representing Arrow schemas, with recent updates focusing on better support for Union types and alignment with C++ type aliases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Apache Arrow Go 18.8.0 release:** The Go libraries were updated to version 18.8.0, featuring over 280 commits from 16 contributors across the Arrow, Flight, and Parquet implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Conbench benchmarking data schema:** Discussion on formalizing a storage layer and schema design for Conbench to improve the collection and analysis of performance benchmarking data across projects. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20+%20conbench%20OSS%20project)
