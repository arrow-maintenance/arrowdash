* **Limiting concurrent PRs for non-committers:** Discussion on implementing a limit of 3 concurrent open pull requests for contributors without write access to manage AI-generated noise and stale contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to low adoption and incomplete cross-language support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal extension proposal paused:** Plans for a canonical BigDecimal extension type have been put on hold to better align with ecosystem requirements and potential compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **New FILE canonical extension type:** Proposal to introduce an `arrow.parquet.file` extension type to provide a standard in-memory representation for file-level references found in Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Arrow 25.0.1 release:** The community announced the general availability of version 25.0.1, including nine resolved issues following the previous major release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **Conbench benchmarking evolution:** Discussion on modernizing the Conbench toolset, including a proposal to move the underlying storage layer to Parquet files queried via DuckDB for better flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **New project committers:** The community welcomed Tadeja Kadunc, Zehua Zou, and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Arrow Hackathon at Community Over Code:** Announcement and planning for an in-person hackathon in Glasgow this October to help new contributors get started with the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
