* **PyArrow win_arm64 support:** Microsoft and Linaro proposed a plan to provide native Windows on ARM support, offering dedicated engineering for CI maintenance and hardware for project maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSPythonCI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **BigDecimal extension type:** A proposal for a canonical `big_decimal` extension type to handle variable-scale numerics was discussed and subsequently paused to further evaluate design tradeoffs and compute requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Pull request limits:** Discussion on limiting contributors without write access to three concurrent open pull requests to manage an uptick in low-quality AI contributions and reduce the burden of stale PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Apache Arrow 25.0.1 release:** The community approved and released version 25.0.1, a patch release addressing nine issues including significant performance improvements for PyArrow nested type conversions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **ArxLang introduction:** Introduction of Arx, an experimental programming language built on Arrow C++ that utilizes Arrow arrays and RecordBatches as its native foundation for data-oriented runtimes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Rust implementation updates:** The Arrow Rust implementation saw steady activity with the release of versions 59.2.0 and 59.3.0 to address critical issues and maintain the release cadence. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)

* **Variant and Parquet spec alignment:** Proposals were made to refine the Variant extension specification to ensure consistency with Parquet shredding, specifically regarding the handling of unsupported types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Community appointments:** The project recognized several contributors for their impact, welcoming Jeffrey Vo to the PMC and appointing Tadeja Kadunc and Zehua Zou as new committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)

* **Community Over Code Hackathon:** Preparations are underway for the Arrow hackathon in Glasgow this October, including calls for task lists and good-first-issues to engage new contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
