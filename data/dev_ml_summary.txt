* **Apache Arrow 25.0.0 release:** The community announced the release of version 25.0.0, which resolves over 220 issues; a potential RC2 to include PyArrow performance improvements for Spark was discussed but ultimately deferred to a patch release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on a proposal to define a canonical JSON format for schemas to improve human readability and simplify metadata exchange in REST APIs and ADBC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Nullability semantics for complex types:** Technical deep dive into the interpretation of the `nullable` flag in IPC for non-trivial types, specifically addressing how to handle logical nulls in nested structs and dictionary arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **C FFI field name clarifications:** Developers clarified how the C Data Interface should handle field names containing nul bytes, emphasizing that producers should detect and error on embedded nul bytes to prevent issues in C string handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **Proposal to raise Swift minimum to 6.0:** Discussion on bumping the minimum Swift version for the Swift implementation to 6.0 to leverage native `Int128` support for decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **ADBC 24 release and documentation overhaul:** Release of ADBC version 24 alongside a major overhaul of the documentation site to clarify the status of official versus vendor-developed drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Variant extension and Parquet shredding inconsistency:** Identification of discrepancies between the Arrow Variant extension specification and the Parquet Variant shredding spec regarding support for unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Release of nanoarrow 0.9.0:** The community voted to release nanoarrow 0.9.0, which includes 38 resolved issues and various bug fixes for the lightweight C library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC Member:** Jeffrey Vo (Jefffrey) has been invited and accepted a position as a new member of the Apache Arrow Project Management Committee. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
