* **PyArrow modularity improvements:** Proposal and proof-of-concept to split PyArrow into multiple wheels, allowing users to install a core package and add optional components like S3 support separately to reduce package size. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Arrow 26.0.0 release:** The community released version 26.0.0 of the project, which includes over 300 resolved issues across various language implementations and components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 release:** Major update to the Rust implementation featuring new Parquet encoding support, kernel performance improvements, and an effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **IBM Db2 ADBC driver contribution:** IBM has proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Arrow ecosystem to facilitate high-performance database connectivity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Range canonical extension types:** A vote is underway to add fixed and variable closedness range types to Arrow’s canonical extension types for standardized mathematical interval support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary-encoded extension types:** Proposal to allow Arrow IPC to represent dictionary-encoded extension types by adding metadata to the dictionary value type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Advertising Substrait dialects in Flight SQL:** Discussion on adding SqlInfo codes to Flight SQL so servers can describe which specific Substrait dialects and functions they support to clients. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **GitHub Actions CI optimization:** Analysis of Arrow's CI usage with recommendations to reduce GitHub runner minutes by 30-40% through workflow refactoring and specialized runners. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **JSON representation of Arrow schemas:** Discussions regarding the finalization of a JSON-based format for Arrow schemas, including support for union types and compatibility with Parquet metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)
