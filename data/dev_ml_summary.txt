* **Arrow 25.0.0 release:** The community released version 25.0.0 with 222 resolved issues; a proposed performance optimization for Python's `to_pylist` was deferred to a 25.0.1 patch to maintain the release schedule. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion is underway to define a standard JSON format for Arrow schemas to facilitate human readability and interoperability in REST APIs and ADBC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable fields:** Developers are debating how the `nullable` flag should be interpreted in nested types like structs and unions, specifically regarding inconsistencies when child arrays contain nulls but the parent does not. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Raising minimum Swift version to 6.0:** A proposal suggests requiring Swift 6.0 for the Swift implementation to leverage native `Int128` support for decimal types and improved concurrency safety. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Parquet Variant spec inconsistency:** An inconsistency was noted between the Arrow Parquet Variant extension and the Parquet Shredding spec regarding the support of unsigned integers in `typed_value` columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC 24 release:** The ADBC subproject released version 24 following a second release candidate to resolve static linking issues with Windows JNI artifacts. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC1)

* **C Data Interface field name clarification:** Discussion clarified that producers using the C Data Interface should error out if UTF-8 field names contain embedded NUL bytes, as these cannot be represented in C-style strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **nanoarrow 0.9.0 release candidate:** Voting is active for nanoarrow 0.9.0, which includes 38 resolved issues and significant improvements to the R and Python bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New PMC member:** Jeffrey Vo (Jefffrey) has been invited and joined the Apache Arrow Project Management Committee. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)
