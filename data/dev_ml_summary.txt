* **Apache Arrow ADBC 24 Release:** The community released version 24 of the ADBC libraries, which includes significant bug fixes and component updates for C, C++, Java, and Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Variant and Parquet Spec Alignment:** Discussion on updating the Arrow Variant extension specification to match the Parquet shredding spec, specifically regarding the handling of unsigned integers and null types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Windows on Arm Support:** Microsoft engineers proposed a plan to bring official win_arm64 support to PyArrow, offering hardware for maintainers and commitment to managing CI failures and unified build paths. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSPythonCI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limits on Concurrent Pull Requests:** Proposal to limit non-committers to three concurrent open pull requests to maintain project health and reduce the burden of stale or low-quality AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Release of nanoarrow 0.9.0:** The lightweight C/C++ implementation nanoarrow reached version 0.9.0, resolving 38 issues and introducing features covered in a new community blog post. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Swift 6.0 Minimum Requirement:** Discussion on raising the minimum Swift version to 6.0 to leverage native Int128 support, which is essential for robustly implementing Decimal types in the Swift library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **BigDecimal Canonical Extension Type:** A proposal and vote for a new `arrow.big_decimal` extension type to handle variable-scale numeric data from sources like PostgreSQL and Oracle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Introduction of ArxLang:** A presentation of Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Apache Arrow 25.0.1 Release:** A patch release was finalized to address nine issues, including critical timezone handling fixes in Gandiva and performance improvements for Python nested type conversions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)
