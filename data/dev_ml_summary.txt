* **AI-generated contributions policy:** Maintainers proposed a PR cap, mandatory AI-use disclosure with a bot that converts undisclosed PRs to drafts, and auto-drafting of stale PRs. A follow-up PR documents a rule against AI-written review replies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Copilot auto-review:** A PR was proposed to disable automatic Copilot reviews on apache/arrow, because they were being billed to contributors' personal Copilot accounts. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Auto%20GitHub%20Copilot%20review)

* **GitHub Actions and CI changes:** GitHub restricts the pull_request_target trigger from December 2, so Arrow workflows are being migrated. The Boring Cyborg labeling bot was also enabled across Arrow repositories. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)

* **Sovereign Tech Fund backs PyArrow:** The German Sovereign Tech Agency is funding about 1.9 FTE of PyArrow work through 2027, covering type annotations, the stalled bug backlog, AI-readiness tooling and documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **Arrow 26.0.1 patch release:** The 26.0.1 vote passed and the release shipped on November 4, including a fix for the statically linked Brotli CVE-2026-111497. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20%28GH-55165%29%20in%2026.0.1)

* **Arrow Rust patch releases:** Rust patch releases for 57.x through 60.x were voted and published, ending with 60.2.0 on November 21. Each passed with binding approvals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1)

* **Arrow Java 20.0.0 and release cadence:** Java 20.0.0 was released on November 21 with Java 17 as the new minimum. A proposal to release Arrow Java at least quarterly received broad support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **ADBC 25 and ADBC 1.2 planning:** ADBC 25 was released in late October with 57 fixes. A planning session agreed on credential callbacks, JSON structured error details and an action-based escape hatch for 1.2, but set no target date. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **Parquet FILE extension type:** A vote is open on adding arrow.parquet.file as a canonical Arrow extension type. Some participants question whether Parquet-specific types belong in Arrow's canonical list or should be defined in Parquet's own spec. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Substrait dialect SqlInfo codes:** A vote proposes two backward-compatible Flight SQL codes, one exposing the server's Substrait dialect and one providing a content hash for client caching. ADBC inherits the codes, and the vote has binding approvals so far. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)
