* **Windows on Arm support:** Microsoft and Linaro proposed a plan to support Windows on Arm wheels for PyArrow, offering engineering time for build consolidation and hardware for maintainers to help with CI stabilization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **BigDecimal Extension Type:** A proposal for a canonical BigDecimal extension type to handle arbitrary-precision numeric data was paused to allow for broader research into ecosystem requirements and compute kernel alignment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **PR limits for non-committers:** Discussion on implementing a limit of three concurrent open pull requests for non-committers to better manage stale and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Tensor and SparseTensor deprecation:** A vote is underway to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-language implementation and maintenance overhead. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **NumPy 2.0 requirement:** Proposal to bump the minimum NumPy version to 2.0 in upcoming releases to enable native support for converting NumPy's variable-width string types to Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Requiring%20NumPy%202.0%20or%20newer%20in%20the%20next%20Arrow%20release)

* **Arrow 25.0.1 release:** The community approved a patch release for the main project, resolving nine issues primarily focused on C++, Python, and Gandiva. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **ArxLang introduction:** Introduction of Arx, an experimental programming language built with an Arrow-native foundation for its data-oriented runtime, arrays, and tensors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant and Parquet spec alignment:** Discussion on updating the Variant extension specification to disallow types not representable in Variant, ensuring consistency with the Parquet shredding specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow Rust releases:** The Rust implementation released versions 59.2.0 and 59.3.0, including important performance optimizations and bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)
