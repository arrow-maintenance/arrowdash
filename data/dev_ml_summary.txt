* **Informal deprecation of Tensors in IPC:** The community voted to informally deprecate Tensor and SparseTensor in the IPC format to reduce specification complexity and reflect their limited usage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Go 18.8.0 release:** The Go implementation release is finalized, including improvements to the compute registry and allocator alignment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Canonical Extension Type for FILE:** Discussion is underway to standardize an `arrow.parquet.file` extension type that maps directly to the Parquet FILE LogicalType for file-level references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArrowMetal GPU compute kernels:** A new project, ArrowMetal, was announced providing 280+ Arrow compute kernels for Apple silicon GPUs using Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Arrow Rust 60.0.0 release:** This major release introduces support for the new ALP encoding in Parquet, Parquet PageIndex structures, and numerous performance improvements across kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Handling AI-generated contributions:** Developers are establishing guidelines for reviewers to manage low-quality AI PRs, including a new "needs-author-engagement" GitHub label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Proposal to drop macOS Intel support:** Due to Homebrew deprecating Intel bottles and very low usage statistics, the community is discussing removing macOS Intel from the official CI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel splitting:** A proposal and proof-of-concept were shared to split PyArrow into multiple optional wheels (like `pyarrow-s3`) to significantly reduce the monolithic package size on PyPI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Standardized JSON representation of schemas:** Ongoing discussion regarding a canonical JSON format for Arrow schemas to facilitate data contract definitions in configuration files. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **New Arrow committer:** Kosta Tarasov has been invited to become a committer on the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
