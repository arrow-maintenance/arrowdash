* **Introduction of ArxLang:** A new experimental programming language, Arx, was introduced which uses Apache Arrow as its native foundation for its runtime and data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **New Project Committers:** The community welcomed Zehua Zou and Kosta Tarasov as the newest committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)

* **Deprecation of Tensor messages in IPC:** A vote passed to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited implementation support across languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal GPU compute:** Announcement of ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple silicon GPUs via Metal with zero-copy memory sharing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical Extension Type for FILE:** Discussion on adding `arrow.parquet.file` as a canonical extension type to align with the new Parquet FILE logical type for representing file-level references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **BigDecimal Extension Type status:** Work on the `arrow.big_decimal` canonical extension type proposal has been paused to gather more information on ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Reviewer guidelines for AI contributions:** Proposal to establish clear guidelines for reviewers on how to handle low-quality or non-conforming AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Release of Arrow Rust 60.0.0:** A major release of the Rust implementation was approved, featuring new support for ALP encoding in Parquet and significant performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Arrow Go 18.8.0 Release:** The Arrow Go libraries were updated to version 18.8.0, including 283 commits covering Arrow, Flight, and Parquet components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Conbench benchmarking evolution:** Discussion on modernizing the Conbench project, including moves toward a storage layer based on Parquet and DuckDB for performance data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)
