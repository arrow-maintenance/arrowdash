* **Arrow 25.0.1 release:** Patch release addressing several issues including performance improvements for nested type conversions in Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Windows Arm64 support for PyArrow:** Microsoft proposed a plan to officially support Windows on Arm, committing dedicated engineering resources to unified build paths and CI maintenance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **ADBC 24 release:** New release of the Arrow Database Connectivity subproject, featuring bug fixes for Windows JNI artifacts and updates to multiple language bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Swift 6.0 minimum version proposal:** Discussion on raising the minimum Swift version to 6.0 to leverage native Int128 support for improved Decimal type implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Canonical BigDecimal extension type:** A formal vote was opened for a new extension type to represent variable-scale numeric data, though some maintainers expressed concerns regarding specification readiness. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limits on concurrent pull requests:** Proposal to limit non-committers to a small number of concurrent open PRs to mitigate the impact of low-quality or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Variant and Parquet spec alignment:** Discussion on ensuring the Arrow Variant extension specification is consistent with the Parquet shredding specification regarding supported types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **nanoarrow 0.9.0 release:** The lightweight nanoarrow library released version 0.9.0, resolving nearly 40 issues across the C and Python implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20nanoarrow%200.9.0)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language built with Apache Arrow as its native foundation for data structures and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
