* **Recent project releases:** Several components saw updates this month, including the release of Apache Arrow 25.0.1 (patch release), nanoarrow 0.9.0, ADBC 24, and Arrow Rust 59.2.0. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20nanoarrow%200.9.0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Windows on Arm support:** Microsoft and Linaro proposed a plan to support `win_arm64` for PyArrow, offering engineering resources for ABI3 stable builds and build path consolidation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Swift version upgrade:** Discussion on raising the minimum required Swift version to 6.0 to support native `Int128` types and better align with modern dependencies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Limit on concurrent PRs:** Proposal to restrict non-committers to three open PRs at a time to reduce the maintenance burden caused by stale or potentially AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal Type:** A proposal and vote were initiated for a `arrow.big_decimal` extension type to handle variable-scale numeric data, though discussions continue regarding the underlying representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Variant spec alignment:** Efforts are underway to ensure the Arrow Variant extension specification is fully consistent with the Parquet shredding specification, specifically regarding disallowed types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Community recognition:** Jeffrey Vo was invited to join the Arrow PMC, and Tadeja Kadunc was welcomed as a new committer for her significant contributions to CI maintenance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed with Apache Arrow as its native foundation for data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)
