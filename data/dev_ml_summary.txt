* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, resolving 337 issues across the project including various C++, Python, and integration improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **PyArrow modularity and multi-wheel split:** Developers are discussing a plan to split PyArrow into multiple optional "side-wheels" (e.g., pyarrow-s3) to significantly reduce the base package size and maintenance burden on PyPI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **CI optimization proposal:** A proposal was introduced to reduce GitHub Actions runner usage by 30-40% by optimizing merge workflows, using slim runners for bot tasks, and reducing redundant runs for PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **Arrow Rust 60.0.0 major release:** The Rust community released version 60.0.0, featuring new Parquet encoding support, major kernel performance improvements, and a sustained effort to eliminate panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical range extension types:** A vote is underway to add fixed and variable closedness range types to the Arrow format specifications to support interoperability with PostgreSQL intervals and pandas IntervalArray. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary extension types:** Discussion on updating the IPC format to allow `DictionaryEncoding` to carry custom metadata for value types, resolving a hole in Arrow's type model for complex extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Substrait dialect discovery in FlightSQL:** Proposal to add new SqlInfo codes to FlightSQL allowing servers to advertise their specific supported Substrait dialects for better client-side plan validation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC driver contribution:** IBM has proposed contributing a new native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON representation of Arrow schemas:** Ongoing discussion to standardize a JSON format for representing Arrow schemas to facilitate data contracts in config files and cross-process communication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)

* **New committer announcement:** Richard Baah has been invited and has accepted to become the newest committer on the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Richard%20Baah)
