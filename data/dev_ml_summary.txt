* **Arrow 25.0.1 release:** The community approved the patch release of version 25.0.1, which includes performance optimizations for nested type conversions to Python lists and various bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Windows on Arm (win_arm64) support:** Microsoft proposed a plan to support PyArrow on Windows Arm64, offering dedicated engineering resources for build consolidation and CI hardware for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limits on concurrent PRs:** Discussion on implementing a limit of three open pull requests for non-committers to manage an increase in stale and potentially AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Canonical BigDecimal extension type:** A proposal for a new `arrow.big_decimal` type to better represent variable-scale numeric data from systems like PostgreSQL and Oracle during transport. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language that uses Apache Arrow as its native foundation for data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant and Parquet spec alignment:** Discussion on resolving inconsistencies between the Arrow Variant extension and Parquet shredding specifications, specifically regarding the handling of unsigned integers and nulls. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift 6.0 minimum version:** Proposal to raise the minimum supported version for the Arrow Swift implementation to 6.0 to modernize the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Lazy memory mapping for Parquet:** Introduction of a library called "faultcache" that allows Parquet columns to be mapped lazily to zero-copy NumPy arrays through custom page fault handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Community updates:** The project announced Jeffrey Vo as a new PMC member, alongside new committers Tadeja Kadunc and Zehua Zou. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
