* **Conbench evolution:** Wes McKinney proposed a new architecture for the Conbench benchmarking tool, moving toward Parquet storage and DuckDB queries to improve scalability and UI flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **Deprecation of Tensor messages:** The community voted to informally deprecate Tensor and SparseTensor IPC messages due to a lack of multi-language implementation support and limited use. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal GPU compute:** A new project called ArrowMetal was announced, enabling Arrow compute kernels to run on Apple silicon GPUs via Metal and the C Device Data Interface. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **macOS Intel support:** Developers discussed dropping official CI support for macOS Intel (x86_64) following Homebrew's deprecation and significant ecosystem shifts toward ARM-based hardware. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Canonical FILE extension:** Discussion on introducing `arrow.parquet.file` as a canonical extension type to preserve Parquet file-level reference semantics across the Arrow ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Standardizing Range types:** The community is refining a proposal for an `arrow.range` canonical extension type to support bounded ranges with configurable closedness parameters. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)

* **AI contribution guidelines:** Proposal to update reviewer documentation with procedures for handling low-quality AI-generated PRs and a new "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Rust 60.0.0 release:** A major version of the Rust implementation was released, introducing support for Adaptive Lossless Floating-Point (ALP) encoding and Parquet PageIndex structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Big Decimal proposal pause:** Active work on the `arrow.big_decimal` extension has been paused to allow for deeper research into existing project requirements and ecosystem decimal patterns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)
