* **Improve modularity of PyArrow:** Proposal to split PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce package size and allow users to install specific modules as optional dependencies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 Release:** The community announced the release of version 26.0.0, resolving over 330 issues across the C++, Python, and other core implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **IPC representation for dictionary-encoded extension types:** Discussion and implementation of a format change to allow `custom_metadata` on dictionary value types, ensuring IPC can correctly represent extension types like UUIDs when dictionary-encoded. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Range canonical extension types:** Proposal and voting on two new canonical extension types, `fixed_closedness_range` and `variable_closedness_range`, to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM contributors proposed adding a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **CI runner optimization:** A detailed proposal suggests reducing GitHub Actions runner usage by 30-40% through selective job triggering for merges and nightly subsets for heavy package builds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%7E30-40%25%20fewer%20runner%20minutes)

* **Substrait dialect advertisement in Flight SQL:** Proposal to add new `SqlInfo` codes that allow Flight SQL servers to describe which parts of the Substrait specification they support via dialect files. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Arrow Rust 60.0.0 Release:** Major release of the Rust implementation including new Parquet encoding support, significant kernel performance improvements, and an effort to remove panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **ADBC logo selection:** The community reached a consensus on a new logo and visual identity for the ADBC (Arrow Database Connectivity) subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)

* **New Arrow Committer:** Richard Baah has accepted an invitation to become a new committer on the project following his recent contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Richard%20Baah)
