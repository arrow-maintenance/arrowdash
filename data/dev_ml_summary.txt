* **Apache Arrow 25.0.1 release:** The community released version 25.0.1, a maintenance release following version 25.0.0 that addresses nine resolved issues across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limit on concurrent open PRs:** Discussion is underway to limit non-committers to three concurrent open pull requests to mitigate the impact of stale or low-quality AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal:** A proposal for a canonical `arrow.big_decimal` extension type was introduced to handle arbitrary-precision decimals but has been paused to better define compute kernel requirements and cross-implementation alignment. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages within the IPC protocol due to limited implementation support and rare usage in the wild. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Canonical extension for FILE type:** Developers are discussing the addition of an `arrow.parquet.file` extension type to provide a standard in-memory representation for the new Parquet FILE LogicalType. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Variant and Parquet shredding consistency:** Discussion on refining the Variant extension specification to explicitly disallow shredded columns, such as unsigned integers, that do not have direct equivalents in the Variant format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **New committers:** Tadeja Kadunc, Zehua Zou, and Kosta Tarasov were invited as new committers in recognition of their significant contributions to CI maintenance and the Go and Rust implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Glasgow Hackathon 2026:** An Arrow community hackathon has been announced for the Community Over Code conference in Glasgow on October 13, focusing on both documentation and core code contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Rust and Go releases:** Version 59.3.0 of the Rust implementation was released, while the Go 18.8.0 release candidate addressed build compatibility issues with the Go 1.27 toolchain. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEGo%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)
