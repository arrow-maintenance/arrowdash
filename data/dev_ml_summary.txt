* **PyArrow modularity and wheel size:** Discussion on splitting the monolithic PyArrow package into multiple smaller wheels (e.g., `pyarrow-s3`, `pyarrow-flight`) to reduce installation size and maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, resolving over 330 issues across the C++, Python, and other implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Canonical extension types for ranges:** Proposal and vote for adding fixed and variable "closedness" range types to the Arrow canonical extension types to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation for dictionary extension types:** Proposal to update the IPC format to support metadata on dictionary-encoded values, allowing for the proper representation of extension types within dictionaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **GitHub Actions CI optimization:** Analysis and discussion on reducing Arrow's CI runner usage by ~30-40% through improved job scheduling, labeling, and nightly workflow adjustments. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%28~30-40%25%20fewer%20runner%20minutes%29)

* **Substrait dialect advertising in Flight SQL:** Proposal to allow Flight SQL servers to communicate their supported Substrait features and dialects to clients via new SqlInfo codes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **ADBC 25 release and IBM Db2 contribution:** Following the release of ADBC version 25, IBM proposed contributing a native C++ ADBC driver for IBM Db2 for LUW. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Arrow Rust 60.0.0 and maintenance releases:** The Rust implementation released major version 60.0.0, followed by coordinated patch releases across several active branches (57, 58, 59, and 60). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Rust%20patch%20releases%20for%2057,%2058,%2059%20and%2060%20branches)

* **JSON representation of schemas:** Continued refinement of a standardized JSON format for Arrow schemas, including logic for handling Sparse/Dense Union types and nested structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)
