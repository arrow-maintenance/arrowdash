* **Arrow 25.0.0 release:** The community released version 25.0.0 with over 220 resolved issues, while planning a 25.0.1 patch to address PyArrow performance regressions in `to_pylist` reported by Spark developers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion is underway to define a formal JSON spec for Arrow schemas to improve interoperability for REST APIs and ADBC while balancing human readability and machine-friendly formatting. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable complex fields:** Developers debated the meaning of the `nullable` flag in IPC for nested types, exploring whether child arrays must match parent lengths or if sparse representations could be adopted to avoid data duplication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Swift 6.0 version proposal:** A proposal was made to raise the minimum Swift version for the Arrow Swift implementation to 6.0, enabling native support for `Int128` types and improving Decimal implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **C Data Interface NUL byte clarification:** Technical discussion clarified that producers using the C Data Interface should error out if field names contain embedded NUL bytes, as the interface relies on C-style NUL-terminated strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **ADBC 24 release and documentation overhaul:** The ADBC subproject released version 24 and significantly updated its documentation to better distinguish between core drivers and those provided by external vendors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Documentation%20overhauled%20for%20ADBC)

* **Variant extension spec inconsistency:** Contributors identified a discrepancy between the Arrow and Parquet specs regarding allowed unsigned integer types in shredded Variant `typed_value` columns, proposing a refresh to ensure round-trip compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **New PMC Member Appointment:** Jeffrey Vo (Jefffrey) has been invited and appointed as a new member of the Apache Arrow Project Management Committee (PMC). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20(Jefffrey))
