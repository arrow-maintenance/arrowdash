* **Apache Arrow 26.0.0 release:** The community approved the release of version 26.0.0, which resolves over 330 issues and includes initial support and verification for Python 3.15. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 release:** A major update for the Rust implementation was announced, featuring support for the new ALP Parquet encoding and significant performance improvements for kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Proposed PyArrow modularity:** Discussion is ongoing regarding splitting PyArrow into smaller, modular wheels (e.g., `pyarrow-s3`) to reduce the core package's installation size and maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Deprecating macOS Intel support:** Developers proposed dropping official CI support for macOS Intel (x86_64) due to Homebrew's deprecation and data showing that these machines account for less than 0.1% of recent PyArrow downloads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** The community is establishing new reviewer guidelines and a "needs-author-engagement" GitHub label to handle low-quality AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Range canonical extension types:** A vote is in progress to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` as new canonical extension types for representing bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Discussion continues on standardizing a JSON format for schemas to improve data contracts and cross-language compatibility for configuration-driven workflows. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **ADBC visual identity:** The Arrow Database Connectivity (ADBC) subproject is finalizing its new logo and visual identity based on community feedback and design iterations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)

* **Rust Object Store 0.14.2 release:** The Rust-based Object Store implementation version 0.14.2 was approved and released following successful verification on multiple architectures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%20Object%20Store%200.14.2%20RC2)
