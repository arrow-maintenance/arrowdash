* **Apache Arrow 25.0.0 and 25.0.1 releases:** Major release 25.0.0 was finalized, followed quickly by a 25.0.1 patch to address performance regressions in PyArrow's `to_pylist` affecting Spark users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2025.0.0%20released)

* **JSON representation of Arrow schemas:** Discussion on a proposed human-readable JSON format for schemas to simplify use in REST APIs and ADBC, debating verbosity and how to handle extension type metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Windows Arm64 support for PyArrow:** Microsoft and Linaro proposed a plan to provide win_arm64 wheels, committing engineering time to implement abi3 support and a unified Windows build path to reduce maintenance burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Swift 6.0 minimum version proposal:** Proposal to raise the minimum Swift version to 6.0 to utilize native Int128 support, which is essential for implementing Decimal types in the Swift columnar implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Semantics of non-nullable fields in complex types:** Architectural discussion on how the `nullable` flag should be interpreted for child fields in nested structures, such as structs where the parent itself may be null. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **ADBC 24 release and documentation site overhaul:** Release of the latest ADBC libraries alongside a restructured documentation site that clarifies the landscape of ASF-maintained versus vendor-provided database drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%20ADBC%2024%20Released)

* **Variant extension spec inconsistency:** Review of inconsistencies between the Arrow Canonical Extension and Parquet Shredding specifications regarding support for unsigned integer types in shredded Variant columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **C Data Interface field name safety:** Discussion on handling embedded null bytes in field names within the C FFI to prevent crashes and ensure robust validation when importing schemas from external producers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)
