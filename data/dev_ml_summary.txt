* **Apache Arrow 25.0.1 release:** The community released version 25.0.1, which includes nine resolved issues following the 25.0.0 release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limit on concurrent open PRs for non-committers:** Discussion is ongoing about limiting contributors without write access to three concurrent open pull requests to manage an uptick in low-value and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension proposal paused:** The proposal for a `arrow.big_decimal` canonical extension type has been paused to better evaluate ecosystem requirements and the scope of necessary compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol, encouraging implementations to move away from these metadata types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Canonical Extension Type for FILE type:** A new proposal suggests creating an `arrow.parquet.file` extension type to provide a standard in-memory representation for file-level references, aligning with recent Parquet format changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed with Apache Arrow as the native foundation for its data types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **New committer announcements:** Tadeja Kadunc, Zehua Zou, and Kosta Tarasov were welcomed as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Apache Arrow Go 18.8.0 release:** Voting is underway for the Go implementation's 18.8.0 release, with the second release candidate addressing build compatibility issues for Go 1.27. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEGo%20Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **Lazy memory mapping for Parquet:** Discussion regarding a new library, `faultcache`, which uses custom fault handling to lazily map Parquet columns to memory, hiding row-group boundaries from the caller. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSParquetCPython%20Lazy%20memory%20mapping)
