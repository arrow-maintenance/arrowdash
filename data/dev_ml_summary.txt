* **Apache Arrow 26.0.0 release:** The community approved the release of version 26.0.0, which resolves over 300 issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Apache Arrow Rust 60.0.0 release:** Version 60.0.0 of the Rust implementation was released, featuring support for the new ALP encoding in Parquet and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **PyArrow modularity proposal:** Discussion on breaking down PyArrow into multiple optional wheels (e.g., `pyarrow[s3]`) to reduce the installation size and maintenance burden of the current monolithic package. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** A proposal to stop supporting Intel-based macOS in CI and official binaries was met with general consensus, cited by Homebrew's deprecation and low usage statistics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** Developers discussed how to handle low-quality AI-generated pull requests, proposing a new "needs-author-engagement" label to flag PRs where the author shows limited understanding of the changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **New canonical extension types for ranges:** A vote was initiated to add `fixed_closedness_range` and `variable_closedness_range` to the official Arrow specification to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** The community is refining a standardized JSON format for Arrow schemas, with recent focus on correctly representing union types and field aliases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **ADBC logo adoption:** Following design iterations, the ADBC (Arrow Database Connectivity) subproject has reached a lazy consensus on a new official logo and visual identity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)

* **Rust Object Store 0.14.2 release:** A minor release for the Rust object-store crate was approved after fixing a minor license header issue discovered during the first release candidate. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%20Object%20Store%200.14.2%20RC2)
