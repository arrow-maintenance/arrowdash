* **PyArrow modularity:** Proposal to split PyArrow into multiple wheels (e.g., pyarrow-s3) to reduce package size and allow users to install only the storage backends they need. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Arrow Rust 60.0.0:** Major release featuring support for the new Adaptive Lossless Floating-Point (ALP) Parquet encoding and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Arrow 26.0.0 Release:** Voting and verification for the next major release, covering over 300 resolved issues and adding support for Python 3.15. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Range Canonical Extension Types:** Formal vote to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **macOS Intel Deprecation:** Discussion on ending support for Intel-based Macs due to CI maintenance difficulties as Homebrew and Apple move away from the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contributions:** Proposal to update reviewer guidelines with specific procedures for handling low-quality AI PRs and a new "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **ArrowMetal:** Announcement of a new project that enables Arrow compute kernels on Apple Silicon GPUs using the Metal framework. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **JSON Schema Representation:** Ongoing work to standardize a JSON format for Arrow schemas to simplify data contract definitions and cross-process communication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **Tensor Deprecation in IPC:** The community approved the informal deprecation of Tensor and SparseTensor in the IPC format to reduce specification complexity. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ADBC Logo:** New design exploration and proposal for a distinct logo for the Arrow Database Connectivity (ADBC) subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)
