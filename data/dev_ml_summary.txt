* **Limit on concurrent open PRs:** Proposal to limit non-committers to three concurrent open pull requests to manage a recent increase in low-value, potentially AI-generated contributions that often go stale. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal:** A proposal for an `arrow.big_decimal` canonical extension type was paused to further evaluate ecosystem practices and requirements for compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Deprecation of Tensor and SparseTensor:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol, encouraging implementations to deprecate related reading and writing APIs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **FILE canonical extension type:** Discussion on introducing a new `arrow.parquet.file` extension type to provide an in-memory Arrow representation that aligns with the recently added Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language designed to use Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Future of Conbench:** Discussions regarding the Arrow benchmarking infrastructure focused on a potential redesign where data is stored in Parquet files and queried via DuckDB rather than using Postgres. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **Apache Arrow 25.0.1 Release:** The community announced the release of version 25.0.1, which includes nine resolved issues found since the 25.0.0 release. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **New Committers:** Tadeja Kadunc, Zehua Zou, and Kosta Tarasov were welcomed as new committers to the Apache Arrow project for their contributions to CI maintenance and format implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Tadeja%20Kadunc)

* **Arrow Rust 59.3.0:** The Rust implementation of Arrow saw a new release following successful verification of the second release candidate. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)
