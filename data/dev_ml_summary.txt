* **Informal deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to a lack of multi-language implementation support. This move encourages implementations to phase out these specific metadata and data reading/writing APIs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal 0.1.0 announcement:** A new project called ArrowMetal was announced, providing Arrow compute kernels that run natively on Apple silicon GPUs via Metal. It uses the C Device Data Interface to allow zero-copy shared memory between CPU and GPU across multiple languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Major release of Arrow Rust 60.0.0:** Version 60.0.0 of the Rust implementation was released, featuring support for the new Adaptive Lossless Floating-Point (ALP) encoding in Parquet. The update also includes new Parquet PageIndex structures and significant performance improvements for compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical Extension Type for FILE type:** Discussion is underway to define `arrow.parquet.file` as a canonical extension type to match the Parquet FILE logical type. This will provide a standardized in-memory representation for file-level references like URIs, offsets, and checksums. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **AI-generated contributions and reviewer guidelines:** Developers discussed establishing stricter guidelines for reviewers to handle low-quality PRs with weak author engagement, often associated with AI generation. Proposals include a "needs-author-engagement" GitHub label to flag PRs requiring more meaningful interaction from the contributor. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Drop macOS Intel support:** A proposal was made to drop support for macOS Intel (x86_64) because Homebrew has stopped supporting Intel bottles, making CI maintenance increasingly difficult. Statistics suggest that while a small percentage of users remain on Intel Macs, the burden of verifying compatibility without reliable CI is becoming unsustainable. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Multi-wheel modularity for PyArrow:** A proof-of-concept was shared to split PyArrow into multiple wheels (e.g., `pyarrow-s3`) to reduce the monolithic 2.1 GB release size. This approach would allow users to install a core package and optionally add specific libraries as needed via extras. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **JSON representation of Arrow schemas:** The community is refining the standardized JSON format for representing Arrow schemas (Draft-02). This effort aims to improve cross-platform metadata interchange and has entered the implementation phase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Go 18.8.0 release:** The Go implementation reached version 18.8.0, resolving build issues encountered with Go 1.27 and updating the compute registry. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Standardizing arrow.range extension type:** Discussions resumed on creating a canonical `arrow.range` extension type for bounded ranges. The proposal suggests a single range type with a "closedness" parameter to handle various boundary behaviors uniformly across implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges)
