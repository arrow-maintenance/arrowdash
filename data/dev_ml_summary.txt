* **Arrow Rust 60.0.0 release:** Major release featuring support for the new Adaptive Lossless Floating-Point (ALP) Parquet encoding, kernel performance improvements, and reduced usage of panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **ArrowMetal announcement:** Introduction of a new project providing Arrow compute kernels for Apple Silicon GPUs via Metal, supporting zero-copy shared memory between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **PyArrow modularity proposal:** Discussion on splitting PyArrow into multiple wheels (e.g., pyarrow-s3) to reduce the monolithic package size and simplify installations for users with specific needs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Proposal to discontinue support for macOS on Intel CPUs due to Homebrew dropping support and the resulting inability to maintain reliable CI testing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contribution guidelines:** Proposal to establish reviewer-specific guidelines for handling low-quality or high-volume PRs generated by AI, including the potential use of a "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Arrow Go 18.8.0 release:** New release containing 283 commits across Arrow, Flight, FlightSQL, and Parquet Go implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Deprecation of Tensor types in IPC:** The community voted to informally deprecate Tensor and SparseTensor types in the IPC format and C++ API in favor of other representation methods. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **New canonical extension types:** Continued progress on standardizing `arrow.range` for bounded ranges and `arrow.parquet.file` for Parquet-specific file metadata representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Add%20arrow.range%20canonical%20extension%20type%20for%20bounded%20ranges) | [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)
