* **Major releases of Apache Arrow 25.0.0 and 25.0.1:** The community finalized the 25.0.0 release and a subsequent 25.0.1 patch release, resolving over 200 issues including performance improvements for nested type conversions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Canonical BigDecimal extension type proposal:** Discussion and voting on a new `arrow.big_decimal` extension type to provide a standardized way to represent variable-scale decimals common in database systems. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Windows ARM64 support for PyArrow:** Microsoft and Linaro proposed a plan to provide `win_arm64` wheels, offering dedicated engineering resources and hardware to maintain the platform's CI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limits on concurrent PRs for non-committers:** Proposal to limit non-committers to three concurrent open pull requests to manage an uptick in stale or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Release of Apache Arrow ADBC 24:** The ADBC subproject released version 24, which includes 57 bug fixes and a major overhaul of the project's documentation site. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Semantics of nullability in non-trivial types:** Technical debate regarding how the `nullable` flag should be interpreted in the IPC format for nested structures, such as structs with logically null child elements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant extension spec vs. Parquet shredding:** Identification of inconsistencies between the Arrow Variant extension and Parquet shredding specs regarding unsigned integer support and null type mappings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Raising minimum Swift version to 6.0:** Proposal to move the Swift implementation to version 6.0 to utilize native `Int128` support for high-precision decimal arithmetic. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Release of nanoarrow 0.9.0:** The lightweight C-based nanoarrow library reached version 0.9.0, resolving 38 issues across its R and Python bindings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **New community members:** The project welcomed Jeffrey Vo to the Project Management Committee (PMC) and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)
