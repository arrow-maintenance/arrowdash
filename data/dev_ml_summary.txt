* **Arrow 26.0.0 release:** The community approved the release of version 26.0.0, which resolves 337 issues and includes fixes for Python 3.15 and simdjson compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and multi-wheel installation:** Proposal to split PyArrow into smaller, optional side-wheels (e.g., `pyarrow[s3]`) to reduce the 2.1 GB total wheel size and installation burden. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on removing CI support for Intel-based Macs due to Homebrew deprecating support for those bottles and declining user numbers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Guidelines for AI-generated contributions:** Proposal to add reviewer-specific guidance and a "needs-author-engagement" label to effectively manage low-quality or poorly supported AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Canonical extension types for ranges:** A vote was held to introduce `fixed_closedness_range` and `variable_closedness_range` as standard extension types for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary-encoded extension types:** Proposal to add custom metadata support to `DictionaryEncoding` so that IPC and the C Data Interface can properly represent extension types within dictionaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 driver contribution to ADBC:** IBM engineers expressed intent to contribute a native C++ ADBC driver for Db2 (LUW) to the Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **JSON representation of Arrow schemas:** Technical discussion on standardizing a JSON format for schemas to facilitate data contract definitions in configuration files and cross-process communication. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Arrow Rust 60.0.0 release:** Announcement of the latest major Rust implementation release, featuring new Parquet encoding support and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **FILE canonical extension type:** The community finalized the naming of the "arrow.parquet.file" extension type following a format change proposal to represent file-based data references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)
