* **Apache Arrow 25.0.0 and 25.0.1 releases:** The community released version 25.0.0 with 222 resolved issues, quickly followed by a 25.0.1 patch release to address critical bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Semantics of non-nullable fields:** Technical discussion regarding how the `nullable` flag in the IPC format should be interpreted for complex types, such as structs with null parents or dictionary arrays with null values in the dictionary. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Windows on Arm support for PyArrow:** Microsoft engineers proposed a plan to enable `win_arm64` support, including a commitment to consolidate Windows build paths and provide hardware for maintenance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **BigDecimal Canonical Extension Type:** Formal proposal and vote for a new `arrow.big_decimal` extension type to provide high-fidelity representation for variable-scale numeric data often found in databases like PostgreSQL and Oracle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limiting concurrent PRs for non-committers:** Discussion on implementing a limit (suggested at 3) on concurrent open pull requests for contributors without write access to manage stale or low-value AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Swift version requirement increase:** Proposal to raise the minimum Swift version to 6.0 to unlock native `Int128` support, which is essential for implementing Decimal types in the Swift library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Apache Arrow ADBC 24 release:** The ADBC subproject released version 24, which includes significant documentation overhauls and clarifies how drivers are developed by external vendors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Variant extension and Parquet shredding inconsistency:** Identification of discrepancies between the Arrow Variant extension specification and the Parquet shredding specification regarding supported primitive type mappings like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)
