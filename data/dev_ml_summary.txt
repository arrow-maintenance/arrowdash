* **Sovereign Tech Fund backs PyArrow:** German government-backed Sovereign Tech Agency will fund about 1.9 FTE of PyArrow work through 2027, covering type annotations, the stalled issue backlog, AI-contribution tooling, documentation and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **Arrow 26.0.1 patch release:** The vote passed with 7 binding +1s and the release shipped on Nov 4. It includes the Brotli CVE-2026-111497 fix, which maintainers had asked to be backported. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20%28GH-55165%29%20in%2026.0.1)

* **Arrow Rust patch releases:** Several maintenance releases were voted through in November, including 60.1.0, 59.3.3, 58.4.2, 57.3.3 and 60.2.0, all approved with binding votes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1)

* **Arrow Java 20.0.0 and release cadence:** Java 20.0.0 was released on Nov 21 after its vote passed, and it raises the minimum to Java 17. A follow-up proposal to release Arrow Java at least quarterly was broadly supported. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **FILE canonical extension type:** A proposal to add `arrow.parquet.file` as a canonical extension type went to vote. Some members argued that Parquet-specific types should instead be defined by the Parquet project, so the discussion may move to the Parquet list. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Flight SQL Substrait dialect codes:** A vote proposes two new SqlInfo codes, one for the Substrait dialect YAML and one for a content hash used for client caching. The change is backward-compatible and early votes are positive. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **ADBC 1.2 planning:** A planning session scoped the 1.2 milestone, which has 36 open items, and excluded async from this release. Metadata, credential callbacks, structured error details, vendor actions and partitioned bulk ingest remain under discussion, with no target date set. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **AI-generated contributions policy:** Maintainers agreed to add two PR labels, one asking authors to explain their change in their own words and one closing PRs that miss expected AI-usage disclosure. The aim is to reduce maintainer burden through automation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Copilot auto-review costs:** Automatic Copilot reviews on every push were billed to individual contributors' accounts. The team agreed to stop auto-reviewing on push, and a PR to disable it was posted. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Auto%20GitHub%20Copilot%20review)

* **GitHub pull_request_target restriction:** GitHub will restrict the `pull_request_target` trigger from December 2, with brownouts on November 9 and 16. Arrow repos are migrating affected workflows, and the Boring Cyborg labeling bot was enabled across the Arrow repos. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)
