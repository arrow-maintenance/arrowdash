* **Apache Arrow 25.0.0 released:** The community announced the release of Apache Arrow 25.0.0, which includes over 200 resolved issues across the ecosystem and significant updates to various language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Semantics of non-nullable fields with non-trivial types:** Developers are debating the exact meaning of the `nullable` flag in the IPC format for complex types like structs with null parents or dictionaries with logically null values. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Windows ARM64 support plan for PyArrow:** Microsoft proposed a formal commitment to support `win_arm64` wheels for PyArrow, offering dedicated engineering resources and CI hardware to the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Proposal to raise minimum Swift version to 6.0:** A discussion was opened to increase the minimum Swift version for the Arrow Swift implementation to 6.0 to leverage native `Int128` support for decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension spec vs. Parquet shredding spec:** Contributors identified inconsistencies between the Arrow Variant extension specification and the Parquet shredding specification regarding unsigned integer support and representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Apache Arrow ADBC 24 and documentation overhaul:** The ADBC subproject released version 24 of its libraries alongside a major documentation rewrite to better clarify driver sources and vendor integrations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Proposed limit on concurrent PRs for non-committers:** To manage an uptick in stale or low-quality AI-generated contributions, a proposal suggests limiting the number of concurrent open pull requests allowed for contributors without write access. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Release of nanoarrow 0.9.0:** The nanoarrow 0.9.0 release was finalized, resolving 38 issues and improving the lightweight C library's integration with Python and R. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20nanoarrow%200.9.0)

* **New PMC member Jeffrey Vo:** The Project Management Committee invited Jeffrey Vo (Jefffrey) to join as a member following his sustained contributions to the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
