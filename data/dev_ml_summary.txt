* **Arrow 25.0.0 release:** Major release including over 220 resolved issues across the ecosystem, featuring performance improvements and bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on creating a canonical human-readable JSON format for schemas to improve ergonomics for JSON APIs and metadata boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Deprecating Tensor IPC messages:** Proposal to deprecate the experimental dedicated Tensor and SparseTensor IPC messages in favor of using canonical extension types within standard RecordBatches. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Deprecate%20Tensor%20and%20SparseTensor%20messages)

* **Semantics of non-nullable fields:** Technical debate regarding how implementations should handle the `nullable` flag in nested types, such as when a parent struct is null but its child fields are marked non-nullable. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Variant and Parquet shredding inconsistencies:** Discussion on resolving discrepancies between the Arrow Variant extension spec and the Parquet shredding specification, specifically concerning supported primitive type mappings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Swift 6.0 upgrade proposal:** Proposal to raise the minimum Swift version to 6.0 to leverage native Int128 support for high-precision decimal arithmetic. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **ADBC 24 release and documentation overhaul:** Release of new Arrow Database Connectivity libraries alongside a complete overhaul of the documentation to better explain vendor-developed drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2024%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Documentation%20overhauled%20for%20ADBC)

* **Field name handling in C FFI:** Investigation into how the C Data Interface should handle embedded nul bytes in field names to prevent round-trip failures or application panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)
