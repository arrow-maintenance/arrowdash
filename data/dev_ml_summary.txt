* **Apache Arrow 26.0.0 and 26.0.1 releases:** The community released version 26.0.0 with over 300 resolved issues, followed shortly by a 26.0.1 patch to update the bundled Brotli dependency to fix CVE-2026-111497. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.1%20released)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed Sovereign Tech Fund will contract research and development work for PyArrow through 2027, focusing on type annotations, extension type support, and improved documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **Apache Arrow ADBC 25 release:** The ADBC subproject released version 25, which includes 57 bug fixes and improvements across multiple language implementations including C++, Go, Python, and Java. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2025%20Released)

* **GitHub Actions CI optimization and migration:** Developers discussed strategies to reduce GitHub Actions runner minutes by ~30-40% and began migrating workflows away from the `pull_request_target` trigger ahead of upcoming GitHub security restrictions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **AI-generated contribution policies:** Discussion on managing the influx of AI-generated pull requests, with proposals for mandatory disclosure and using specific labels to ensure human engagement before review. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Rust implementation patch releases:** The Rust community coordinated simultaneous patch releases across the 57, 58, 59, and 60 release branches to backport critical bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RUST%20Rust%20patch%20releases%20for%2057%2C%2058%2C%2059%20and%2060%20branches)

* **Dictionary-encoded extension types in IPC:** A proposal and series of PRs were introduced to allow the Arrow IPC format to represent dictionary-encoded extension types by attaching metadata to the dictionary value type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait dialect advertising:** Proposal to add new `SqlInfo` codes to Flight SQL that allow servers to advertise their specific supported Substrait dialects and capabilities to clients. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 driver contribution to ADBC:** IBM proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
