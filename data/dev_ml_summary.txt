* **Windows Arm64 support for PyArrow:** Microsoft proposed a comprehensive plan to add win_arm64 build support, offering dedicated engineering resources from Linaro and hardware for maintainers to help with triage and testing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Swift 6.0 migration proposal:** Discussion on raising the minimum Swift version to 6.0 to leverage native Int128 support, which is essential for implementing robust Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Limits on concurrent open PRs:** Proposal to limit the number of open pull requests for non-committers (suggested limit of 3) to manage an uptick in low-value and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Arrow 25.0.1 patch release:** The community released version 25.0.1, featuring several bug fixes and significant performance improvements for converting nested types to Python lists. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Canonical BigDecimal extension type:** A formal vote was initiated for a `BigDecimal` extension type to support variable-scale decimals, though some maintainers suggest further discussion is needed on the underlying representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Presentation of Arx, an experimental programming language that uses Apache Arrow as its native foundation for data types, arrays, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant and Parquet spec alignment:** Technical discussion regarding inconsistencies between the Arrow Variant extension and the Parquet shredding specification, specifically concerning types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Arrow ADBC 24 release:** The ADBC subproject released version 24, resolving over 50 issues across multiple language bindings including C++, Go, Java, and Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Nanoarrow 0.9.0 and Rust 59.2.0 releases:** Both the nanoarrow and Rust implementations saw new releases, with nanoarrow 0.9.0 addressing 38 issues and Rust 59.2.0 providing a stable update for the community. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Community updates:** The PMC announced the addition of Jeffrey Vo to the Project Management Committee and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
