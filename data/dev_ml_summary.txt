* **Windows on Arm support for PyArrow:** Microsoft and Linaro proposed a plan to support `win_arm64` builds, including commitments for maintenance and providing hardware to maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Limiting concurrent pull requests:** Discussion on implementing a limit of 3 concurrent open PRs for non-committers to help manage maintainer load and the influx of low-quality AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal canonical extension type:** Proposal for a new extension type to represent variable-scale decimals, facilitating better interoperability with RDBMS types like PostgreSQL's NUMERIC. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers presented Arx, an experimental programming language built with Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Apache Arrow 25.0.1 maintenance release:** The community approved and released version 25.0.1, featuring performance optimizations for nested types and critical bug fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Lazy memory mapping for Parquet:** Discussion regarding a new library approach that uses fault handling to lazily map Parquet columns to NumPy arrays for zero-copy access. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Upcoming Glasgow hackathon:** Plans are being finalized for an Arrow hackathon at the Community Over Code conference in Glasgow this October, including the curation of task lists for attendees. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Rust implementation releases:** The Rust implementation saw active release cycles this month with version 59.2.0 and version 59.3.0 to address regression fixes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)

* **Community growth:** The project welcomed Jeffrey Vo as a new PMC member, while Tadeja Kadunc and Zehua Zou were appointed as new committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20%28Jefffrey%29)
