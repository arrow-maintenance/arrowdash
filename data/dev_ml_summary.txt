* **Apache Arrow 25.0.1 release:** The community released version 25.0.1, a patch release including nine resolved issues following the 25.0.0 milestone. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limit on concurrent PRs for non-committers:** Discussion on implementing a limit of three concurrent open pull requests for contributors without write access to mitigate the influx of low-value or AI-generated PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal canonical extension type:** A proposal to introduce an `arrow.big_decimal` type for arbitrary-precision decimals was paused to allow for broader research into compute kernel requirements and existing ecosystem patterns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages within the IPC protocol, encouraging implementations to move away from these under-utilized features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **FILE canonical extension type:** Proposal to add an `arrow.parquet.file` extension type to provide a native Arrow representation for the new Parquet FILE logical type, facilitating file-level references across IPC and Flight. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language built with Apache Arrow as its native foundation for data structures and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant extension spec alignment:** Discussion regarding making the Arrow Variant extension specification consistent with Parquet shredding by explicitly disallowing types like unsigned integers that have no equivalent in Variant. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Lazy memory mapping for Parquet:** A proposal and prototype for using custom page fault handling to map Parquet columns lazily to memory, allowing for vectorized operations over entire columns without explicit row-group management. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **New project committers:** The community welcomed Tadeja Kadunc, Zehua Zou, and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Tadeja%20Kadunc)
