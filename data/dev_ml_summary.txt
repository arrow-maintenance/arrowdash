* **Arrow 26.0.0 release:** The community approved the release of Apache Arrow 26.0.0, which includes over 337 resolved issues across the core libraries and multiple language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 release:** A major update for the Rust implementation was released, featuring support for the new Adaptive Lossless Floating-Point (ALP) encoding in Parquet and significant performance gains in kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **PyArrow modularity and wheel size:** A proposal was made to split PyArrow into multiple wheels (e.g., separating S3 support into `pyarrow-s3`) to reduce the installation size, which currently exceeds 2GB. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Developers discussed dropping official support for macOS Intel (x86_64) binaries due to low usage statistics and the increasing difficulty of maintaining CI pipelines following Homebrew's deprecation of the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **Range canonical extension types:** A formal vote was initiated to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` to the project's canonical extensions to support bounded intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **AI-generated contribution guidelines:** To maintain code quality, the community is establishing reviewer protocols for handling low-quality AI-generated pull requests, including a new "needs-author-engagement" GitHub label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **JSON representation of Arrow schemas:** Discussions continued on standardizing a JSON format for schemas to facilitate cross-language data contracts and configuration, with a focus on supporting union types and string aliases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **CSV date and time parsing improvements:** A long-standing pull request is being reviewed to allow the CSV reader to use `timestamp_parsers` as a fallback for date columns, enabling support for non-ISO-8601 formats. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2BPython%20Getting%20PR%20%2350146%20%28CSV%20date%2Ftime%20parsing%2C%20GH-41488%29%20reviewed)

* **Rust Object Store 0.14.2 release:** The object store crate was updated to version 0.14.2 following a release candidate cycle that addressed a missing license header issue. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%20Object%20Store%200.14.2%20RC2)
