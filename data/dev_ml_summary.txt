* **Arrow 25.0.0 release:** The community finalized the major release of version 25.0.0, which resolves over 220 issues across the ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **JSON representation of Arrow schemas:** Discussion on creating a canonical, human-readable JSON format for schemas to simplify use in non-binary API contracts like ADBC metadata. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Deprecating Tensor IPC messages:** Proposal to deprecate dedicated IPC messages for Tensors and SparseTensors in favor of the newer, more flexible canonical extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Deprecate%20Tensor%20and%20SparseTensor%20messages)

* **Nullability semantics for nested types:** Investigation into how the `nullable` flag should be logically interpreted for child fields in complex types like structs and dictionary-encoded arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Swift 6.0 upgrade proposal:** Discussion on raising the minimum Swift version to 6.0 to leverage native `Int128` support for decimal types and improved concurrency safety. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **C Data Interface field name safety:** Clarification on how the C FFI should handle field names containing null bytes, with a consensus to error out on the producer side to prevent round-trip failures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **Variant extension spec alignment:** Identification of inconsistencies between the Arrow Variant extension and the Parquet shredding spec, particularly regarding unsigned integer support in `typed_value` fields. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ADBC documentation overhaul and release:** The ADBC subproject released version 24 and overhauled its documentation to better clarify the distinction between ASF-maintained and vendor-specific drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Documentation%20overhauled%20for%20ADBC) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2024%20-%20RC2)

* **Bug squashing initiative:** Community members are organizing a focused effort to triage and close out stale issues across all language implementations to improve project health. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Closing%20out%20old%20issues%20-%20extra%20help%20wanted)
