* **Arrow 26.0.1 patch release:** The RC1 vote passed with 7 binding approvals, and the release was announced on Nov 4. It includes the Brotli CVE-2026-111497 fix that downstream users had requested. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.1%20released)

* **PyArrow 27 timing:** Users asked about a PyArrow 27 release after a vulnerability scanner flagged 26.0.1. The answer was that 27.0.0 is planned for January 2027. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Version%2027) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Pyaarow%2027.0.0%20version%20availability)

* **Rust patch releases:** Arrow Rust 60.2.0, 59.3.3, 58.4.2 and 57.3.3 all passed their votes in mid-November. Reviewers flagged non-blocking licensing notes that are being tracked for follow-up. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1)

* **Arrow Java 20.0.0 and release cadence:** The 20.0.0 vote passed on Nov 20 and the release followed on Nov 21, raising the minimum to Java 17. A proposal for at least quarterly Java releases got broad support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **Sovereign Tech Fund invests in PyArrow:** A German government-backed fund will finance about 1.9 FTE of PyArrow work through 2027. Priorities include type annotations, the issue backlog, AI-readiness tooling, documentation, and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **AI-generated contributions policy:** Maintainers agreed to use two labels, one asking authors to explain their change in their own words and one closing PRs whose expected AI-usage disclosure is missing. The goal is to reduce maintainer load and allow automation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Parquet FILE canonical extension type:** A vote to add `arrow.parquet.file` is open, matching the Parquet FILE logical type. Committers disagree on whether Parquet-specific types should be Arrow canonical types, so the vote may be paused. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20(GH-51143)) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Flight SQL Substrait dialect codes:** A vote proposes two new SqlInfo codes that expose the server's accepted Substrait dialect and a content hash for client caching. The change is backwards compatible and has binding +1 votes so far. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **ADBC 1.2 planning:** Maintainers agreed on a metadata approach, a credential callback that updates the connection via SetOption, and JSON for structured error details. Partitioned bulk ingest had no consensus and will be reworked as an action. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **GitHub pull_request_target restriction:** GitHub will restrict the `pull_request_target` trigger from December 2, with brownouts on November 9 and 16. Arrow repos are inventorying affected workflows, and the Boring Cyborg bot was enabled for labeling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)
