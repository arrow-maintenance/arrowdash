* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, which includes 337 resolved issues across the project components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2026.0.0%20released)

* **Dropping macOS Intel support:** Developers discussed removing support for macOS Intel on CI due to Homebrew deprecation and high maintenance costs, citing that these users represent only ~0.1% of PyArrow downloads. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **PyArrow modularity and multi-wheel distribution:** A proposal is underway to split PyArrow into multiple optional wheels (e.g., S3, GCS, Azure) to reduce the monolithic package size and improve installation flexibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Handling AI-generated contributions:** Discussion regarding the rise of low-quality AI PRs led to a proposal for a "needs-author-engagement" label to flag contributors who do not demonstrate understanding or respond to review feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Range canonical extension types:** A vote is open for adding two new canonical extension types, `arrow.fixed_closedness_range` and `arrow.variable_closedness_range`, to represent bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Native IBM Db2 driver for ADBC:** IBM contributors have proposed the contribution of a native C++ ADBC driver for Db2 (LUW), expanding the ecosystem of database connectivity drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **IPC representation of dictionary-encoded extension types:** This proposal aims to allow `custom_metadata` on dictionary values in IPC streams, closing a gap in the specification and enabling better support for types like UUIDs and spatial data. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait dialect advertising:** A new proposal suggests using `SqlInfo` codes to allow Flight SQL servers to advertise exactly which Substrait dialects and features they support for better client compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Arrow Rust 60.0.0 release:** The Rust implementation reached version 60.0.0, introducing new Parquet encoding support, kernel performance improvements, and work to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)
