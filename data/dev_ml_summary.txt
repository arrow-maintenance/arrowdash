* **Arrow 26.0.0 and 26.0.1 releases:** Major release featuring over 300 resolved issues, followed by a rapid patch to address a security vulnerability in the bundled Brotli library (CVE-2026-111497). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1)

* **Sovereign Tech Fund investment in PyArrow:** The German Sovereign Tech Agency is funding 1.9 FTEs through 2027 to improve PyArrow type annotations, documentation, and maintainer tooling for managing high-volume contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI optimization and GitHub Actions costs:** Large-scale effort to reduce the project's CI footprint by 30-40% through more efficient job triggers and the mandatory migration away from the `pull_request_target` event. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)

* **Managing AI-generated contributions:** Proposal to implement mandatory AI disclosure for pull requests, including automated bot actions to convert non-compliant PRs to drafts and refined triage guidelines for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **ADBC 25 release and IBM Db2 driver:** The ADBC subproject reached version 25 with major updates across libraries, while IBM proposed contributing a new native C++ ADBC driver for the Db2 ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **IPC support for dictionary-encoded extensions:** Cross-language effort to add optional metadata to `DictionaryEncoding` to allow the Arrow IPC format to properly represent extension types within dictionaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Substrait dialect support in Flight SQL:** New `SqlInfo` codes are proposed to allow Flight SQL servers to advertise their supported Substrait dialects, enabling better client-side compatibility checks before plan execution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **New Canonical Extension Types:** Technical discussions on defining standard extension types for "fixed and variable closedness ranges" and a "FILE" type to improve interoperability with Parquet logical types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)
