* **BigDecimal extension type pause:** Discussion on a canonical `big_decimal` extension for arbitrary precision and scale has been paused to re-evaluate ecosystem requirements and compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArxLang introduction:** Developers presented Arx, an experimental programming language designed with Apache Arrow as its native foundation for data-oriented runtimes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Deprecation of IPC Tensor messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to reduce maintenance burden on underutilized features. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal project announcement:** A new project called ArrowMetal was announced, providing zero-copy Arrow compute kernels that run on Apple Silicon GPUs through the Metal API. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Parquet File extension type:** Proposal to define `arrow.parquet.file` as a canonical extension type to represent file-level references, matching the Parquet specification's logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow Rust 60.0.0 release:** The Rust implementation released version 60.0.0, introducing support for the new ALP (Adaptive Lossless Floating-Point) Parquet encoding and significant performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **AI-generated contribution guidelines:** Reviewers are discussing formalizing procedures and response templates for managing low-quality or non-compliant AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **New committers joined:** The Apache Arrow PMC announced the addition of Zehua Zou and Kosta Tarasov as new project committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Kosta%20Tarasov)

* **Arrow Go 18.8.0 release:** The Go implementation reached version 18.8.0, incorporating nearly 300 commits across its core libraries, Flight, and Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)
