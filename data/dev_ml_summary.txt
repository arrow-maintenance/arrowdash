* **Arrow 26.0.0 release:** The community approved the release candidate for Apache Arrow 26.0.0, which includes over 330 resolved issues across the project's various implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **PyArrow modularity and wheel size:** Discussion on splitting PyArrow into smaller, optional wheels (e.g., `pyarrow-s3`) to reduce the core installation size and maintenance burden of the monolithic package. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Proposal to drop official support and CI coverage for macOS on x86_64 architecture due to declining usage and Homebrew’s discontinuation of support for Intel bottles. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Management of AI-generated contributions:** Debate on handling low-quality AI-generated pull requests, including a proposal to introduce a "needs-author-engagement" label to ensure contributors understand their submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Arrow Rust 60.0.0 release:** Announcement of a major release for the Rust implementation, featuring new Parquet encoding support and significant performance improvements for compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical range extension types:** A vote was held to add new canonical extension types to the Arrow format for representing both fixed and variable closedness ranges. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation for dictionary-encoded extensions:** Proposal to add an optional field to the IPC format that allows dictionary-encoded extension types to correctly preserve their metadata during serialization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait dialect advertising:** Discussion on adding new SqlInfo codes to Flight SQL, allowing servers to advertise specific supported Substrait dialects for improved plan compatibility checking. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC driver contribution:** IBM developers have proposed contributing a native C++ ADBC driver for Db2 to the ecosystem to support high-performance data access. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
