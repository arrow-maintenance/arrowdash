* **Apache Arrow 26.0.0 Release:** The community announced the release of version 26.0.0, including over 330 resolved issues across the C++, C#, Go, Java, Python, and Rust implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Sovereign Tech Fund investment in PyArrow:** The German government-backed fund is financing 1.9 full-time equivalents through 2027 to work on PyArrow type annotations, documentation, and tooling to help maintainers manage high volumes of contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)

* **CI resource optimization:** Developers are implementing strategies to reduce GitHub Actions runner usage by up to 40% to alleviate queue congestion, including moving to self-hosted runners and reducing redundant test runs on PRs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%7E30-40%25%20fewer%20runner%20minutes)

* **AI-generated contribution policy:** Discussion regarding the surge in AI-assisted PRs has led to proposed guidelines requiring mandatory disclosure and new triage procedures for managing unaddressed or low-quality automated code. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **New Range Extension Types:** A vote is underway to add `fixed_closedness_range` and `variable_closedness_range` to the Arrow canonical extension types to provide standardized support for mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **ADBC 25 Release:** The ADBC subproject released version 25, which includes updates for C#, Java, and Rust, as well as a new visual identity and logo for the subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%20ADBC%2025%20-%20RC2)

* **IPC for dictionary-encoded extension types:** A proposal to allow the Arrow IPC format to represent extension types that use dictionary encoding by adding custom metadata to the `DictionaryEncoding` format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Flight SQL Substrait advertising:** Discussion on adding new `SqlInfo` codes to allow Flight SQL servers to inform clients about supported Substrait dialects and capabilities for better plan compatibility. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Java contributions from DataFusion Comet:** Maintainers from the Apache DataFusion Comet project have begun upstreaming bug fixes and performance improvements to Arrow Java to replace internal workarounds. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Java%20Contributing%20back%20from%20Comet%20project)

* **Arrow 26.0.1 Patch Release:** A maintenance release is being finalized to address a security vulnerability in the bundled Brotli library (CVE-2026-111497) and fix several critical CI failures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1)
