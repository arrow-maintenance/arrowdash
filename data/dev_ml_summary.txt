* **Apache Arrow 26.0.0 and ADBC 25 releases:** Major releases for the core library and the database connectivity subproject, resolving over 390 issues combined across multiple language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0 major release:** Significant update for the Rust implementation featuring new Parquet encoding support, kernel performance optimizations, and a sustained effort to remove panics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **Improving PyArrow modularity:** Discussion on splitting PyArrow into smaller, modular wheels to reduce the installation footprint, addressing a long-standing concern for downstream Python users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Substrait dialect advertising via Flight SQL:** Proposal to allow servers to report supported Substrait features using SqlInfo codes, helping clients avoid runtime errors by checking compatibility beforehand. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **Metadata for dictionary-encoded extension types:** Addressing a gap in the IPC format to ensure extension type metadata is preserved when dictionary encoding is applied to columns. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 ADBC driver contribution:** IBM developers proposed contributing a native C++ ADBC driver for Db2 (LUW) to the ecosystem, with a repository already established for collaboration. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Policy for AI-generated contributions:** Exploration of the impact of AI on maintainer workload, leading to proposed documentation on mandatory disclosure and rules against AI-generated review replies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **CI workflow optimization:** Analysis suggesting a 30-40% reduction in GitHub Actions usage by refining path filters, using new "ubuntu-slim" runners, and optimizing merge-triggered jobs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20~30-40%25%20fewer%20runner%20minutes)

* **Canonical range extension types:** A vote on defining canonical extension types for ranges with fixed and variable closedness, facilitating interoperability for mathematical intervals and Postgres-style range types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation for Arrow schemas:** Discussion on a standardized JSON format for defining schemas, useful for data contracts and passing metadata between processes in a human-readable way. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)
