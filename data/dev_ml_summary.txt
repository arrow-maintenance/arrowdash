* **Arrow 26.0.0 release:** The community approved the release of version 26.0.0, resolving 337 issues across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Arrow Rust 60.0.0:** This major release of the Rust implementation introduces support for Parquet ALP encoding and significant performance improvements to kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **PyArrow modularity improvements:** Proposal to split PyArrow into multiple wheels (e.g., pyarrow-s3) to reduce the monolithic package size and allow for optional dependencies. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on deprecating official CI support for macOS Intel as Homebrew and other infrastructure tools shift focus toward Apple Silicon. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **AI-generated contributions:** Proposal to establish reviewer guidelines for handling low-quality AI PRs, including the introduction of a "needs-author-engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Range canonical extension types:** Discussion and voting on adding `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` as canonical extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **JSON representation of Arrow schemas:** Ongoing work to standardize a JSON format for Arrow schemas to facilitate data contracts between different processes and languages. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)

* **ADBC logo proposal:** Exploration of a new visual identity for the Arrow Database Connectivity (ADBC) subproject, which has reached a revised design via community feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ADBC%20Logo%20Proposal)

* **CSV date/time parsing improvements:** Efforts to move forward a long-standing PR that enables the CSV reader to use custom timestamp parsers for date and time types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:C%2B%2B%20Python%20Getting%20PR%20%2350146%20CSV%20date/time%20parsing%2C%20GH-41488%20reviewed)
