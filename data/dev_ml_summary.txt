* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages within the IPC protocol due to limited implementation across languages and to simplify the format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Status of BigDecimal extension proposal:** Work on the `arrow.big_decimal` canonical extension type has been paused to better evaluate ecosystem requirements and the scope of necessary compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArrowMetal GPU compute for Apple Silicon:** Introduction of ArrowMetal, a new library providing Arrow compute kernels that run on Apple Silicon GPUs via Metal with zero-copy data sharing between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Upcoming Arrow Hackathon in Glasgow:** An in-person hackathon is scheduled for October 13th at the Community Over Code conference, focused on helping new contributors get started and collaborating on "good first issues." [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Apache Arrow Go v18.8.0 release:** The Go implementation has released version 18.8.0, featuring 283 commits from 16 contributors across the core library, Flight, and Parquet components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Proposed FILE canonical extension type:** Developers proposed `arrow.parquet.file` as a new extension type to provide a standard in-memory representation of file-level references compatible with the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang Arrow-native programming language:** Introduction of Arx, an experimental data-oriented programming language that uses Apache Arrow as its native foundation for types and runtime. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant extension and Parquet shredding consistency:** Discussion on refining the Variant extension specification to explicitly disallow Arrow types that cannot be mapped back to Variant, such as unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **New Project Committers:** The PMC announced the addition of Zehua Zou and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou)
