* **Apache Arrow 25.0.0 and 25.0.1 releases:** Major release 25.0.0 was published with 222 resolved issues, followed by a 25.0.1 patch release to address specific regressions and improve nested type performance. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **Windows Arm64 support for PyArrow:** Microsoft and Linaro proposed a commitment to enable and maintain Windows on Arm64 builds, offering dedicated engineering resources and hardware for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSPythonCI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Semantics of non-nullable fields in IPC:** Technical discussion on clarifying how the `nullable` flag should be interpreted for complex types, such as child fields in structs or dictionary arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Canonical BigDecimal extension type:** Proposal for a new `arrow.big_decimal` extension type to provide high-fidelity transport for variable-scale numeric data from systems like PostgreSQL and Trino. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limits on concurrent PRs for non-committers:** Discussion on implementing a GitHub policy to limit contributors without write access to a small number of open pull requests to manage stale and AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Swift minimum version bump:** Proposal to raise the minimum required Swift version to 6.0 to utilize native `Int128` support for high-precision decimal arithmetic. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSSwift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension and Parquet shredding inconsistency:** Developers identified discrepancies between the Arrow Variant extension spec and the Parquet shredding spec regarding unsigned integer support and null mappings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Apache Arrow ADBC 24 release:** The ADBC subproject released version 24, featuring a major documentation overhaul and independent versioning for its various language implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **New community members:** The project welcomed Jeffrey Vo to the Project Management Committee (PMC) and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
