* **Apache Arrow 25.0.1 and ADBC 24 releases:** The community released Apache Arrow 25.0.1 to address critical bugs and ADBC release 24, which includes over 50 improvements across various database drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Windows on Arm (win_arm64) support:** Microsoft proposed a comprehensive plan to enable win_arm64 support for PyArrow, including commitments for dedicated engineering and hardware for maintainers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Canonical BigDecimal extension type:** Discussion on a new extension type to represent variable-scale numeric data, though some maintainers expressed concerns regarding the maturity of the layout specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Limit on concurrent PRs for non-committers:** Proposal to limit non-committers to three open pull requests to reduce the burden of stale and low-quality AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Variant extension and Parquet shredding alignment:** Developers are working to resolve inconsistencies between the Arrow Variant extension and the Parquet shredding specification, specifically regarding unsupported types like unsigned integers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang introduction:** Presentation of an experimental programming language that uses Apache Arrow as its native foundation for data types, arrays, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Community over Code Hackathon:** Planning is underway for an Arrow hackathon in Glasgow this October, with a focus on curated issues and "good first issues" for new contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Minimum Swift version bump:** Proposal to increase the minimum required Swift version to 6.0 to leverage modern language features in the Arrow Swift implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Lazy memory mapping for Parquet:** An experimental library was presented that uses custom fault handling to lazily map Parquet columns to NumPy arrays, hiding row-group boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)
