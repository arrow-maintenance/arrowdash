* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, resolving 337 issues across the project including significant updates to C++, Python, and GLib implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.0%20released)

* **AI-generated contributions:** Developers discussed strategies for managing low-quality AI-generated pull requests, proposing a "needs-author-engagement" GitHub label to flag contributions where the author lacks subject matter understanding or fails to respond to feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Dropping macOS Intel support:** A proposal was made to drop official support and CI testing for macOS Intel (x86_64) due to Homebrew's deprecation of the platform and very low usage statistics in the community. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel split:** Discussion on splitting the monolithic PyArrow package into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the 2 GB release size and improve installation flexibility for users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Arrow Rust 60.0.0:** The Rust implementation reached version 60.0.0, featuring new Parquet encoding support, kernel performance improvements, and a sustained effort to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Canonical range extension types:** A formal vote was opened to add `fixed_closedness_range` and `variable_closedness_range` to the Arrow canonical extension types for representing mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC metadata for dictionary-encoded types:** Developers proposed adding `custom_metadata` to the IPC `DictionaryEncoding` structure to ensure that extension type metadata for dictionary values is preserved during serialization. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **ADBC Db2 driver contribution:** IBM has proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertising:** A proposal was made to add new `SqlInfo` codes so that Flight SQL servers can advertise specifically which Substrait dialects and functions they support to clients. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)
