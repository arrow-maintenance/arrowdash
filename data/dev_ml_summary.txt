* **Deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to simplify the specification, as these features are rarely used or implemented. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **New File canonical extension type:** Proposal to add an `arrow.parquet.file` extension type to standardise how file-level references, such as URIs and checksums, are represented across memory and storage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow Rust 60.0.0 release:** A major update to the Rust implementation featuring support for ALP (Adaptive Lossless Floating-Point) encoding in Parquet and significant performance improvements for PageIndex structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTERUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **ArrowMetal Apple GPU compute:** Announcement of ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple silicon GPUs via the Metal API and shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **AI-generated contribution guidelines:** Discussion on introducing specific reviewer guidelines to handle low-quality AI contributions and establish protocols for when to close non-conforming pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **BigDecimal extension work paused:** Development of a canonical BigDecimal extension type has been paused to re-evaluate ecosystem practices and requirements for arbitrary-precision numeric compute. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Lazy memory mapping for Parquet:** Proposal for a Parquet interface using custom fault handling to map address ranges lazily to columns, enabling zero-copy access for vectorized operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSParquetCPython%20Lazy%20memory%20mapping)

* **Arrow Go 18.8.0 release:** The Go implementation release was finalized with 283 commits, including updates to the compute registry and improved support for newer Go toolchains. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **New project committers:** Zehua Zou and Kosta Tarasov have joined the project as new committers following their significant contributions to the community. [Thread 1](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread 2](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
