* **AI-generated contributions:** Maintainers discussed PR overload from AI-generated work and proposed a PR cap via .asf.yaml, mandatory AI-use disclosure with a bot that converts non-compliant PRs to drafts, and a neutral "needs author engagement" label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **pull_request_target restriction:** GitHub will restrict the pull_request_target trigger from December 2, with brownouts on November 9 and 16. Arrow is migrating its affected workflows, tracked in a GitHub issue. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)

* **Lighter GitHub Actions CI:** Proposal to cut runner minutes by about 30-40% by adopting optimization hints and running CI from forks. Airflow reports good results from self-hosted runners, and fork CI still awaits a final vote there. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow%27s%20GitHub%20Actions%20CI%20lighter%20%28~30-40%25%20fewer%20runner%20minutes%29)

* **Arrow 26.0.1 patch release:** The RC1 vote passed with 7 binding votes, and the release shipped on November 4. It includes the Brotli fix for CVE-2026-111497, and PyArrow users asked when a fixed version would be available. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Brotli%20CVE-2026-111497%20fix%20%28GH-55165%29%20in%2026.0.1)

* **Arrow Rust patch releases:** Patch releases 57.3.3, 58.4.2 and 59.3.3 were approved in mid-November. Version 60.2.0 followed on November 21 after a vote with 4 binding approvals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1)

* **Arrow Java 20.0.0 and release cadence:** Java 20.0.0 was released on November 21, raising the minimum to Java 17. A follow-up proposal to release Arrow Java at least quarterly, or on demand, was broadly supported. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Java%2020.0.0%20Released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **arrow.parquet.file extension type:** A vote is open to add a canonical extension type for the Parquet FILE type, matching the Parquet logical type. Discussion continues on whether Parquet-specific types should be defined by the Parquet community rather than Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Flight SQL Substrait dialect codes:** A vote proposes two new SqlInfo codes that expose the Substrait dialect a server accepts, plus a hash for client-side caching. The change is backward-compatible, and the vote has early binding approvals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **ADBC 1.2 planning:** A planning session settled the approach for metadata, the credential callback, structured error details, and vendor-specific actions. Partitioned bulk ingest still lacks consensus, and no target date is set yet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **PyArrow funding from Sovereign Tech Fund:** The German Sovereign Tech Agency will fund about 1.9 FTE of PyArrow work through 2027. Priorities include type annotations, the issue backlog, AI-contribution tooling, documentation, and extension type support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Announce%20The%20Sovereign%20Tech%20Fund%20invests%20in%20PyArrow)
