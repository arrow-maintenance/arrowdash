* **ArxLang native Arrow integration:** Introduction of Arx, an experimental programming language designed with Apache Arrow as its native foundation for data types and runtime operations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol to focus on the project's core columnar format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal 0.1.0, which provides Arrow compute kernels that run on Apple silicon GPUs through Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Reviewer guidelines for AI contributions:** Discussion on establishing formal procedures for reviewers to handle low-effort or non-compliant AI-generated pull requests. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Canonical extension for FILE type:** Proposal to add an `arrow.parquet.file` extension type to provide an in-memory Arrow representation of the new Parquet FILE logical type. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **BigDecimal extension proposal paused:** Work on standardizing a canonical BigDecimal extension type has been paused to gather more information on ecosystem compute requirements and specific user use cases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Rust 60.0.0 release:** Major release of the Rust implementation featuring new support for the ALP (Adaptive Lossless Floating-Point) Parquet encoding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **New project committers:** Zehua Zou and Kosta Tarasov were officially announced as new committers for the Apache Arrow project following community votes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou)
