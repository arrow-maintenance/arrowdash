* **Deprecation of Tensor IPC messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-language implementation and the lack of alignment with modern format evolution. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal for Apple Silicon GPUs:** Announcement of ArrowMetal 0.1.0, a library providing Arrow compute kernels that run on Apple silicon GPUs via Metal with zero-copy shared memory. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension proposal paused:** Discussion on a canonical arbitrary-precision decimal type was put on hold to gather more information on ecosystem requirements and potential compute kernel needs. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Apache Arrow Go 18.8.0 release:** A new release of the Go library is available, including nearly 300 commits and specific fixes for building with the Go 1.27 toolchain. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **New canonical extension for FILE types:** Proposal to define an `arrow.parquet.file` extension type that aligns with the Parquet specification's new FILE LogicalType for representing file-level references. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Variant extension specification alignment:** Discussion on refining the Variant extension documentation to explicitly disallow types in the shredded representation that have no equivalent in the base Variant format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **ArxLang experimental language:** Introduction of Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and data types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Pull Request limits for non-committers:** A proposal to limit non-committers to three concurrent open pull requests is under review to help optimize reviewer bandwidth across the project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **New project committers:** The Apache Arrow PMC announced that Zehua Zou and Kosta Tarasov have accepted invitations to become project committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)
