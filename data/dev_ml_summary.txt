* **Arrow Rust 60.0.0 release:** Major release featuring support for the new ALP encoding, significant Parquet performance improvements, and the removal of various panics across the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Apache Arrow 26.0.0 release:** The community approved the release of version 26.0.0, resolving over 330 issues across the project's various implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **AI-generated contribution guidelines:** Discussion on establishing reviewer guidelines for handling low-quality AI PRs, including a proposal for a "needs-author-engagement" label to flag lack of author feedback. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **Dropping macOS Intel support:** Proposal to drop macOS Intel (x86_64) support for CI and official binaries due to Homebrew deprecations and extremely low usage statistics (~0.1% for PyArrow). [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Drop%20macOS%20Intel%20support)

* **PyArrow modularity and multi-wheel support:** A proof-of-concept was presented to split PyArrow into multiple wheels (e.g., core and optional modules like S3) to significantly reduce the package installation size. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Improve%20modularity%20of%20PyArrow)

* **Canonical extension types for ranges:** A vote is open to add `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` to the Arrow specification to support mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTEFormat%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 ADBC driver contribution:** IBM developers proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC subproject. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **New Committer announcement:** Richard Baah has been invited to become a committer on the Apache Arrow project following his sustained contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Richard%20Baah)

* **JSON representation of Arrow schemas:** Discussion on finalizing a standardized JSON format for Arrow schemas, including support for complex types like Sparse Unions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSSFormat%20JSON%20representation%20of%20Arrow%20schemas)
