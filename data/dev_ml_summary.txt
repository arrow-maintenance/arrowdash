* **Apache Arrow 26.0.0 release:** The community announced the release of version 26.0.0, resolving 337 issues across the project including significant updates to C++, Python, and documentation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Apache%20Arrow%2026.0.0%20released)

* **PyArrow modularity and multi-wheel installation:** Proposal to split PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the primary package size on PyPI and alleviate maintenance burdens. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Dropping macOS Intel support:** Discussion on ending support for macOS Intel (x86_64) due to Homebrew's deprecation of Intel bottles and the increasing difficulty of maintaining CI coverage for the platform. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Arrow Rust 60.0.0 release:** The Rust community released version 60.0.0, featuring new Parquet encoding support, significant kernel performance improvements, and work to remove panics from the codebase. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **Canonical extension types for ranges:** A formal vote is open to add two range types (fixed and variable closedness) to the Arrow specification to better support interval data from pandas and PostgreSQL. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **AI-generated contributions and author engagement:** Discussion on managing the quality of AI-assisted PRs, including a proposal for a "needs-author-engagement" label to flag contributors who lack understanding of their own submissions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **IPC representation of dictionary-encoded extension types:** Draft proposals for C++, Go, and Rust to allow IPC messages to represent metadata for dictionary-encoded extension types, filling a gap in the current format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM contributors proposed adding a native C++ ADBC driver for IBM Db2 (LUW) to the official ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertising:** Proposal to add new SqlInfo codes to Flight SQL so servers can explicitly advertise which Substrait dialects, types, and functions they support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **New Arrow Committer:** Richard Baah has been invited and accepted to become a committer on the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20Arrow%20committer%20Richard%20Baah)
