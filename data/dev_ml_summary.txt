* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor-related messages in the IPC protocol and will encourage implementations to remove associated APIs. This move reflects a lack of cross-language implementation and a shift toward alternative representations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal announcement:** Introduction of ArrowMetal 0.1.0, a new project providing Arrow compute kernels that run on Apple silicon GPUs via Metal with zero-copy data sharing. The project also identified several divergences in existing Arrow implementations that are being addressed upstream. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **BigDecimal extension type status:** Work on the `arrow.big_decimal` extension proposal is being paused to re-evaluate requirements. Discussion highlighted the tension between a simple transport type for RDBMS interoperability and a fully featured type with compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation including new support for the ALP (Adaptive Lossless Floating-Point) Parquet encoding. It also features updated Parquet PageIndex structures and significant performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:RESULT%20VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Reviewer guidelines for AI contributions:** Developers are discussing establishing formal guidelines for reviewers on how to handle low-quality or non-compliant AI-generated pull requests. The proposal includes a standardized warning message and escalation paths for closing low-effort contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20AI-generated%20contributions)

* **New Canonical Extension Type for FILE:** Proposal to add `arrow.parquet.file` as a canonical extension type to align with the Parquet specification's FILE LogicalType. This would preserve file-level references (URIs, offsets, checksums) across IPC and language boundaries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Lazy memory mapping for Parquet:** Discussion on a proposal to implement lazy loading for Parquet columns using address range fault handling. This would allow exposing entire columns through mmap-like interfaces that load data only when accessed, hiding row-group boundaries from the caller. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)

* **Conbench benchmarking evolution:** Project maintainers are discussing a redesign of the Conbench benchmarking infrastructure. The proposed direction moves toward a storage layer based on Parquet files queried by DuckDB rather than relying on Postgres as the primary system of record. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **New Committers:** The project welcomed Zehua Zou and Kosta Tarasov as new committers to the Apache Arrow project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:New%20committer%20Zehua%20Zou) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20committer%20Kosta%20Tarasov)

* **PR limits for non-committers:** The community discussed and agreed upon a limit of 3 concurrent open pull requests for non-committers to manage review load and encourage focus on merging existing contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)
