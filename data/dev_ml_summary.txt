* **Apache Arrow 25.0.0 release:** This major release resolves over 220 issues; the community specifically addressed performance bottlenecks in `to_pylist` that would otherwise impact Spark 4.2's new default Arrow serialization path. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2025.0.0%20-%20RC1)

* **Standardized JSON schema representation:** Discussion on a formal JSON specification for Arrow schemas to simplify use in REST APIs and improve human readability compared to raw Flatbuffer layouts. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Semantics of non-nullable fields:** A technical investigation into how the `nullable` flag should be interpreted for complex types, specifically regarding whether child fields in a struct remain logically valid when the parent struct is null. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Swift 6.0 minimum version proposal:** Proposal to increase the minimum Swift requirement to 6.0 to leverage native `Int128` support, which is essential for implementing high-precision Decimal types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension spec discrepancies:** Identification of inconsistencies between Arrow’s Variant extension specification and the Parquet shredding spec, particularly concerning the handling of unsigned integer types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **C Data Interface field name constraints:** Clarification that while Arrow supports null bytes in UTF-8 field names, the C FFI exporter must validate and error out on them as they cannot be round-tripped through nul-terminated C strings. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Spec%20clarification%20on%20field%20names)

* **ADBC 24 release:** The community released version 24 of the Arrow Database Connectivity (ADBC) libraries, which includes a comprehensive documentation overhaul and version updates for C, Go, Java, and Python drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20ADBC%2024%20-%20RC1)

* **Parquet extended range timestamp proposal:** Notification regarding a Parquet community proposal to store the full SQL range for nanosecond timestamps, which will eventually require support in Arrow's Parquet reader/writer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Parquet%20proposal%20for%20extended%20range%20timestamp%20type)
