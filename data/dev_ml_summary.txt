* **Deprecation of Tensor and SparseTensor in IPC:** The community voted to informally deprecate Tensor and SparseTensor-related messages in the IPC protocol to simplify the core specification and reflect limited cross-implementation support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **BigDecimal canonical extension type proposal:** Discussion and a vote were held for a new `arrow.big_decimal` type to represent arbitrary-precision decimals; the effort is currently paused to better align with existing ecosystem compute requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **ArrowMetal GPU compute for Apple Silicon:** Introduction of ArrowMetal, a new project providing Arrow compute kernels that run on Apple GPUs via Metal, featuring zero-copy shared memory between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Limit on concurrent PRs for non-committers:** Proposal to limit non-committers to three concurrent open pull requests to help maintainers manage review load and mitigate potential AI-generated submission spam. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **FILE canonical extension type:** A new extension type `arrow.parquet.file` was proposed to provide a standard in-memory representation for file-level references, mirroring the recently added FILE LogicalType in Parquet. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **ArxLang announcement:** Developers introduced Arx, an experimental programming language designed with Apache Arrow as its native foundation for runtime data types and memory representation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Lazy memory mapping for Parquet:** A proposal for a library that uses custom fault handling to lazily map Parquet column ranges to memory, enabling vectorized operations over entire columns without explicit row-group handling. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Lazy%20memory%20mapping)

* **Recent releases and new committers:** The project released Arrow Go v18.8.0, Arrow Rust 59.3.0, and Arrow 25.0.1, while welcoming Tadeja Kadunc, Zehua Zou, and Kosta Tarasov as new committers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.1%20released)

* **Community Over Code Hackathon:** Planning is underway for an Arrow-focused hackathon in Glasgow this October, with maintainers curating a list of "good first issues" for new contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
