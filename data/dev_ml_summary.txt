* **Semantics of non-nullable fields:** A technical deep dive into what the `nullable` flag means for complex types like nested structs and unions, specifically addressing cases where a parent is null but a child field is marked non-nullable. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Semantics%20of%20non-nullable%20fields%20with%20non-trivial%20types)

* **Canonical BigDecimal extension type:** Formal proposal and vote to add an `arrow.big_decimal` extension type to handle variable-scale numeric data common in databases like PostgreSQL and Oracle. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Windows on Arm (win_arm64) support:** Engineers from Microsoft and Linaro proposed a plan to provide dedicated CI maintenance, hardware, and engineering time to support official PyArrow wheels for Windows on Arm. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **PR limits for non-committers:** Discussion on implementing a limit (potentially 3) on concurrent open pull requests for contributors without write access to manage an influx of stale or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **Apache Arrow 25.0.0 and 25.0.1 releases:** The project announced the major 25.0.0 release followed by a 25.0.1 patch release to address critical bug fixes in C++ and Python. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2025.0.0%20released)

* **ADBC 24 release and documentation overhaul:** The Arrow Database Connectivity (ADBC) subproject released version 24 and significantly updated its documentation site to better clarify the relationship between ASF and vendor-provided drivers. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20ADBC%2024%20Released)

* **Swift 6.0 minimum version proposal:** A proposal to raise the minimum Swift version to 6.0 to leverage native `Int128` support, which is a prerequisite for implementing robust Decimal types in the Swift library. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Swift%20Proposal%20to%20raise%20minimum%20Swift%20version%20to%206.0)

* **Variant extension spec inconsistency:** Developers identified a discrepancy between the Arrow Variant spec and the Parquet Shredding spec regarding unsigned integer mappings, leading to a proposal to align the two. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Community growth:** The project welcomed Jeffrey Vo to the Project Management Committee (PMC) and Tadeja Kadunc as a new committer. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)
