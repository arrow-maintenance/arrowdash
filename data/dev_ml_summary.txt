* **BigDecimal extension type proposal:** Discussion and subsequent pause on standardizing a canonical `arrow.big_decimal` extension type for variable-scale numeric data, highlighting the need for broader scope regarding compute kernel support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **Deprecation of Tensor messages in IPC:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to low adoption and incomplete cross-language implementation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Limits on concurrent PRs:** Proposal to limit non-committers to three concurrent open pull requests to help maintainers manage review load and reduce the impact of potential AI-generated spam. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **ArrowMetal performance library:** Announcement of ArrowMetal 0.1.0, which implements Arrow compute kernels on Apple silicon GPUs using Metal and shared memory for zero-copy data exchange. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Canonical Extension Type for FILE:** Proposal to introduce an `arrow.parquet.file` extension type to preserve file-level reference semantics (URI, offset, size) consistently with the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Conbench benchmarking infrastructure:** Discussion on revamping the Conbench project, including moving toward a Parquet-based storage layer and DuckDB for performance data analysis. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Status%20of%20Arrow%20conbench%20data%20%2B%20conbench%20OSS%20project)

* **ArxLang introduction:** Presentation of Arx, an experimental language utilizing Apache Arrow as its native foundation for arrays, tensors, and DataFrames. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Release updates for Go and Rust:** Successful releases of Arrow Go v18.8.0 and voting cycles for Arrow Rust v60.0.0 and Object Store v0.14.2. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Arrow community hackathon:** Planning for an in-person Arrow hackathon at the Community Over Code conference in Glasgow this October to help new contributors get started. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)
