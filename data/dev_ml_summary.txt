* **Arrow Rust 60.0.0 Release:** The community announced version 60.0.0 of the Rust implementation, featuring the first Parquet implementation with ALP encoding support and various performance improvements to kernels and FFI. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **JSON representation of Arrow schemas:** Discussion continues on establishing a standardized JSON format for Arrow schemas to facilitate data contracts and cross-process communication, specifically addressing support for Union types and nested structures. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)

* **Guidelines for AI-generated contributions:** Developers are refining reviewer guidelines to handle low-quality AI-generated PRs, proposing a new "needs-author-engagement" GitHub label to flag contributions where the author shows limited understanding of the changes. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Canonical Range extension types:** A formal proposal and vote were initiated for adding `arrow.fixed_closedness_range` and `arrow.variable_closedness_range` extension types to represent bounded mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **Dropping macOS Intel support:** Due to Homebrew deprecating Intel bottles and increasing CI maintenance burdens, the community is moving toward dropping official macOS Intel support in favor of a best-effort basis. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **Modularizing PyArrow wheels:** A proof-of-concept was presented to split PyArrow into multiple optional wheels (e.g., pyarrow-s3) to reduce the monolithic installation size and improve package management for users. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Apache Arrow 26.0.0 Release:** The release candidate for version 26.0.0 was approved, resolving over 330 issues and including updates to the C++ and Python implementations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **ADBC Logo and Visual Identity:** The Arrow Database Connectivity (ADBC) subproject reached lazy consensus on a new logo and visual identity to better distinguish the project's branding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20Logo%20Proposal)

* **CSV Date and Time Parsing:** Community members are seeking reviews for a long-standing PR that allows the CSV reader to use custom timestamp parsers as a fallback for date and time types, addressing several legacy issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Getting%20PR%20#50146%20CSV%20date/time%20parsing,%20GH-41488%20reviewed)
