* **Arrow hackathon at Community Over Code:** An Arrow hackathon is scheduled for October 13th in Glasgow, focusing on curating "good first issues" and documentation tasks for new contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Arrow%20Hackathon%20at%20Community%20Over%20Code%20Conference%202026)

* **Deprecation of Tensor and SparseTensor IPC messages:** A vote passed to informally deprecate Tensor and SparseTensor messages in the IPC protocol, as these features lacked cross-implementation support and were primarily limited to C++. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **ArrowMetal 0.1.0 announcement:** Developers introduced ArrowMetal, a new project providing Arrow compute kernels that run natively on Apple silicon GPUs using the Metal API with zero-copy data sharing. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Apache Arrow Go 18.8.0 release:** The Go implementation version 18.8.0 has been released, including 283 commits across Arrow, Flight, FlightSQL, and Parquet libraries. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%20Go%20v18.8.0%20Released)

* **Canonical Extension Type for FILE type:** Discussion is underway to define a canonical extension type, `arrow.parquet.file`, to maintain semantic alignment with the new FILE LogicalType in the Parquet specification. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **BigDecimal extension proposal paused:** The effort to standardize a `arrow.big_decimal` extension has been paused to re-evaluate ecosystem requirements and compute kernel support for arbitrary-precision numerics. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISC%20Status%20update%20on%20arrow.big_decimal%20extension%20proposal)

* **PR limit for non-committers:** The community agreed to implement a limit of three concurrent open pull requests for non-committers to ensure review capacity remains sustainable. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **ArxLang introduction:** Developers presented Arx, an experimental programming language that uses Apache Arrow as the native foundation for its data-oriented runtime and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Variant extension and Parquet shredding inconsistency:** A proposal was made to clarify the Variant extension spec to explicitly disallow shredded columns in the Arrow representation that have no equivalent in the Variant format. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20Variant%20extension%20spec%20inconsistent%20with%20the%20Parquet%20shredding%20spec)

* **Rust and Object Store releases:** Voting and releases are progressing for several Rust components, including Arrow Rust 60.0.0 and Object Store 0.14.2. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)
