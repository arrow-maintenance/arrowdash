* **PyArrow modularity and wheel size:** Proposal to split libarrow shared libraries (like S3 and GCS) into optional side-wheels to reduce the core PyArrow package size from over 2GB. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Arrow Rust 60.0.0 release:** Major release featuring new Parquet encoding support, a sustained effort to remove panics, and significant kernel performance improvements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUCNCE%20Arrow%20Rust%2060.0.0)

* **Apache Arrow 26.0.0 release:** A major milestone resolving 337 issues, including initial support for Python 3.15 and updates to MSVC build configurations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **CI resource optimization:** Discussion on reducing GitHub Actions runner usage by 30-40% by optimizing "Extra" workflows and moving heavy package builds to nightly schedules. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Ideas%20to%20make%20Arrow's%20GitHub%20Actions%20CI%20lighter%20%28%7E30-40%25%20fewer%20runner%20minutes%29)

* **IPC representation of dictionary extension types:** Proposal to allow custom metadata on dictionary values in the IPC format, enabling full support for dictionary-encoded extension types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Canonical range extension types:** Voting to add fixed and variable closedness range types to the Arrow specification to represent mathematical intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IBM Db2 driver for ADBC:** IBM engineers proposed contributing a native C++ ADBC driver for Db2 (LUW) to the Apache Arrow ADBC ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)

* **Flight SQL Substrait dialect advertising:** Proposal to add new SqlInfo codes so servers can inform clients which specific Substrait dialects and features they support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20FlightSQL%20Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **JSON representation of Arrow schemas:** Discussion on refining a standardized JSON format for Arrow schemas to improve cross-language data contracts and interoperability. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Format%20JSON%20representation%20of%20Arrow%20schemas)
