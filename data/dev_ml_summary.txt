* **Arrow 26.0.1 patch release:** The RC1 vote passed with seven binding +1s, and the release was announced on November 4 with about 20 resolved issues. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2026.0.1%20-%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20Apache%20Arrow%2026.0.1%20released)

* **Arrow Java 20.0.0 and release cadence:** Java 20.0.0 passed its vote and was released on November 21, which requires Java 17 or later. The follow-up proposal is to release Arrow Java at least quarterly, with a volunteer to run the releases. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Java%20Release%20Apache%20Arrow%20Java%2020.0.0%20RC0) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Arrow%20Java%20regular%20release%20cadence)

* **Arrow Rust patch releases:** Patch releases 57.3.3, 58.4.2, 59.3.3 and 60.2.0 all passed their votes and were published to crates.io. One test failure on Rust 1.99.1 was judged non-blocking. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.3%20RC1) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2060.2.0%20RC1)

* **arrow.parquet.file canonical extension type:** A vote is open to add a canonical extension type for Parquet FILE columns, matching the Parquet file logical type. The discussion is split on whether Parquet-specific types belong in Arrow's canonical list or should be defined by the Parquet project. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Add%20arrow.parquet.file%20canonical%20extension%20type%20%28GH-51143%29) [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Canonical%20Extension%20Type%20for%20FILE%20type)

* **Flight SQL Substrait dialect codes:** A vote proposes two new SqlInfo codes, one returning the Substrait dialect YAML and one returning a hash for client-side caching. The change is backwards-compatible and the vote has binding approvals so far. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20FlightSQL%20Add%20Substrait%20dialect%20SqlInfo%20codes)

* **ADBC 1.2 planning:** A planning session set scope and open items, with Async out of scope for 1.2. Preliminary decisions cover metadata, a credential callback, JSON error details, a vendor "escape hatch" via actions, and partitioned bulk ingest, which still lacks consensus. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ADBC%20specification%20version%201.2%20planning%20session%20November%2024%202300%20UTC)

* **Automatic Copilot reviews:** Copilot auto-reviews on apache/arrow were billed to contributors' personal accounts. The fix is to stop reviewing on every push, and a PR to disable auto-review was planned to merge on November 24. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Auto%20GitHub%20Copilot%20review)

* **pull_request_target restriction:** GitHub will restrict the pull_request_target trigger from December 2, with brownouts on November 9 and 16. Projects including Arrow are migrating affected workflows, and a Boring Cyborg labeling bot has been enabled across Arrow repositories. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:pull_request_target%20trigger%20migration)

* **Merge button for apache/arrow PRs:** Committers can now use "Squash and merge" instead of dev/merge_arrow.sh, after checking the PR title and text. The old merge script still works but may be removed later. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20PRs%20in%20apache%2Farrow%20can%20now%20be%20merged%20with%20merge%20button)

* **Arrow gathering at Compute! Paris:** An informal Arrow and Parquet Birds of a Feather session is planned for November 26 during the Compute! Paris conference. Attendees must register for the conference. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20gathering%20at%20Compute%21%20Paris)
