* **PyArrow modularization:** Discussion on splitting PyArrow into multiple optional wheels (e.g., `pyarrow-s3`) to reduce the monolithic package size and simplify the installation process. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **Arrow 26.0.0 release:** The community successfully voted on and released version 26.0.0, which addresses over 300 resolved issues across the project's components. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%2026.0.0%20-%20RC0)

* **Dropping macOS Intel support:** Proposal to end official CI and binary support for macOS on Intel hardware due to maintenance burdens and deprecations in the Homebrew ecosystem. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **AI-generated contribution policy:** Discussion on managing the quality of AI-generated pull requests, including a proposal to introduce a "needs-author-engagement" label for non-responsive contributors. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **New Range canonical extension types:** A vote is underway to add `fixed_closedness_range` and `variable_closedness_range` extension types to the Arrow specification for representing bounded intervals. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Fixed%20and%20variable%20closedness%20range%20canonical%20extension%20types)

* **IPC representation of dictionary-encoded extension types:** Proposal to update the IPC format to allow custom metadata on dictionary value types, ensuring extension type information is preserved during encoding. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:IPC%20representation%20of%20dictionary-encoded%20extension%20types)

* **Arrow Rust 60.0.0 release:** Announcement of the major release of the Rust implementation, featuring improved Parquet encoding support and significant performance enhancements in compute kernels. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Arrow%20Rust%2060.0.0)

* **Flight SQL Substrait dialects:** Proposal to add new `SqlInfo` codes allowing Flight SQL servers to advertise supported Substrait features for better client-side plan validation. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Advertise%20supported%20Substrait%20dialect%20via%20SqlInfo)

* **IBM Db2 ADBC driver:** IBM has proposed contributing a native C++ ADBC driver for Db2 (LUW) to the project to expand the ADBC ecosystem's database coverage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Request%20to%20contribute%20IBM%20Db2%20driver%20to%20arrow-adbc)
