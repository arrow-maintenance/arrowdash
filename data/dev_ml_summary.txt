* **Windows on Arm support:** Microsoft engineers proposed a detailed plan for supporting Windows on Arm in PyArrow, including commitments to fund dedicated engineering time for CI maintenance and unified build paths. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Python%20CI%20win_arm64%20support%20for%20PyArrow%20proposed%20plan%20and%20commitment)

* **Arrow 25.0.1 patch release:** The community approved and released a patch version to address several issues found in the 25.0.0 release, including performance improvements for nested type conversions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20Apache%20Arrow%2025.0.1%20-%20RC1)

* **Limit on concurrent PRs:** Developers discussed implementing a limit of three concurrent open pull requests for non-committers to improve review quality and manage the influx of low-value or AI-generated contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Limit%20on%20concurrent%20open%20PRs%20for%20non-committers)

* **BigDecimal extension type proposal:** A proposal for a canonical BigDecimal extension type was discussed to improve interoperability with RDBMS numeric types, though active work was paused to further evaluate ecosystem requirements. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Format%20Proposal%20for%20Canonical%20BigDecimal%20Extension%20Type)

* **ArxLang introduction:** Developers introduced Arx, an experimental programming language built with Apache Arrow as its native foundation for data-oriented runtimes and types. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20ArxLang%20Arrow-native%20data%20types%20in%20a%20programming%20language)

* **Rust implementation updates:** The Arrow Rust implementation saw several releases this month, culminating in version 59.3.0 to resolve issues identified in previous release candidates. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20RUST%20Release%20Apache%20Arrow%20Rust%2059.3.0%20RC2)

* **nanoarrow 0.9.0 release:** The lightweight C-based nanoarrow implementation successfully released version 0.9.0, featuring 38 resolved issues and expanded platform support. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:VOTE%20Release%20nanoarrow%200.9.0)

* **Community recognition:** The project announced Jeffrey Vo as a new PMC member, and welcomed Tadeja Kadunc and Zehua Zou as new committers following their consistent contributions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ANNOUNCE%20New%20Arrow%20PMC%20member%20Jeffrey%20Vo%20Jefffrey)

* **Lazy memory mapping for Parquet:** A proposal was introduced to use custom fault handling for lazy memory mapping of Parquet columns, allowing large datasets to be accessed as zero-copy NumPy arrays. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:DISCUSS%20Parquet%20C%20Python%20Lazy%20memory%20mapping)
