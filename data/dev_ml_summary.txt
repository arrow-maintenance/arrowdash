* **Deprecation of Tensor messages:** The community voted to informally deprecate Tensor and SparseTensor messages in the IPC protocol due to limited cross-language implementation and low usage. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Informal%20deprecation%20of%20Tensor%20and%20SparseTensor%20in%20IPC)

* **Arrow Rust 60.0.0 release:** A major release of the Rust implementation was approved, featuring support for the new Parquet ALP encoding and significant performance improvements for kernels and Parquet PageIndex. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Rust%2060.0.0%20RC1)

* **Dropping macOS Intel support:** Developers proposed dropping support for Intel-based macOS hardware in CI and official binaries as Homebrew and Apple move toward sunsetting support for the architecture. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Drop%20macOS%20Intel%20support)

* **PyArrow modularity and wheel size:** A proposal was introduced to split PyArrow into multiple optional wheels (e.g., pyarrow-s3) to reduce the monolithic 2GB+ distribution size and allow for more granular installations. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Improve%20modularity%20of%20PyArrow)

* **ArrowMetal project announcement:** Announcement of ArrowMetal 0.1.0, which provides Arrow compute kernels optimized for Apple Silicon GPUs through Metal, allowing shared-storage memory between CPU and GPU. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:ArrowMetal%200.1.0%20Arrow%20compute%20on%20Apple%20silicon%20GPUs%20through%20Metal)

* **Handling AI-generated contributions:** Discussion revived on establishing reviewer guidelines for low-quality AI-generated pull requests, including the proposal of a "needs-author-engagement" GitHub label. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:AI-generated%20contributions)

* **Canonical FILE extension type:** Proposal to add `arrow.parquet.file` as a canonical extension type to preserve file-level metadata (URIs, offsets, sizes) when converting between Parquet and Arrow. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Canonical%20Extension%20Type%20for%20FILE%20type)

* **Arrow Go 18.8.0 release:** The Go library was updated to version 18.8.0, resolving build issues with Go 1.27 and including fixes for allocator alignment and the compute registry. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:Release%20Apache%20Arrow%20Go%2018.8.0%20RC1)

* **JSON representation of schemas:** Ongoing discussion regarding a standardized JSON format for Arrow schemas, including draft-02 revisions to improve support for nested types and unions. [Thread](https://lists.apache.org/list?dev@arrow.apache.org:lte=2M:JSON%20representation%20of%20Arrow%20schemas)
